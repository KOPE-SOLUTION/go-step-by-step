# แบบฝึกหัด EP.25 — โปรเจกต์เล็ก 1 — ข้อมูลการวัดและสถานะ

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep25-project-reading` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เปลี่ยนเป็น sensor-02 ค่า 30 ให้ได้ WARNING

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง
