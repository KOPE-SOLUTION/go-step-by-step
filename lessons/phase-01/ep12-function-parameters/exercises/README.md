# แบบฝึกหัด EP.12 — แยกงานเป็นฟังก์ชันและส่งค่าเข้าไป

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep12-function-parameters` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เปลี่ยนให้เรียกด้วย gateway-01 เพียงครั้งเดียว

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
