## คำถามทบทวน

เครื่องหมาย * ใน *float64 และ *value ทำหน้าที่เหมือนกันหรือไม่?

ไม่เหมือน: *float64 ใช้ระบุชนิด pointer ส่วน *value ใช้อ่านหรือเขียนค่าที่ pointer ชี้ในนิพจน์
