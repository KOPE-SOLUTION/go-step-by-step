# แบบฝึกหัด EP.20 — ใช้ pointer เมื่อต้องการแก้ค่าต้นฉบับ

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep20-pointers` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เปลี่ยนค่าเริ่ม 20 และ offset -0.5 ให้ได้ 19.5

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

สร้าง n := 5 และ p := &n แล้วเพิ่มค่าผ่าน *p อีก 1 พิมพ์ n

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
