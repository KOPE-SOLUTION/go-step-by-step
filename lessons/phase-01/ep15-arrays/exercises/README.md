# แบบฝึกหัด EP.15 — เก็บข้อมูลจำนวนคงที่ด้วย array

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep15-arrays` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

สร้าง array สองค่าคือ 20 และ 25 แล้วพิมพ์สมาชิกตำแหน่ง 1

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

คัดลอก array [2]int{1, 2} ไปอีกตัว แก้ช่องแรกของสำเนาเป็น 9 แล้วพิมพ์ทั้งสอง

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
