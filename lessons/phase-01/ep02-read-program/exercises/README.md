# แบบฝึกหัด EP.2 — อ่านโครงโปรแกรมและเปลี่ยนข้อความ

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep02-read-program` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เปลี่ยนข้อความให้เป็น `Device simulator` โดยคงโครงเดิม

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง

## ข้อ 2

พิมพ์ `สวัสดี Go` และสังเกตการแสดงภาษาไทย

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง
