## แนวคิดและคำใหม่

นึกถึงแบบฟอร์มที่มีช่องข้อความ โครงโปรแกรมช่วยให้เครื่องมือรู้ว่าจะเริ่มตรงไหน ส่วนข้อความในเครื่องหมายคำพูดคือสิ่งที่เราเลือกให้แสดง วันนี้เปลี่ยนข้อมูลหนึ่งจุดแล้วสังเกตผล ไม่ต้องเปลี่ยนทุกบรรทัดพร้อมกัน

**package** คือกลุ่มไฟล์ที่ทำงานร่วมกันในโฟลเดอร์เดียวกัน; **import** ระบุ package ที่จะใช้; **ฟังก์ชัน** คือชุดคำสั่งที่มีชื่อ; **string** คือค่าข้อความ

## หยุดคาดเดาก่อนเปิดผล

เปลี่ยนข้อความใน quote แล้วจะต้องเปลี่ยนชื่อ main ตามด้วยหรือไม่?

จดคำตอบสั้น ๆ ก่อนรัน ผิดได้ เก็บเหตุผลที่คิดไว้เทียบกับสิ่งที่เกิดขึ้น

## ตัวอย่างเล็กที่รันได้

### examples/main.go

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, learner!")
}
```

เปิด PowerShell แล้วเลือกโฟลเดอร์บทนี้ (เครื่องอื่นให้เปลี่ยนส่วนหน้าของตำแหน่งตามที่วางหลักสูตร):

```powershell

```

ผลที่คาดหวัง:


ถ้าผลต่าง ให้ตรวจตำแหน่งด้วย `Get-Location` ตรวจไฟล์ที่บันทึก และอ่าน error แรกก่อนแก้

## ทำไมโค้ดจึงทำงานแบบนี้

- `package main` ระบุ package ของโปรแกรมที่สั่งรันได้ ส่วน `func main()` คือฟังก์ชันเริ่มต้นหลังการเตรียม package ของโปรแกรม
- `import "fmt"` ทำให้เรียกเครื่องมือแสดงข้อความได้ `fmt` ติดมากับ Go
- `fmt.Println` เรียกฟังก์ชันที่พิมพ์ค่าแล้วขึ้นบรรทัดใหม่ ส่วน quote ครอบข้อความแต่ไม่ถูกพิมพ์ออก

**แยกประเภท:** syntax และชนิดข้อมูลเป็นหลักของภาษา; การแยกหน้าที่ให้ส่วนเล็กอ่านง่ายเป็นแนวทางออกแบบ; ชื่อโฟลเดอร์และการใช้หนึ่ง module ต่อ EP เป็นทางเลือกของหลักสูตร เกณฑ์อุณหภูมิที่พบเป็นข้อกำหนดจำลอง

## ข้อผิดพลาดที่พบบ่อย

- เขียน `Println` เป็น `println`: Go แยกตัวใหญ่เล็ก ตรวจตัว P
- ผลยังเหมือนเดิม: ตรวจว่าบันทึกและรันจากโฟลเดอร์ที่กำลังแก้จริง
