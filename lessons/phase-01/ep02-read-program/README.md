# EP.2 — อ่านโครงสร้างโปรแกรมและเปลี่ยนข้อความ

Phase 1 — Go Basic • [สารบัญ](../../../docs/playlist-01-go-basic/README.md)

## เป้าหมายและสิ่งที่ควรรู้ก่อน

อธิบายส่วนประกอบของโปรแกรมและเปลี่ยนข้อความที่แสดงได้ ก่อนเริ่มควรเปิด PowerShell และรันตัวอย่างจาก EP.1 ได้ สามารถเปิดตัวอย่างประกอบระหว่างฝึกได้

เรียนตามลำดับ: ทำความเข้าใจ → คาดเดาผล → รันโปรแกรม → ลองแก้ทีละจุด หากต้องการทบทวน เปิด [ตอนก่อนหน้า](../../01-hello-go/EP01.md)

## แนวคิดและคำใหม่

นึกถึงแบบฟอร์มที่มีช่องข้อความ โครงโปรแกรมช่วยให้เครื่องมือรู้ว่าจะเริ่มตรงไหน ส่วนข้อความในเครื่องหมายคำพูดคือสิ่งที่เราเลือกให้แสดง บทนี้จะเริ่มจากเปลี่ยนข้อความหนึ่งจุด แล้วสังเกตผลที่เกิดขึ้น

**package** คือกลุ่มไฟล์ที่ทำงานร่วมกันในโฟลเดอร์เดียวกัน; **import** ระบุ package ที่จะใช้; **ฟังก์ชัน** คือชุดคำสั่งที่มีชื่อ; **string** คือค่าข้อความ

## ลองคาดเดาผลลัพธ์ก่อนรัน

เปลี่ยนข้อความในเครื่องหมายคำพูด แล้วจะต้องเปลี่ยนชื่อ main ตามด้วยหรือไม่?

จดผลที่คาดเดาและเหตุผลสั้น ๆ ก่อนรัน แล้วเปรียบเทียบกับผลจริง หากต่างกัน ให้ลองอธิบายว่าเกิดจากส่วนใดของโค้ด

## โค้ดตัวอย่าง

### examples/main.go

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, learner!")
}
```

## รันและตรวจผล

เปิด PowerShell แล้วเลือกโฟลเดอร์บทเรียน หากวางหลักสูตรไว้ที่ตำแหน่งอื่น ให้ปรับเส้นทางในคำสั่งให้ตรงกับเครื่องของคุณ:

```powershell
Set-Location -LiteralPath 'C:\Users\kopes\Documents\Codex\2026-09-17\go-youtube-go-iot-edge-gateway\Go\lessons\phase-01\ep02-read-program'
go run ./examples
```

ผลที่คาดหวัง:

```text
Hello, learner!
```

หากผลลัพธ์ไม่ตรงกับที่คาด ให้ตรวจตำแหน่งด้วย `Get-Location` และตรวจว่าได้บันทึกไฟล์แล้ว หากมีข้อผิดพลาด ให้อ่านข้อความแรกก่อนแก้โค้ด

## อธิบายการทำงานของโค้ด

- `package main` ระบุ package ของโปรแกรมที่สั่งรันได้ ส่วน `func main()` คือฟังก์ชันเริ่มต้นหลังการเตรียม package ของโปรแกรม
- `import "fmt"` ทำให้เรียกเครื่องมือแสดงข้อความได้ `fmt` ติดมากับ Go
- `fmt.Println` เรียกฟังก์ชันที่พิมพ์ค่าแล้วขึ้นบรรทัดใหม่ ส่วนเครื่องหมายคำพูดใช้กำหนดขอบเขตข้อความและไม่ปรากฏในผลลัพธ์

**หลักภาษาและแนวทางออกแบบ:** รูปแบบคำสั่งและชนิดข้อมูลเป็นหลักของภาษา Go การแยกโค้ดตามหน้าที่เป็นแนวทางออกแบบให้เข้าใจง่าย ส่วนชื่อโฟลเดอร์และการใช้หนึ่ง module ต่อ EP เป็นทางเลือกในการจัดหลักสูตร

## ฝึกแก้ไขโค้ดด้วยตนเอง

เปิด [วิธีสร้างพื้นที่ฝึก](../../../docs/PRACTICE.md) แล้วสร้างพื้นที่ฝึกสำหรับ EP.2 ด้วย `./scripts/new-practice.ps1 -Episode 2` จากราก Go เพียงครั้งเดียว จากนั้นเปิด `practics/phase-01/ep02-read-program` แก้ไฟล์ใน `examples` แล้วรัน `go run ./examples` จากโฟลเดอร์ EP ที่คัดลอกแล้ว

พื้นที่ฝึกไม่รวมเฉลย และคำสั่งสร้างจะหยุดถ้าโฟลเดอร์มีอยู่แล้ว จึงไม่ทับงานที่เคยทำ

## ข้อผิดพลาดที่พบบ่อย

- เขียน `Println` เป็น `println`: Go แยกตัวใหญ่เล็ก ตรวจตัว P
- ผลยังเหมือนเดิม: ตรวจว่าบันทึกและรันจากโฟลเดอร์ที่กำลังแก้จริง
