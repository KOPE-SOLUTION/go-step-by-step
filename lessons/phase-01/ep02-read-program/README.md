# EP.2 — อ่านโครงสร้างโปรแกรมและเปลี่ยนข้อความ

**เป้าหมาย:** อธิบายส่วนประกอบของโปรแกรมและเปลี่ยนข้อความที่แสดงได้

## 1. อ่านโค้ด

`string` คือข้อความในเครื่องหมายคำพูด `package main` และ `func main()` เป็นโครงของโปรแกรม ส่วน `import "fmt"` ทำให้เรียกคำสั่งแสดงข้อความได้

ไฟล์ [examples/main.go](examples/main.go)

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, learner!")
}
```

## 2. ลองรัน

**ก่อนรัน:** เปลี่ยนข้อความในเครื่องหมายคำพูด แล้วจะต้องเปลี่ยนชื่อ main ตามด้วยหรือไม่?

รันจากโฟลเดอร์ `lessons/phase-01/ep02-read-program`:

```shell
go run ./examples
```

## 3. ฝึกเอง

ใช้ **`practics/main.go` ไฟล์เดิม** เปลี่ยนเนื้อหาทั้งไฟล์เป็นโค้ดจาก [ตัวอย่าง EP นี้](examples/main.go) แล้วทำโจทย์ด้านล่าง

ถ้ายังไม่มีไฟล์ ให้สร้างโฟลเดอร์ `practics` ใน `Go` แล้วสร้าง `main.go` ข้างใน ไม่ต้องมี `examples` หรือ `go.mod` ดู [วิธีสร้างครั้งแรก](../../../docs/PRACTICE.md)

**แก้ `main.go` ในโฟลเดอร์ฝึก** ทีละข้อ:

1. เปลี่ยนข้อความ `Hello, learner!` ใน `fmt.Println(...)` ให้เป็น `Device simulator`
2. ในไฟล์เดิม เปลี่ยนข้อความอีกครั้งเป็น `สวัสดี Go` แล้วสังเกตการแสดงภาษาไทย

บันทึกไฟล์ (Ctrl+S) แล้วรันจาก **`practics`**:

```shell
go run main.go
```

<details>
<summary>อ่านเพิ่มเติมเมื่อสงสัย</summary>

นึกถึงแบบฟอร์มที่มีช่องข้อความ โครงโปรแกรมช่วยให้เครื่องมือรู้ว่าจะเริ่มตรงไหน ส่วนข้อความในเครื่องหมายคำพูดคือสิ่งที่เราเลือกให้แสดง บทนี้จะเริ่มจากเปลี่ยนข้อความหนึ่งจุด แล้วสังเกตผลที่เกิดขึ้น

**package** คือกลุ่มไฟล์ที่ทำงานร่วมกันในโฟลเดอร์เดียวกัน; **import** ระบุ package ที่จะใช้; **ฟังก์ชัน** คือชุดคำสั่งที่มีชื่อ; **string** คือค่าข้อความ

- `package main` ระบุ package ของโปรแกรมที่สั่งรันได้ ส่วน `func main()` คือฟังก์ชันเริ่มต้นหลังการเตรียม package ของโปรแกรม
- `import "fmt"` ทำให้เรียกเครื่องมือแสดงข้อความได้ `fmt` ติดมากับ Go
- `fmt.Println` เรียกฟังก์ชันที่พิมพ์ค่าแล้วขึ้นบรรทัดใหม่ ส่วนเครื่องหมายคำพูดใช้กำหนดขอบเขตข้อความและไม่ปรากฏในผลลัพธ์

**ข้อผิดพลาดที่พบบ่อย**

- เขียน `Println` เป็น `println`: Go แยกตัวใหญ่เล็ก ตรวจตัว P
- ผลยังเหมือนเดิม: ตรวจว่าบันทึกและรันจากโฟลเดอร์ที่กำลังแก้จริง
