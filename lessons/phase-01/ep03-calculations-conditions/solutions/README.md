# เฉลย EP.3

ลองทำ [โจทย์ในบทเรียน](../README.md#ฝึกเอง) ก่อน แต่ละข้อเริ่มจากตัวอย่างตั้งต้นของบทนี้

## ข้อ 1

เปลี่ยนเกณฑ์เตือนเป็นตั้งแต่ `35` C และลองค่า `34.0` โดยคงช่วงข้อมูล 0–100 ไว้

ดู [main.go](01/main.go)

รันจาก `lessons/phase-01/ep03-calculations-conditions/solutions/01` ด้วย `go run .`

```text
34.0 C = 93.2 F [OK]
```


เหตุผล: เกณฑ์เปลี่ยนเป็น 35 ดังนั้น 34 ยังเป็น OK แต่สูตรแปลงหน่วยยังเหมือนเดิม

## ข้อ 2

เขียนเงื่อนไขเดิมด้วย `switch` ที่ไม่มีค่าต่อท้าย และลอง `101.0` ต้องได้ INVALID

ดู [main.go](02/main.go)

รันจาก `lessons/phase-01/ep03-calculations-conditions/solutions/02` ด้วย `go run .`

```text
101.0 C = 213.8 F [INVALID]
```


เหตุผล: switch ตรวจกรณีจากบนลงล่าง ช่วงที่ใช้ไม่ได้ต้องอยู่ก่อนกรณีเตือน
