# EP.3 — คำนวณและตรวจเงื่อนไขของข้อมูล

**เป้าหมาย:** แปลงหน่วยและแยกข้อมูลปกติ ค่าสูง และค่าที่อยู่นอกช่วงจำลองได้

**ก่อนเริ่ม:** EP.2 — ตัวแปรและชนิดข้อมูล

## ทำความเข้าใจ

**ตัวดำเนินการ** คือเครื่องหมายที่ใช้คำนวณหรือเปรียบเทียบ เช่น `+ - * /`, `>=` และ `==` ผลการเปรียบเทียบเป็น bool ส่วน `if` เลือกทำงานเมื่อเงื่อนไขเป็นจริง

เรากำหนดให้ช่วง 0–100 C เป็นค่าที่รับได้ รวมค่า 0 และ 100 ด้วย ภายในช่วงนี้ ถ้าอุณหภูมิตั้งแต่ 30 C ขึ้นไปให้แสดงคำเตือน กฎนี้กำหนดเพื่อฝึก ไม่ใช่มาตรฐานของอุปกรณ์จริง

## ลงมือทำ

1. คำนวณ Fahrenheit จาก Celsius แล้วลอง `27.5` และ `30.0`
2. เพิ่ม `if ... else if` ตามตัวอย่าง ก่อนรันให้คาดเดาผลสำหรับ `-1`, `29.9`, `30` และ `101` โดยเปลี่ยนทีละค่า
3. ทดลอง `fmt.Println(9 / 5)` กับ `fmt.Println(9.0 / 5.0)` แล้วอธิบายว่าทำไมส่วนทศนิยมต่างกัน ถ้าใช้ตัวแปรชนิด `int` ทั้งสองตัวหารกัน ผลลัพธ์จะไม่มีส่วนทศนิยม หากต้องการผลแบบทศนิยมให้แปลงค่าของทั้งสองตัวเป็น `float64` ก่อนหาร

### ตัวอย่างเมื่อทำครบ

ไฟล์ [main.go](main.go):

```go
package main

import "fmt"

func main() {
	celsius := 30.0
	fahrenheit := celsius*9.0/5.0 + 32
	status := "OK"

	if celsius < 0 || celsius > 100 {
		status = "INVALID"
	} else if celsius >= 30 {
		status = "WARNING"
	}

	fmt.Printf("%.1f C = %.1f F [%s]\n", celsius, fahrenheit, status)
}
```

### รันและตรวจผล

งานฝึก: เปิด terminal ที่ `practics` แล้วรัน:

```shell
go run main.go
```

ถ้ารันตัวอย่างที่ให้มาโดยตรง ให้เปิด terminal ที่ `lessons/phase-01/ep03-calculations-conditions` แล้วใช้ `go run .` ใช้ได้ทั้ง terminal ใน VS Code, PowerShell และ cmd

ก่อนเปิดผลลัพธ์ ลองคาดเดาว่า `30.0` C จะได้สถานะ `OK`, `WARNING` หรือ `INVALID`

<details>
<summary>อธิบายโค้ดและจุดที่ควรตรวจสอบ</summary>

- `||` หมายถึงอย่างน้อยหนึ่งเงื่อนไขจริง จึงตรวจได้ทั้งต่ำกว่า 0 หรือสูงกว่า 100 ส่วน `&&` ต้องจริงทั้งคู่ และ `!` กลับค่าจริง/เท็จ
- ตรวจค่าที่อยู่นอกช่วง 0–100 ก่อน เพื่อให้ `101` ได้สถานะ `INVALID` หากตรวจเงื่อนไขตั้งแต่ 30 ขึ้นไปก่อน จะได้ `WARNING` ทั้งที่ค่าอยู่นอกช่วง
- เริ่ม `status` เป็น OK แล้วเปลี่ยนเมื่อพบเงื่อนไขอื่น เป็นทางเลือกในการเขียนให้สั้น จะเขียน `else` กำหนด OK ก็ได้
- Go ไม่แปลงตัวแปร int เป็น float64 ให้อัตโนมัติเมื่อคำนวณข้ามชนิด และ `=` คือกำหนดค่า ส่วน `==` คือเปรียบเทียบ
- เมื่อมีหลายกรณี สามารถใช้ `switch { case เงื่อนไข: ...; default: ... }` ได้ แต่ไม่จำเป็นต้องเปลี่ยน if ที่อ่านชัดอยู่แล้ว

**ข้อผิดพลาดที่พบบ่อย:** ถ้าใช้ `>` แทน `>=` ค่า 30 จะไม่เตือน ให้ทดลองค่าต่ำกว่า เท่ากับ และสูงกว่าเกณฑ์ ส่วน `9 / 5` เป็นการหารจำนวนเต็มจึงได้ `1` ถ้าเขียนสูตรเป็น `celsius * (9 / 5) + 32` จะคำนวณในวงเล็บได้ `1` ก่อน ทำให้แปลงหน่วยผิด

</details>

## ฝึกเอง

ฝึกใน `practics/main.go` ไฟล์เดิม ก่อนทำแต่ละข้อให้ใส่โค้ดตัวอย่างเต็มของบทนี้ แล้วแก้ตามโจทย์ หากต้องการเก็บคำตอบข้อก่อนหน้า ให้คัดลอกเป็นไฟล์ `.txt` ก่อน

1. เปลี่ยนเกณฑ์เตือนเป็นตั้งแต่ `35` C และลองค่า `34.0` โดยคงช่วงข้อมูล 0–100 ไว้
2. เปลี่ยนชุด `if ... else if` เป็น `switch { ... }` โดยใส่เงื่อนไขในแต่ละ `case` แล้วลอง `celsius := 101.0` ต้องได้สถานะ `INVALID`

ทำก่อนแล้วค่อยดู [เฉลยพร้อมเหตุผล](solutions/README.md)

**ลองอธิบาย:** ถ้าตรวจ `celsius >= 30` ก่อนตรวจค่าที่อยู่นอกช่วง 0–100 ในชุด `if ... else if` เดียวกัน ค่า `101` จะได้สถานะอะไร?

<details>
<summary>แนวคำตอบ</summary>

`WARNING` เพราะเข้าเงื่อนไขแรกแล้วจึงไม่ตรวจเงื่อนไขถัดไปในชุด `if ... else if` เดียวกัน

</details>
