# EP.3 — คำนวณและตรวจเงื่อนไขของข้อมูล

**เป้าหมาย:** แปลงหน่วยและแยกข้อมูลปกติ ค่าสูง และค่าที่อยู่นอกช่วงจำลองได้

**ก่อนเริ่ม:** EP.2 — ตัวแปรและชนิดข้อมูล

## ทำความเข้าใจ

**ตัวดำเนินการ** คือเครื่องหมายที่ใช้คำนวณหรือเปรียบเทียบ เช่น `+ - * /`, `>=` และ `==` ผลการเปรียบเทียบเป็น bool ส่วน `if` เลือกทำงานเมื่อเงื่อนไขเป็นจริง

เราจะใช้กฎของตัวอย่างว่า 0–100 C เป็นช่วงที่รับได้ และตั้งแต่ 30 C เป็นคำเตือน กฎนี้กำหนดเพื่อฝึก ไม่ใช่มาตรฐานของอุปกรณ์จริง

## ลงมือทำ

1. คำนวณ Fahrenheit จาก Celsius แล้วลอง `27.5` และ `30.0`
2. เพิ่ม `if ... else if` ตามตัวอย่าง ก่อนรันให้คาดเดาผลสำหรับ `-1`, `29.9`, `30` และ `101` โดยเปลี่ยนทีละค่า
3. ทดลอง `fmt.Println(9 / 5)` กับ `fmt.Println(9.0 / 5.0)` แล้วอธิบายว่าทำไมส่วนทศนิยมต่างกัน ถ้าค่ามาจากตัวแปร int ให้แปลงด้วย `float64(count)` ก่อนนำไปหารแบบทศนิยม

### ตัวอย่างเมื่อทำครบ

ไฟล์ [main.go](main.go):

```go
package main

import "fmt"

func main() {
	celsius := 30.0
	fahrenheit := celsius*9.0/5.0 + 32
	status := "OK"

	if celsius < 0 || celsius > 100 {
		status = "INVALID"
	} else if celsius >= 30 {
		status = "WARNING"
	}

	fmt.Printf("%.1f C = %.1f F [%s]\n", celsius, fahrenheit, status)
}
```

### รันและตรวจผล

งานฝึก: เปิด terminal ที่ `practics` แล้วรัน:

```shell
go run main.go
```

<details>
<summary>อธิบายโค้ดและวิธีตรวจเมื่อผลไม่ตรง</summary>

- `||` หมายถึงอย่างน้อยหนึ่งเงื่อนไขจริง จึงตรวจได้ทั้งต่ำกว่า 0 หรือสูงกว่า 100 ส่วน `&&` ต้องจริงทั้งคู่ และ `!` กลับค่าจริง/เท็จ
- ตรวจช่วงที่ใช้ไม่ได้ก่อน เพื่อให้ `101` เป็น INVALID ไม่ตกลงไปเป็น WARNING
- เริ่ม `status` เป็น OK แล้วเปลี่ยนเมื่อพบเงื่อนไขอื่น เป็นทางเลือกในการเขียนให้สั้น จะเขียน `else` กำหนด OK ก็ได้
- Go ไม่แปลงตัวแปร int เป็น float64 ให้อัตโนมัติเมื่อคำนวณข้ามชนิด และ `=` คือกำหนดค่า ส่วน `==` คือเปรียบเทียบ
- เมื่อมีหลายกรณี สามารถใช้ `switch { case เงื่อนไข: ...; default: ... }` ได้ แต่ไม่จำเป็นต้องเปลี่ยน if ที่อ่านชัดอยู่แล้ว

**ลองตรวจเมื่อผิด:** ถ้าใช้ `>` แทน `>=` ค่า 30 จะไม่เตือน ให้ทดลองค่าต่ำกว่า เท่ากับ และสูงกว่าเกณฑ์ ส่วน `9 / 5` เป็นการหารค่าจำนวนเต็มจึงได้ 1 ต้องระวังถ้าวางส่วนนี้ในวงเล็บของสูตร

</details>

## ฝึกเอง

ใช้ `practics/main.go` เดิม เริ่มแต่ละข้อจากตัวอย่างของบทนี้ ไม่ต้องสร้างโฟลเดอร์แยกโจทย์ หากต้องการเก็บงานเดิมให้คัดลอกเป็นไฟล์ .txt ก่อนเปลี่ยนโค้ด

1. เปลี่ยนเกณฑ์เตือนเป็นตั้งแต่ `35` C และลองค่า `34.0` โดยคงช่วงข้อมูล 0–100 ไว้
2. เขียนเงื่อนไขเดิมด้วย `switch` ที่ไม่มีค่าต่อท้าย และลอง `101.0` ต้องได้ INVALID

ทำก่อนแล้วค่อยดู [เฉลยพร้อมเหตุผล](solutions/README.md)

**ลองอธิบาย:** ถ้าตรวจ >= 30 ก่อนช่วงข้อมูลที่ใช้ไม่ได้ ค่า 101 จะถูกจัดเป็นอะไร?
