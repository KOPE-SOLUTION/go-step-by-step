# EP.3 — คำนวณและตรวจเงื่อนไขของข้อมูล

**เป้าหมาย:** แปลงหน่วยและแยกข้อมูลปกติ ค่าสูง และค่าที่อยู่นอกช่วงจำลองได้

**ก่อนเริ่ม:** EP.2 — ตัวแปรและชนิดข้อมูล

## ทำความเข้าใจ

**ตัวดำเนินการ** คือเครื่องหมายที่ใช้คำนวณหรือเปรียบเทียบ เช่น `+ - * /`, `>=` และ `==` ผลการเปรียบเทียบเป็น bool เราจะลองพิมพ์ผลนี้ก่อนใช้เลือกการทำงาน

กฎจำลองของบทนี้รับอุณหภูมิช่วง 0–100 C รวมค่า 0 และ 100 ด้วย ภายในช่วงนี้ ค่าตั้งแต่ 30 C ขึ้นไปให้แสดงคำเตือน กฎนี้กำหนดเพื่อฝึก ไม่ใช่มาตรฐานของอุปกรณ์จริง

## ลงมือทำทีละขั้น

ใช้ `practics/main.go` ไฟล์เดิม เริ่มด้วยโค้ดขั้นที่ 1 แล้วแก้ต่อทีละขั้น หากต้องการเก็บงานเดิม ให้คัดลอกเป็น `.txt` ก่อนเปลี่ยนโค้ด บันทึกและรันจาก terminal ที่ `practics` ทุกครั้ง:

```shell
go run main.go
```

### 1. คำนวณ Fahrenheit จาก Celsius

เริ่ม `main.go` ของบทนี้ด้วยสูตร Celsius คูณ 9 หาร 5 แล้วบวก 32:

```go
package main

import "fmt"

func main() {
	celsius := 30.0
	fahrenheit := celsius*9.0/5.0 + 32

	fmt.Printf("%.1f C = %.1f F\n", celsius, fahrenheit)
}
```

`*` คือคูณ `/` คือหาร และ `+` คือบวก การคูณและหารทำก่อนการบวก สูตรนี้จึงคำนวณส่วน `celsius*9.0/5.0` ก่อนบวก 32

**ลองคิดก่อนรัน:** 30 C จะเท่ากับกี่ F?

<details>
<summary>รันแล้วค่อยเปิดตรวจผล</summary>

```text
30.0 C = 86.0 F
```

</details>

ลองเปลี่ยนเป็น `celsius := 27.5` แล้วคาดเดาก่อนรัน จากนั้นเปลี่ยนกลับเป็น 30.0 ก่อนทำขั้นถัดไป

<details>
<summary>ผลเมื่อลอง 27.5 C</summary>

```text
27.5 C = 81.5 F
```

</details>

### 2. ทดลองการหารที่ทำให้สูตรผิด

เพิ่มสามบรรทัดนี้ก่อน `Printf` แสดงรายงาน โดยยังเก็บสูตรคำนวณ `fahrenheit` เดิมไว้:

```go
	fmt.Println(9 / 5)
	fmt.Println(9.0 / 5.0)
	fmt.Println(celsius*(9/5) + 32)
```

`9 / 5` หารจำนวนเต็ม ส่วน `9.0 / 5.0` คำนวณแบบทศนิยม วงเล็บในบรรทัดที่สามบังคับให้หาค่า `9 / 5` ก่อนนำไปคูณอุณหภูมิ

**ลองคิดก่อนรัน:** สองบรรทัดแรกได้ค่าเท่ากันหรือไม่? สูตรบรรทัดที่สามยังได้ 86 หรือไม่?

<details>
<summary>รันแล้วค่อยเปิดตรวจผล</summary>

```text
1
1.8
62
30.0 C = 86.0 F
```

`9 / 5` ได้ 1 จึงทำให้สูตรที่ใส่วงเล็บคำนวณเป็น 30 คูณ 1 บวก 32 ได้ 62 ส่วนสูตรเดิมที่เก็บใน `fahrenheit` ยังได้ 86

</details>

เมื่อทดลองเสร็จ ให้เอา `Println` สามบรรทัดที่เพิ่งเพิ่มออก ก่อนทำขั้นถัดไป

### 3. ลองเปรียบเทียบค่าก่อนเขียน if

`>` หมายถึงมากกว่า `>=` หมายถึงมากกว่าหรือเท่ากับ และ `==` หมายถึงเท่ากัน ผลที่ได้เป็น `true` หรือ `false` ส่วน `=` ใช้กำหนดค่าให้ตัวแปร

เพิ่มสามบรรทัดนี้หลังบรรทัดคำนวณ `fahrenheit` ก่อน `Printf`:

```go
	fmt.Println(celsius > 30)
	fmt.Println(celsius >= 30)
	fmt.Println(celsius == 30)
```

**ลองคิดก่อนรัน:** เมื่อ celsius เป็น 30 แต่ละเงื่อนไขจะเป็นจริงหรือเท็จ?

<details>
<summary>รันแล้วค่อยเปิดตรวจผล</summary>

```text
false
true
true
30.0 C = 86.0 F
```

</details>

### 4. ใช้ if และ else เลือกสถานะ

`if` ทำคำสั่งเมื่อเงื่อนไขเป็นจริง ส่วน `else` ทำเมื่อเงื่อนไขนั้นเป็นเท็จ แทน `main` ทั้งฟังก์ชันด้วยโค้ดนี้ โดยเก็บ `package` และ `import` ไว้:

```go
func main() {
	celsius := 30.0
	fahrenheit := celsius*9.0/5.0 + 32
	status := "OK"

	if celsius >= 30 {
		status = "WARNING"
	} else {
		status = "OK"
	}

	fmt.Printf("%.1f C = %.1f F [%s]\n", celsius, fahrenheit, status)
}
```

ขั้นนี้เลือกได้สองสถานะตามเกณฑ์ 30 โดยยังไม่ได้ปฏิเสธค่าที่อยู่นอกช่วง 0–100 คำสั่งพิมพ์ผลเปรียบเทียบจากขั้นที่ 3 ไม่อยู่ในเวอร์ชันนี้แล้ว

**ลองคิดก่อนรัน:** ค่า 30 จะเข้าฝั่ง `if` หรือ `else`? ถ้าเปลี่ยนเป็น 29.9 จะต่างกันอย่างไร?

<details>
<summary>รันแล้วค่อยเปิดตรวจผล</summary>

เมื่อใช้ `celsius := 30.0`:

```text
30.0 C = 86.0 F [WARNING]
```

เมื่อทดลองเปลี่ยนเป็น `celsius := 29.9`:

```text
29.9 C = 85.8 F [OK]
```

</details>

**ลองให้รันได้แต่ตัดสินใจผิด:** ตั้ง `celsius := 30.0` แล้วเปลี่ยน `>= 30` เป็น `> 30` จากนั้นรันอีกครั้ง

<details>
<summary>ตรวจผลและแก้เงื่อนไข</summary>

โปรแกรมยังรันได้ แต่แสดง `OK` ซึ่งผิดกฎ “ตั้งแต่ 30 ขึ้นไป” เพราะ `>` ไม่รวมค่าที่เท่ากับ 30 แก้กลับเป็น `>=` แล้วรันให้ได้ `WARNING` ก่อนทำต่อ นี่คือข้อผิดพลาดของเงื่อนไขที่ compiler ตรวจให้ไม่ได้

</details>

### 5. ตรวจค่าที่อยู่นอกช่วงก่อนตรวจคำเตือน

`<` หมายถึงน้อยกว่า ส่วน `||` หมายถึง “หรือ” โดยเงื่อนไขอย่างน้อยหนึ่งด้านเป็นจริงก็ได้ `else if` ใช้ตรวจเงื่อนไขต่อเมื่อเงื่อนไขก่อนหน้าเป็นเท็จ

แทน `main` ทั้งฟังก์ชันด้วยเวอร์ชันนี้:

```go
func main() {
	celsius := 30.0
	fahrenheit := celsius*9.0/5.0 + 32
	status := "OK"

	if celsius < 0 || celsius > 100 {
		status = "INVALID"
	} else if celsius >= 30 {
		status = "WARNING"
	}

	fmt.Printf("%.1f C = %.1f F [%s]\n", celsius, fahrenheit, status)
}
```

ตรวจนอกช่วงก่อน เพื่อให้ค่า 101 เป็น `INVALID` แทนที่จะเข้าเงื่อนไขเตือนทันที เมื่อไม่เข้าเงื่อนไขใด `status` จะคงค่าเริ่มต้น `"OK"` จึงไม่ต้องมี `else` กำหนด OK ซ้ำ เป็นทางเลือกในการจัดโค้ดให้สั้นลง

**ลองคิดก่อนรัน:** ลองค่า -1.0, 0.0, 29.9, 30.0, 100.0 และ 101.0 ทีละค่า แต่ละค่าควรได้สถานะอะไร? แล้วเปลี่ยนกลับเป็น 30.0 ก่อนทำขั้นถัดไป

<details>
<summary>รันแล้วค่อยเปิดตรวจผล</summary>

| Celsius | Fahrenheit | สถานะ |
|---|---|---|
| -1.0 | 30.2 | INVALID |
| 0.0 | 32.0 | OK |
| 29.9 | 85.8 | OK |
| 30.0 | 86.0 | WARNING |
| 100.0 | 212.0 | WARNING |
| 101.0 | 213.8 | INVALID |

ผลเมื่อใช้ค่าเริ่มต้น 30.0:

```text
30.0 C = 86.0 F [WARNING]
```

</details>

### 6. ลองเขียนกฎเดิมด้วย switch

`switch` แบบไม่มีค่าหลังคำว่า switch เลือก `case` แรกที่เงื่อนไขเป็นจริง ส่วน `default` ใช้เมื่อไม่มี case ใดตรง เป็นอีกทางเลือกสำหรับกฎเดียวกับขั้นที่ 5

แทนเฉพาะบล็อก `if ... else if` ด้วยโค้ดนี้ เก็บตัวแปร สูตร และ `Printf` ไว้เหมือนเดิม:

```go
	switch {
	case celsius < 0 || celsius > 100:
		status = "INVALID"
	case celsius >= 30:
		status = "WARNING"
	default:
		status = "OK"
	}
```

Go จบการเลือกหลังทำ case ที่ตรง จึงไม่ต้องเติม `break` ในตัวอย่างนี้ ลำดับยังสำคัญ: ตรวจนอกช่วงก่อน แล้วจึงตรวจคำเตือน

**ลองคิดก่อนรัน:** ค่า 30.0 ควรได้ผลเหมือน if หรือไม่? แล้วลองชุดค่าในตารางขั้นที่ 5 กับ switch เพื่อเทียบสถานะ

<details>
<summary>รันแล้วค่อยเปิดตรวจผล</summary>

```text
30.0 C = 86.0 F [WARNING]
```

</details>

### ตัวอย่างเมื่อทำครบ

<details>
<summary>เปิดเทียบโค้ดฉบับเต็มหลังทำครบทุกขั้น</summary>

ไฟล์ [main.go](main.go) เก็บเวอร์ชัน `if` จากขั้นที่ 5 ส่วน `switch` ในขั้นที่ 6 ใช้แทนบล็อกเงื่อนไขนี้ได้ โดยให้ผลตามกฎเดียวกัน:

```go
package main

import "fmt"

func main() {
	celsius := 30.0
	fahrenheit := celsius*9.0/5.0 + 32
	status := "OK"

	if celsius < 0 || celsius > 100 {
		status = "INVALID"
	} else if celsius >= 30 {
		status = "WARNING"
	}

	fmt.Printf("%.1f C = %.1f F [%s]\n", celsius, fahrenheit, status)
}
```

</details>

<details>
<summary>วิธีรันตัวอย่างต้นฉบับและจุดที่ควรตรวจ</summary>

เปิด terminal ที่ `lessons/phase-01/ep03-calculations-conditions` แล้วรัน `go run .` จะได้ `30.0 C = 86.0 F [WARNING]` ส่วนไฟล์ที่เขียนเองยังรัน `go run main.go` จาก `practics`

- ถ้าสถานะผิด ให้ตรวจลำดับเงื่อนไข แล้วลองค่าต่ำกว่า เท่ากับ และสูงกว่าเกณฑ์
- ถ้าแปลงหน่วยผิด ให้ตรวจวงเล็บและชนิดตัวเลข โดยเฉพาะ `9 / 5` ซึ่งได้ `1`
- `if` และ `switch` ในบทนี้ให้ผลตามกฎเดียวกัน เลือกใช้รูปแบบที่อ่านเข้าใจ ไม่ต้องเขียนทั้งสองชุดซ้ำในโปรแกรมเดียว

</details>
