## คำถามทบทวน

struct ต่างจาก map[string]float64 อย่างไรในตัวอย่างการวัด?

struct กำหนดช่องและชนิดของแต่ละช่องไว้ เช่น string กับ float64; map แบบนี้ใช้ key ยืดหยุ่นแต่ value ทุกตัวเป็น float64
