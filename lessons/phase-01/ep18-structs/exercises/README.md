# แบบฝึกหัด EP.18 — รวมข้อมูลหนึ่งรายการด้วย struct

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep18-structs` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

สร้าง Reading ที่ DeviceID เป็น sensor-02 โดยไม่ใส่ Celsius แล้วพิมพ์ทั้งสองช่อง

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

คัดลอก Reading ค่า 25 แล้วแก้ Celsius ของสำเนาเป็น 30 พิมพ์ Celsius ของทั้งสอง

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
