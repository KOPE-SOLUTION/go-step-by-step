# แบบฝึกหัด EP.27 — โปรเจกต์สรุป ตอนที่ 3 — รายงานหลายรายการ

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep27-project-report` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เพิ่ม sensor-05 ค่า 31 ต่อท้ายและดูรายงานครบห้าบรรทัด

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
