# แบบฝึกหัด EP.28 — โปรเจกต์เล็ก 4 — ตรวจผลและทบทวน Phase 1

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep28-project-tests` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เพิ่มกรณีรายงานมีชื่อว่างหนึ่งรายการ ต้องได้ ": ERROR: device ID is empty"

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples` และ `go test ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง

## ข้อ 2

เพิ่มกรณีข้อมูลผิดติดกันสองรายการ แล้วมีรายการดีหนึ่งรายการ ต้องได้ครบสามบรรทัด

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples` และ `go test ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง
