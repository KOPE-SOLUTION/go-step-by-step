# แบบฝึกหัด EP.14 — ตรวจสอบและจัดการ error

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep14-errors` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

ส่ง -1 และตรวจว่ามีเพียงบรรทัด ERROR

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

ส่ง 100 แล้วตรวจว่าขอบเขตบนผ่าน

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
