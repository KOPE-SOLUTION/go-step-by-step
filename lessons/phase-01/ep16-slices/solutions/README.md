## คำถามทบทวน

กำหนด b := a เมื่อ a เป็น slice ทำให้สมาชิกเป็นสำเนาอิสระหรือไม่?

ไม่ใช่ มีการคัดลอกตัว slice แต่ยังอ้างถึง array เดิม การแก้สมาชิกจึงอาจเห็นร่วมกัน; append อาจเปลี่ยน array ที่อ้างถึงได้
