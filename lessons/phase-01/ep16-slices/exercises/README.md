# แบบฝึกหัด EP.16 — ใช้ slice กับรายการที่เพิ่มได้

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep16-slices` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เริ่มด้วย []string{} แล้ว append ชื่อ sensor-01 และพิมพ์รายการกับจำนวน

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

สร้าง values := []int{1, 2, 3} และ first := values[:2] แก้ first[0] = 9 แล้วพิมพ์ values

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
