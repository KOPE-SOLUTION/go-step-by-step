# EP.22 — อ่าน go.mod และเข้าใจขอบเขต module

Phase 1 — Go Basic • [สารบัญ](../../../docs/playlist-01-go-basic/README.md)

## เป้าหมายและสิ่งที่ควรรู้ก่อน

แยก module, package และโฟลเดอร์ที่ใช้รันคำสั่งได้ ก่อนเริ่มควรทำ EP.21 ได้และอธิบายตัวอย่างด้วยคำของตนเอง ไม่จำเป็นต้องจำโค้ดจากความจำ

บทนี้มีหนึ่งเรื่องหลัก อ่านเป็นช่วงได้: ทำความเข้าใจ → คาดเดา → รัน → เปลี่ยนทีละจุด ถ้าต้องกลับไปทบทวนใช้ [ตอนก่อนหน้า](../ep21-packages/README.md)

## แนวคิดและคำใหม่

module เหมือนแฟ้มใหญ่ที่บอกชื่อชุดโค้ด ภายในมี package ได้หลายอัน บทนี้ดูแฟ้มที่เตรียมไว้ก่อน ยังไม่เพิ่มไลบรารีภายนอก

go.mod คือไฟล์ประกาศชื่อ module และ Go version ขั้นต่ำ; module path เป็นคำนำหน้าของ import ภายในชุดนี้; standard library คือ package ที่มากับ Go เช่น fmt; dependency คือโค้ดอีกชุดที่โปรแกรมต้องใช้

## หยุดคาดเดาก่อนเปิดผล

import ที่เริ่ม example.com ในบทนี้ต้องต่ออินเทอร์เน็ตหรือไม่?

จดคำตอบสั้น ๆ ก่อนรัน ผิดได้ เก็บเหตุผลที่คิดไว้เทียบกับสิ่งที่เกิดขึ้น

## ตัวอย่างเล็กที่รันได้

### examples/main.go

```go
package main

import (
	"fmt"

	"example.com/go-course/basic/ep22/sensor"
)

func main() {
	fmt.Println(sensor.IsWarning(30))
}
```

### sensor/reading.go

```go
package sensor

func IsWarning(celsius float64) bool {
	return celsius >= 30
}
```

## ทำไมโค้ดจึงทำงานแบบนี้

- go.mod กำหนด module example.com/go-course/basic/ep22 จึง import package ย่อยด้วยชื่อนี้ต่อ /sensor
- go 1.22.0 คือเวอร์ชันขั้นต่ำที่ module ประกาศ ไม่ใช่คำสั่งติดตั้ง; ตัวอย่างตรวจด้วย Go ที่มีในเครื่อง
- เราเลือกหนึ่ง module ต่อ EP เพื่อรันและลองแต่ละบทแยกกัน เป็นทางเลือกสำหรับหลักสูตร ไม่ใช่กฎว่าทุกแอปต้องแยกแบบนี้

**แยกประเภท:** syntax และชนิดข้อมูลเป็นหลักของภาษา; การแยกหน้าที่ให้ส่วนเล็กอ่านง่ายเป็นแนวทางออกแบบ; ชื่อโฟลเดอร์และการใช้หนึ่ง module ต่อ EP เป็นทางเลือกของหลักสูตร เกณฑ์อุณหภูมิที่พบเป็นข้อกำหนดจำลอง

## ลองแก้ในพื้นที่ฝึก

เปิด [วิธีสร้างพื้นที่ฝึก](../../../docs/PRACTICE.md) แล้วสร้าง EP.22 ด้วย `./scripts/new-practice.ps1 -Episode 22` จากราก Go เพียงครั้งเดียว จากนั้นเปิด `practics/phase-01/ep22-modules` แก้ไฟล์ใน `examples` แล้วรัน `go run ./examples` จากโฟลเดอร์ EP ที่คัดลอกแล้ว โฟลเดอร์ sensor ต้องอยู่ด้วย สคริปต์คัดลอกให้แล้ว

พื้นที่ฝึกไม่รวมเฉลย และคำสั่งสร้างจะหยุดถ้าโฟลเดอร์มีอยู่แล้ว จึงไม่ทับงานที่เคยทำ

## ข้อผิดพลาดที่พบบ่อย

- รัน go run ./examples จาก Go/ ซึ่งไม่มี go.mod: cd เข้าโฟลเดอร์ EP ก่อน
- แก้ module path แล้วไม่แก้ import ภายใน: ชื่อสองฝั่งต้องตรงกัน; ไม่ต้องใช้ go get เพื่อแก้การสะกด path ในบทนี้
