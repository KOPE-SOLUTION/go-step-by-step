# แบบฝึกหัด EP.22 — อ่าน go.mod และเข้าใจขอบเขต module

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep22-modules` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

รัน Get-Content go.mod และ go list ./... ในพื้นที่ฝึก แล้วเขียนอธิบายว่าอันใดคือ module อันใดคือ package จากนั้นรันด้วยค่า 25

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง

## ข้อ 2

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง
