# แบบฝึกหัด EP.23 — เขียน unit test แรก

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep23-first-test` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เพิ่ม test กรณี 29.9 ต้อง false แล้วรัน go test ในพื้นที่ฝึก

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples` และ `go test ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง
