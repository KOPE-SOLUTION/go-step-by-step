# เฉลย EP.13

ลองทำ [โจทย์ในบทเรียน](../README.md#ฝึกเอง) ก่อน แต่ละข้อเริ่มจากตัวอย่างตั้งต้นของบทนี้

## ข้อ 1

เพิ่มกรณีทดสอบใน `main_test.go` โดยใช้เกณฑ์ 0 กับค่า -0.1 และ 0 แล้วกำหนดผลที่ต้องการตามกฎเดิม ไม่ต้องแก้ `main.go`

ดู [main.go](01/main.go) และ [main_test.go](01/main_test.go)

รันจาก `lessons/phase-01/ep13-unit-tests/solutions/01` ด้วย `go run .` และ `go test -v .`

```text
29.9 C: OK
30.0 C: WARNING
```

เหตุผล: ใช้เกณฑ์ใหม่เพื่อตรวจว่า `status` เปรียบเทียบกับค่าที่ผู้เรียกส่งมา โดยยังใช้กฎเดิมว่าค่าตั้งแต่เกณฑ์ขึ้นไปต้องเตือน

## ข้อ 2

สมมติเปลี่ยนกฎให้เตือนเฉพาะค่าที่มากกว่าเกณฑ์ เริ่มจากแก้ผลที่ต้องการของ test กรณี `equal` เป็น `OK` แล้วรันให้เห็นว่าไม่ผ่าน จากนั้นแก้ `status` ให้ตรงกฎใหม่และรัน test ซ้ำ

ดู [main.go](02/main.go) และ [main_test.go](02/main_test.go)

รันจาก `lessons/phase-01/ep13-unit-tests/solutions/02` ด้วย `go run .` และ `go test -v .`

```text
29.9 C: OK
30.0 C: OK
```

เหตุผล: เมื่อกฎเปลี่ยน จึงแก้ผลที่ต้องการใน test ก่อน หลังเห็นว่า test ไม่ผ่าน จึงเปลี่ยนตัวเปรียบเทียบใน `status` จาก `>=` เป็น `>` ให้ตรงกฎใหม่
