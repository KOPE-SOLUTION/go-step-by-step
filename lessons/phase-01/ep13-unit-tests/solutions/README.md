# เฉลย EP.13

ลองทำ [โจทย์ในบทเรียน](../README.md#ฝึกเอง) ก่อน แต่ละข้อเริ่มจากตัวอย่างตั้งต้นของบทนี้

## ข้อ 1

เพิ่ม test เกณฑ์ 0 กับค่า -0.1 และ 0 เพื่อตรวจว่าฟังก์ชันเปรียบเทียบตามเกณฑ์ที่ส่งมาได้ โปรแกรมหลักไม่ต้องเปลี่ยน

ดู [main.go](01/main.go) และ [main_test.go](01/main_test.go)

รันจาก `lessons/phase-01/ep13-unit-tests/solutions/01` ด้วย `go run .` และ `go test -v .`

```text
29.9 C: OK
30.0 C: WARNING
```


เหตุผล: เพิ่มกรณี input ให้ครอบคลุมเกณฑ์ที่ต่างออกไป โดยใช้ผลที่ต้องการตามกฎเดิม

## ข้อ 2

สมมติเปลี่ยนกฎเป็นเกินเกณฑ์เท่านั้นจึงเตือน ปรับ test equal ให้คาดว่า OK ก่อน รันให้ล้มเหลว แล้วปรับ status ให้ตรงกฎใหม่

ดู [main.go](02/main.go) และ [main_test.go](02/main_test.go)

รันจาก `lessons/phase-01/ep13-unit-tests/solutions/02` ด้วย `go run .` และ `go test -v .`

```text
29.9 C: OK
30.0 C: OK
```


เหตุผล: ข้อกำหนดเปลี่ยน จึงเปลี่ยนผลที่คาดก่อน เมื่อเห็น test ล้มเหลวจึงแก้ > ให้ตรงข้อกำหนดใหม่
