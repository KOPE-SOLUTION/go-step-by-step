# แบบฝึกหัด EP.4 — อ่านข้อผิดพลาดจากการสะกดชื่อ

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep04-read-errors` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

ทำให้ P เป็น p ในไฟล์ฝึก เก็บ error แล้วแก้กลับให้พิมพ์ Check complete

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

ลบ import fmt ในไฟล์ฝึก ทดลองอ่าน error แล้วคืน import พร้อมเปลี่ยนข้อความเป็น Fixed

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
