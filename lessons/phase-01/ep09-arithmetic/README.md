# EP.9 — คำนวณและแปลงชนิดตัวเลข

**เป้าหมาย:** คำนวณค่าเฉลี่ยโดยรู้ว่าการหารจำนวนเต็มต่างจากทศนิยม

## 1. อ่านโค้ด

การหารจำนวนเต็มจะตัดเศษทิ้ง ใช้ `float64(...)` แปลงชนิดก่อนหารเมื่อต้องการทศนิยม ส่วน `const` ประกาศค่าคงที่

ไฟล์ [examples/main.go](examples/main.go)

```go
package main

import "fmt"

func main() {
	const count = 2
	total := 5
	fmt.Println(total / count)
	average := float64(total) / count
	fmt.Printf("%.1f\n", average)
}
```

## 2. ลองรัน

**ก่อนรัน:** float64(total / count) จะยังได้ 2.5 หรือไม่?

รันจากโฟลเดอร์ `lessons/phase-01/ep09-arithmetic`:

```shell
go run ./examples
```

<summary>ดูผลที่คาดหวังหลังลองรัน</summary>

```text

2.5
```

แปลงชนิดก่อนหาร เพราะการแปลงผลที่หารเป็นจำนวนเต็มไปแล้วจะไม่ทำให้เศษกลับมา

</details>

## 3. ฝึกเอง

ทำ [แบบฝึกหัด 2 ข้อ](exercises/README.md) ใน [practics](../../../docs/PRACTICE.md) แล้วลองตอบ: ทำไมต้องแปลงก่อนหารเมื่ออยากรักษาส่วนเศษ?

<details>
<summary>อ่านเพิ่มเติมเมื่อสงสัย</summary>

ถ้าแบ่งของ 5 ชิ้นให้ 2 กลุ่มโดยนับเฉพาะชิ้นเต็ม จะได้กลุ่มละ 2 แต่การวัดอุณหภูมิต้องการส่วนเศษ จึงต้องเลือกชนิดก่อนหาร ไม่ใช่ค่อยแปลงหลังเศษหายไปแล้ว

`+ - * /` คือบวก ลบ คูณ หาร; **conversion** คือแปลงชนิดอย่างชัดเจน เช่น float64(total); **const** คือชื่อค่าคงที่ซึ่งกำหนดใหม่ไม่ได้

- total เป็น int การหารในบรรทัดแรกจึงเป็นการหารจำนวนเต็ม ตัดส่วนเศษเข้าหาศูนย์
- float64(total) แปลงก่อนหารจึงรักษาผลเป็นทศนิยม
- count เป็นค่าคงที่ไม่มีชนิดระบุในตัวอย่างนี้ จึงใช้กับการหารทั้งสองแบบได้

**ข้อผิดพลาดที่พบบ่อย**

- แปลงหลังหารจำนวนเต็ม: เศษหายไปแล้ว
- หารด้วยศูนย์: เป็นกรณีที่ต้องกันไว้เมื่อจำนวนมาจากข้อมูล ไม่ทดลองกับระบบจริง
