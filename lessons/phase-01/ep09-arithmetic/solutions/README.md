# เฉลย EP.9

ลองทำ [แบบฝึกหัด](../exercises/README.md) ด้วยตนเองก่อนอ่านเฉลย โค้ดอาจเขียนต่างจากตัวอย่างได้ หากให้ผลตรงตามโจทย์

คำสั่งด้านล่างรันจากโฟลเดอร์ต้นฉบับ `lessons/phase-01/ep09-arithmetic` ไม่ใช่โฟลเดอร์ practics ซึ่งไม่มีเฉลย

## ข้อ 1

แปลงก่อนหาร

ดู [main.go](01/main.go)

```powershell
go run ./solutions/01
```

ผล:

```text
3.5
```

## ข้อ 2

กำหนด c เป็น float64 ก่อน สูตรนี้จึงคำนวณแบบทศนิยม

ดู [main.go](02/main.go)

```powershell
go run ./solutions/02
```

ผล:

```text
77.0
```

## คำถามทบทวน

ทำไมต้องแปลงก่อนหารเมื่ออยากรักษาส่วนเศษ?

เพราะเมื่อหาร int เสร็จแล้ว ส่วนเศษถูกตัดไป การแปลงทีหลังไม่ทำให้กลับคืน
