## คำถามทบทวน

ทำไมต้องแปลงก่อนหารเมื่ออยากรักษาส่วนเศษ?

เพราะเมื่อหาร int เสร็จแล้ว ส่วนเศษถูกตัดไป การแปลงทีหลังไม่ทำให้กลับคืน
