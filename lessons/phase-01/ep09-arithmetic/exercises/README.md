# แบบฝึกหัด EP.9 — คำนวณและแปลงชนิดตัวเลข

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep09-arithmetic` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

คำนวณเฉลี่ยจากผลรวม 7 และจำนวน 2 ให้ได้ 3.5

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง
