# EP.2 — เก็บข้อมูลด้วยตัวแปรและชนิดข้อมูล

**เป้าหมาย:** เก็บชื่ออุปกรณ์ ค่าการวัด และสถานะ แล้วจัดรูปแบบรายงานได้

**ก่อนเริ่ม:** EP.1 — รันโปรแกรมและอ่าน main ได้

## ทำความเข้าใจ

**ตัวแปร** คือชื่อที่ใช้อ้างถึงค่าซึ่งเปลี่ยนได้ ส่วน **ชนิดข้อมูล** บอกว่าค่านั้นใช้งานแบบไหน เช่น `string` สำหรับข้อความ `int` สำหรับจำนวนเต็ม `float64` สำหรับเลขทศนิยม และ `bool` สำหรับ `true` หรือ `false`

**ค่าคงที่** ประกาศด้วย `const` ใช้กับค่าที่ไม่เปลี่ยน เช่น หน่วยวัด

## ลงมือทำ

1. เริ่มจาก `deviceID` และ `celsius` แล้วพิมพ์ค่าด้วย `Println` ลองเปลี่ยนข้อมูลโดยไม่แก้ข้อความส่วนอื่น
2. เพิ่มตัวแปรตามตัวอย่าง ก่อนรันให้เดาค่าของ `retries`, `label` และ `failed` ที่ยังไม่ได้กำหนดเอง
3. เปลี่ยนเป็น `Printf` เพื่อจัดรูปแบบรายงาน แล้วลองแทน `%.1f` ด้วย `%.2f`

### ตัวอย่างเมื่อทำครบ

ไฟล์ [main.go](main.go):

```go
package main

import "fmt"

func main() {
	const unit = "C"
	var deviceID string = "sensor-01"
	celsius := 27.5
	connected := true
	var retries int
	var label string
	var failed bool
	celsius = 28.25

	fmt.Printf("%s: %.1f %s\n", deviceID, celsius, unit)
	fmt.Printf("connected=%t retries=%d\n", connected, retries)
	fmt.Printf("label=%q failed=%t\n", label, failed)
}
```

### รันและตรวจผล

งานฝึก: เปิด terminal ที่ `practics` แล้วรัน:

```shell
go run main.go
```

ถ้ารันตัวอย่างที่ให้มาโดยตรง ให้เปิด terminal ที่ `lessons/phase-01/ep02-variables-types` แล้วใช้ `go run .` ใช้ได้ทั้ง terminal ใน VS Code, PowerShell และ cmd

ก่อนเปิดผลลัพธ์ ลองคาดเดาว่าข้อมูลแต่ละรายการจะถูกจัดการอย่างไร

<details>
<summary>ผลลัพธ์ที่คาดหวัง</summary>

```text
sensor-01: 28.2 C
connected=true retries=0
label="" failed=false
```

</details>

<details>
<summary>อธิบายโค้ดและวิธีตรวจเมื่อผลไม่ตรง</summary>

- `var deviceID string = ...` บอกชนิดเอง ส่วน `celsius := 27.5` ให้ Go เลือกชนิดจากค่า ในตัวอย่างนี้เป็น `float64` ใช้ `:=` ประกาศตัวแปรภายในฟังก์ชัน
- `celsius = 28.25` เปลี่ยนค่าตัวแปรเดิม จึงใช้ `=` ไม่ประกาศชื่อเดิมซ้ำด้วย `:=`
- ตัวแปรที่ยังไม่กำหนดค่ามี **zero value**: ตัวเลขเป็น `0`, string เป็น `""`, bool เป็น `false`
- `Printf` ใช้ `%s` แทนข้อความ `%d` แทนจำนวนเต็ม `%t` แทน bool `%q` แสดงข้อความพร้อม quote และ `%.1f` แสดงทศนิยมหนึ่งตำแหน่ง `\n` คือขึ้นบรรทัดใหม่ การจัดรูปแบบไม่เปลี่ยนค่าที่เก็บในตัวแปร

**ลองตรวจเมื่อผิด:** ตัวแปรที่ประกาศแล้วไม่ใช้ทำให้ compile ไม่ผ่าน ลองอ่านชื่อใน error แล้วใช้หรือนำประกาศที่ไม่จำเป็นออก ส่วน `%d` ใช้กับ float64 ไม่ตรงชนิดและอาจแสดงข้อความรูปแบบ `%!d(...)` ให้เลือก `%f`

</details>

## ฝึกเอง

ใช้ `practics/main.go` เดิม เริ่มแต่ละข้อจากตัวอย่างของบทนี้ ไม่ต้องสร้างโฟลเดอร์แยกโจทย์ หากต้องการเก็บงานเดิมให้คัดลอกเป็นไฟล์ .txt ก่อนเปลี่ยนโค้ด

1. เปลี่ยนเป็น `sensor-02` ตั้งค่าอุณหภูมิล่าสุดเป็น `26.75` และแสดงทศนิยมสองตำแหน่ง
2. ก่อนพิมพ์รายงาน กำหนด `retries = 2`, `label = "backup"` และ `failed = true` โดยไม่ประกาศตัวแปรซ้ำ
