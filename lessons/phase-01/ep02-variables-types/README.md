# EP.2 — เก็บข้อมูลด้วยตัวแปรและชนิดข้อมูล

**เป้าหมาย:** เก็บชื่ออุปกรณ์ ค่าการวัด และสถานะ แล้วจัดรูปแบบรายงานได้

**ก่อนเริ่ม:** EP.1 — รันโปรแกรมและอ่าน main ได้

## ทำความเข้าใจ

**ตัวแปร** คือชื่อที่ใช้อ้างถึงค่าซึ่งเปลี่ยนได้ ส่วน **ชนิดข้อมูล** ระบุประเภทของค่าที่ตัวแปรเก็บได้ เช่น `string` สำหรับข้อความ `int` สำหรับจำนวนเต็ม `float64` สำหรับเลขทศนิยม และ `bool` สำหรับ `true` หรือ `false`

**ค่าคงที่** ประกาศด้วย `const` ใช้กับค่าที่ไม่เปลี่ยน เช่น หน่วยวัด

## ลงมือทำ

1. เริ่มจาก `deviceID` และ `celsius` แล้วพิมพ์ค่าด้วย `Println` ลองเปลี่ยนค่าของตัวแปรทั้งสองแล้วรันใหม่เพื่อดูว่าข้อความเปลี่ยนตามอย่างไร
2. เพิ่มตัวแปรตามตัวอย่าง ก่อนรันให้เดาค่าของ `retries`, `label` และ `failed` ที่ยังไม่ได้กำหนดเอง
3. เปลี่ยนเป็น `Printf` เพื่อจัดรูปแบบรายงาน แล้วลองแทน `%.1f` ด้วย `%.2f`

### ตัวอย่างเมื่อทำครบ

ไฟล์ [main.go](main.go):

```go
package main

import "fmt"

func main() {
	const unit = "C"
	var deviceID string = "sensor-01"
	celsius := 27.5
	connected := true
	var retries int
	var label string
	var failed bool
	celsius = 28.25

	fmt.Printf("%s: %.1f %s\n", deviceID, celsius, unit)
	fmt.Printf("connected=%t retries=%d\n", connected, retries)
	fmt.Printf("label=%q failed=%t\n", label, failed)
}
```

### รันและตรวจผล

งานฝึก: เปิด terminal ที่ `practics` แล้วรัน:

```shell
go run main.go
```

ถ้ารันตัวอย่างที่ให้มาโดยตรง ให้เปิด terminal ที่ `lessons/phase-01/ep02-variables-types` แล้วใช้ `go run .` ใช้ได้ทั้ง terminal ใน VS Code, PowerShell และ cmd

ก่อนเปิดผลลัพธ์ ลองคาดเดาค่าล่าสุดของ `celsius` และค่าเริ่มต้นของ `retries`, `label` กับ `failed`

<details>
<summary>ผลลัพธ์ที่คาดหวัง</summary>

```text
sensor-01: 28.2 C
connected=true retries=0
label="" failed=false
```

</details>

<details>
<summary>อธิบายโค้ดและจุดที่ควรตรวจสอบ</summary>

- `var deviceID string = ...` บอกชนิดเอง ส่วน `celsius := 27.5` ให้ Go เลือกชนิดจากค่า ในตัวอย่างนี้เป็น `float64` ใช้ `:=` ประกาศตัวแปรภายในฟังก์ชัน
- `celsius = 28.25` เปลี่ยนค่าตัวแปรเดิม จึงใช้ `=` ไม่ประกาศชื่อเดิมซ้ำด้วย `:=`
- ตัวแปรที่ยังไม่กำหนดค่ามี **zero value**: ตัวเลขเป็น `0`, string เป็น `""`, bool เป็น `false`
- `Printf` ใช้ `%s` แทนข้อความ `%d` แทนจำนวนเต็ม `%t` แทน bool `%q` แสดงข้อความพร้อมเครื่องหมายคำพูด และ `%.1f` แสดงทศนิยมหนึ่งตำแหน่ง `\n` คือขึ้นบรรทัดใหม่ การจัดรูปแบบไม่เปลี่ยนค่าที่เก็บในตัวแปร

**ข้อผิดพลาดที่พบบ่อย:** ตัวแปรภายในฟังก์ชันที่ประกาศแล้วไม่ใช้ทำให้คอมไพล์ไม่ผ่าน ให้อ่านชื่อตัวแปรใน error แล้วนำตัวแปรนั้นไปใช้ หรือลบคำประกาศถ้าไม่จำเป็น ส่วนการใช้ `%d` กับ `float64` จะได้ข้อความผิดรูปแบบ เช่น `%!d(...)` ให้เปลี่ยนเป็น `%f`

</details>

## ฝึกเอง

ฝึกใน `practics/main.go` ไฟล์เดิม ก่อนทำแต่ละข้อให้ใส่โค้ดตัวอย่างเต็มของบทนี้ แล้วแก้ตามโจทย์ หากต้องการเก็บคำตอบข้อก่อนหน้า ให้คัดลอกเป็นไฟล์ `.txt` ก่อน

1. เปลี่ยนค่า `deviceID` เป็น `"sensor-02"` แก้บรรทัด `celsius = 28.25` ให้เป็น `celsius = 26.75` และแสดงอุณหภูมิเป็นทศนิยมสองตำแหน่ง
2. ก่อนพิมพ์รายงาน กำหนด `retries = 2`, `label = "backup"` และ `failed = true` โดยไม่ประกาศตัวแปรซ้ำ

ทำก่อนแล้วค่อยดู [เฉลยพร้อมเหตุผล](solutions/README.md)

**ลองอธิบาย:** การพิมพ์ `28.2` ด้วย `%.1f` ทำให้ค่าที่เก็บในตัวแปร `celsius` เปลี่ยนเป็น `28.2` ด้วยหรือไม่?

<details>
<summary>แนวคำตอบ</summary>

ไม่ ค่าตัวแปรยังเป็น `28.25` ส่วน `%.1f` เปลี่ยนเฉพาะรูปแบบข้อความที่แสดง

</details>
