# แบบฝึกหัด EP.8 — จัดข้อความด้วย Printf

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep08-format-output` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

แสดง sensor-02: 28.25 C ด้วยทศนิยมสองตำแหน่ง

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
