# EP.10 — ตัดสินใจด้วย if และ else

**เป้าหมาย:** เลือกแสดงสถานะจากอุณหภูมิหนึ่งค่า

## 1. อ่านโค้ด

`if` ทำงานเมื่อเงื่อนไขเป็นจริง ส่วน `else` ทำงานในกรณีที่เหลือ `>=` หมายถึงมากกว่าหรือเท่ากับ

ไฟล์ [examples/main.go](examples/main.go)

```go
package main

import "fmt"

func main() {
	temperature := 30.0
	if temperature >= 30 {
		fmt.Println("WARNING")
	} else {
		fmt.Println("OK")
	}
}
```

## 2. ลองรัน

**ก่อนรัน:** ค่า 30 พอดีจะเข้า WARNING หรือ OK เพราะอะไร?

จากโฟลเดอร์หลักสูตรที่มี `lessons` เปิด PowerShell แล้วใช้:

```powershell

go run ./examples
```

เกณฑ์จำลองนี้เริ่มเตือนที่ 30 ดังนั้นค่า 30 พอดีอยู่ในกลุ่ม WARNING

</details>

## 3. ฝึกเอง

ทำ [แบบฝึกหัด 2 ข้อ](exercises/README.md) ใน [practics](../../../docs/PRACTICE.md) แล้วลองตอบ: ถ้าเปลี่ยน >= เป็น > แล้วใช้ค่า 30 ผลจะเปลี่ยนอย่างไร?

<details>
<summary>อ่านเพิ่มเติมเมื่อสงสัย</summary>

เหมือนตรวจว่าต้องหยิบร่มหรือไม่ เราตั้งคำถามที่ตอบได้แค่จริงหรือเท็จ แล้วทำงานตามคำตอบ ตัวอย่างนี้กำหนดเกณฑ์เตือนสมมติที่ 30 องศา

เงื่อนไขคือข้อความที่ให้ค่า bool; >= หมายถึงมากกว่าหรือเท่ากับ; if ทำงานเมื่อเงื่อนไขเป็น true; else ทำงานในกรณีที่เหลือ

- Go ไม่ต้องใส่วงเล็บรอบเงื่อนไข แต่ต้องมี { } ครอบคำสั่ง
- เครื่องหมาย >= รวมค่าที่เท่ากับด้วย ถ้าใช้ > ค่า 30 จะไปอีกทาง
- ทำงานเพียงทางเดียวใน if/else ชุดนี้; เกณฑ์ 30 เป็นข้อกำหนดตัวอย่าง ไม่ใช่กฎของภาษา

**ข้อผิดพลาดที่พบบ่อย**

- ใช้ = แทนการเปรียบเทียบ: = คือกำหนดค่า ส่วน == คือเท่ากัน
- วาง else แยกบรรทัดจาก } ก่อนหน้า: ใช้ } else { ตามตัวอย่าง
