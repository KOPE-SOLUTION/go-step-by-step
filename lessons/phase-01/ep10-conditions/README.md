# EP.10 — ตัดสินใจด้วย if และ else

Phase 1 — Go Basic • [สารบัญ](../../../docs/playlist-01-go-basic/README.md)

## เป้าหมายและสิ่งที่ควรรู้ก่อน

เลือกแสดงสถานะจากอุณหภูมิหนึ่งค่า ก่อนเริ่มควรเรียน EP.9 และอธิบายตัวอย่างในตอนนั้นด้วยคำของตนเองได้ สามารถเปิดตัวอย่างประกอบระหว่างฝึกได้

เรียนตามลำดับ: ทำความเข้าใจ → คาดเดาผล → รันโปรแกรม → ลองแก้ทีละจุด หากต้องการทบทวน เปิด [ตอนก่อนหน้า](../ep09-arithmetic/README.md)

## แนวคิดและคำใหม่

เหมือนตรวจว่าต้องหยิบร่มหรือไม่ เราตั้งคำถามที่ตอบได้แค่จริงหรือเท็จ แล้วทำงานตามคำตอบ ตัวอย่างนี้กำหนดเกณฑ์เตือนสมมติที่ 30 องศา

เงื่อนไขคือข้อความที่ให้ค่า bool; >= หมายถึงมากกว่าหรือเท่ากับ; if ทำงานเมื่อเงื่อนไขเป็น true; else ทำงานในกรณีที่เหลือ

## ลองคาดเดาผลลัพธ์ก่อนรัน

ค่า 30 พอดีจะเข้า WARNING หรือ OK เพราะอะไร?

จดผลที่คาดเดาและเหตุผลสั้น ๆ ก่อนรัน แล้วเปรียบเทียบกับผลจริง หากต่างกัน ให้ลองอธิบายว่าเกิดจากส่วนใดของโค้ด

## โค้ดตัวอย่าง

### examples/main.go

```go
package main

import "fmt"

func main() {
	temperature := 30.0
	if temperature >= 30 {
		fmt.Println("WARNING")
	} else {
		fmt.Println("OK")
	}
}
```

ผลที่คาดหวัง:

## อธิบายการทำงานของโค้ด

- Go ไม่ต้องใส่วงเล็บรอบเงื่อนไข แต่ต้องมี { } ครอบคำสั่ง
- เครื่องหมาย >= รวมค่าที่เท่ากับด้วย ถ้าใช้ > ค่า 30 จะไปอีกทาง
- ทำงานเพียงทางเดียวใน if/else ชุดนี้; เกณฑ์ 30 เป็นข้อกำหนดตัวอย่าง ไม่ใช่กฎของภาษา

**หลักภาษาและแนวทางออกแบบ:** รูปแบบคำสั่งและชนิดข้อมูลเป็นหลักของภาษา Go การแยกโค้ดตามหน้าที่เป็นแนวทางออกแบบให้เข้าใจง่าย ส่วนชื่อโฟลเดอร์และการใช้หนึ่ง module ต่อ EP เป็นทางเลือกในการจัดหลักสูตร

## ฝึกแก้ไขโค้ดด้วยตนเอง

พื้นที่ฝึกไม่รวมเฉลย และคำสั่งสร้างจะหยุดถ้าโฟลเดอร์มีอยู่แล้ว จึงไม่ทับงานที่เคยทำ

## ข้อผิดพลาดที่พบบ่อย

- ใช้ = แทนการเปรียบเทียบ: = คือกำหนดค่า ส่วน == คือเท่ากัน
- วาง else แยกบรรทัดจาก } ก่อนหน้า: ใช้ } else { ตามตัวอย่าง
