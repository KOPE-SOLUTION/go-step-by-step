# แบบฝึกหัด EP.7 — ค่าศูนย์เมื่อยังไม่กำหนดค่า

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep07-zero-values` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

ประกาศชื่อว่าง พิมพ์ใน [] แล้วกำหนด sensor-01 และพิมพ์อีกครั้ง

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

ประกาศ online แบบ bool ไม่ใส่ค่า พิมพ์แล้วเปลี่ยนเป็น true พิมพ์อีกครั้ง

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
