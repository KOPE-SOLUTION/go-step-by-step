# EP.7 — ค่าศูนย์เมื่อยังไม่กำหนดค่า

Phase 1 — Go Basic • [สารบัญ](../../../docs/playlist-01-go-basic/README.md)

## เป้าหมายและสิ่งที่ควรรู้ก่อน

คาดเดาค่าเริ่มต้นของตัวแปรและไม่ตีความว่าอ่านอุปกรณ์สำเร็จ ก่อนเริ่มควรทำ EP.6 ได้และอธิบายตัวอย่างด้วยคำของตนเอง ไม่จำเป็นต้องจำโค้ดจากความจำ

บทนี้มีหนึ่งเรื่องหลัก อ่านเป็นช่วงได้: ทำความเข้าใจ → คาดเดา → รัน → เปลี่ยนทีละจุด ถ้าต้องกลับไปทบทวนใช้ [ตอนก่อนหน้า](../ep06-data-types/README.md)

## แนวคิดและคำใหม่

Go ให้ค่าเริ่มต้นที่แน่นอนเมื่อประกาศด้วย var โดยไม่ใส่ค่า แต่เลข 0 ในตัวแปรไม่ได้ยืนยันว่าอุปกรณ์วัดได้ 0 จริง ต้องแยกความหมายของข้อมูลกับค่าเริ่มต้น

**zero value** คือค่าที่ได้เมื่อยังไม่กำหนดค่า: int/float64 เป็น 0, bool เป็น false, string เป็นข้อความว่าง

## หยุดคาดเดาก่อนเปิดผล

ถ้าชื่อว่าง บรรทัดสุดท้ายจะหายไปหรือเห็น []?

จดคำตอบสั้น ๆ ก่อนรัน ผิดได้ เก็บเหตุผลที่คิดไว้เทียบกับสิ่งที่เกิดขึ้น

## ตัวอย่างเล็กที่รันได้

### examples/main.go

```go
package main

import "fmt"

func main() {
	var count int
	var temperature float64
	var online bool
	var deviceName string
	fmt.Println(count)
	fmt.Println(temperature)
	fmt.Println(online)
	fmt.Println("[" + deviceName + "]")
}
```

## ทำไมโค้ดจึงทำงานแบบนี้

- var แบบไม่มี = ยังมีค่าให้ใช้ ไม่ใช่ค่าขยะ
- เครื่องหมาย + เมื่อใช้กับ string คือการต่อข้อความ ใส่วงเล็บเหลี่ยมเพื่อให้เห็นตำแหน่งข้อความว่าง
- ค่า false เป็นค่าเริ่มต้น ไม่ได้เกิดจากการตรวจการเชื่อมต่อในตัวอย่างนี้

**แยกประเภท:** syntax และชนิดข้อมูลเป็นหลักของภาษา; การแยกหน้าที่ให้ส่วนเล็กอ่านง่ายเป็นแนวทางออกแบบ; ชื่อโฟลเดอร์และการใช้หนึ่ง module ต่อ EP เป็นทางเลือกของหลักสูตร เกณฑ์อุณหภูมิที่พบเป็นข้อกำหนดจำลอง
