# EP.7 — ค่าศูนย์เมื่อยังไม่กำหนดค่า

Phase 1 — Go Basic • [สารบัญ](../../../docs/playlist-01-go-basic/README.md)

## เป้าหมายและสิ่งที่ควรรู้ก่อน

คาดเดาค่าเริ่มต้นของตัวแปรและไม่ตีความว่าอ่านอุปกรณ์สำเร็จ ก่อนเริ่มควรเรียน EP.6 และอธิบายตัวอย่างในตอนนั้นด้วยคำของตนเองได้ สามารถเปิดตัวอย่างประกอบระหว่างฝึกได้

เรียนตามลำดับ: ทำความเข้าใจ → คาดเดาผล → รันโปรแกรม → ลองแก้ทีละจุด หากต้องการทบทวน เปิด [ตอนก่อนหน้า](../ep06-data-types/README.md)

## แนวคิดและคำใหม่

Go ให้ค่าเริ่มต้นที่แน่นอนเมื่อประกาศด้วย var โดยไม่ใส่ค่า แต่เลข 0 ในตัวแปรไม่ได้ยืนยันว่าอุปกรณ์วัดได้ 0 จริง ต้องแยกความหมายของข้อมูลกับค่าเริ่มต้น

**zero value** คือค่าที่ได้เมื่อยังไม่กำหนดค่า: int/float64 เป็น 0, bool เป็น false, string เป็นข้อความว่าง

## ลองคาดเดาผลลัพธ์ก่อนรัน

ถ้าชื่อว่าง บรรทัดสุดท้ายจะหายไปหรือเห็น []?

จดผลที่คาดเดาและเหตุผลสั้น ๆ ก่อนรัน แล้วเปรียบเทียบกับผลจริง หากต่างกัน ให้ลองอธิบายว่าเกิดจากส่วนใดของโค้ด

## โค้ดตัวอย่าง

### examples/main.go

```go
package main

import "fmt"

func main() {
	var count int
	var temperature float64
	var online bool
	var deviceName string
	fmt.Println(count)
	fmt.Println(temperature)
	fmt.Println(online)
	fmt.Println("[" + deviceName + "]")
}
```

## รันและตรวจผล

เปิด PowerShell แล้วเลือกโฟลเดอร์บทเรียน หากวางหลักสูตรไว้ที่ตำแหน่งอื่น ให้ปรับเส้นทางในคำสั่งให้ตรงกับเครื่องของคุณ:

```powershell
Set-Location -LiteralPath 'C:\Users\kopes\Documents\Codex\2026-09-17\go-youtube-go-iot-edge-gateway\Go\lessons\phase-01\ep07-zero-values'
go run ./examples
```

ผลที่คาดหวัง:

```text
0
0
false
[]
```

หากผลลัพธ์ไม่ตรงกับที่คาด ให้ตรวจตำแหน่งด้วย `Get-Location` และตรวจว่าได้บันทึกไฟล์แล้ว หากมีข้อผิดพลาด ให้อ่านข้อความแรกก่อนแก้โค้ด

## อธิบายการทำงานของโค้ด

- var แบบไม่มี = ยังมีค่าให้ใช้ ไม่ใช่ค่าขยะ
- เครื่องหมาย + เมื่อใช้กับ string คือการต่อข้อความ ใส่วงเล็บเหลี่ยมเพื่อให้เห็นตำแหน่งข้อความว่าง
- ค่า false เป็นค่าเริ่มต้น ไม่ได้เกิดจากการตรวจการเชื่อมต่อในตัวอย่างนี้

**หลักภาษาและแนวทางออกแบบ:** รูปแบบคำสั่งและชนิดข้อมูลเป็นหลักของภาษา Go การแยกโค้ดตามหน้าที่เป็นแนวทางออกแบบให้เข้าใจง่าย ส่วนชื่อโฟลเดอร์และการใช้หนึ่ง module ต่อ EP เป็นทางเลือกในการจัดหลักสูตร

## ข้อผิดพลาดที่พบบ่อย

- คิดว่า 0 ยืนยันค่าเซนเซอร์: ตัวอย่างไม่ได้อ่านอุปกรณ์เลย
- ดูข้อความว่างไม่ออก: ครอบด้วยตัวคั่นหรือใช้ %q ในตอนจัดรูปแบบ
