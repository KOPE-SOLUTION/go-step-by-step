# เฉลย EP.7

ลองทำ [แบบฝึกหัด](../exercises/README.md) ด้วยตนเองก่อนอ่านเฉลย โค้ดอาจเขียนต่างจากตัวอย่างได้ หากให้ผลตรงตามโจทย์

คำสั่งด้านล่างรันจากโฟลเดอร์ต้นฉบับ `lessons/phase-01/ep07-zero-values` ไม่ใช่โฟลเดอร์ practics ซึ่งไม่มีเฉลย

## ข้อ 1

เปรียบเทียบก่อน/หลังกำหนดค่า

ดู [main.go](01/main.go)

```powershell
go run ./solutions/01
```

ผล:

```text
[]
[sensor-01]
```

## ข้อ 2

false มาจาก zero value ส่วน true มาจากการกำหนดของเรา

ดู [main.go](02/main.go)

```powershell
go run ./solutions/02
```

ผล:

```text
false
true
```

## คำถามทบทวน

เลขศูนย์อย่างเดียวบอกได้ไหมว่าอ่านอุปกรณ์มาแล้ว?

ไม่ได้ ต้องมีข้อมูลสถานะหรือ error ของการอ่าน ซึ่งจะเรียนต่อภายหลัง

## ฝึกทบทวนด้วยตนเอง

ปิดเฉลย เปลี่ยนค่าหนึ่งจุดในพื้นที่ฝึก แล้วอธิบายผลด้วยตนเอง [กลับบทเรียน](../README.md)
