# แบบฝึกหัด EP.17 — ค้นหาค่าด้วยชื่อใน map

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep17-maps` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

สร้าง map ว่าง เพิ่ม sensor-02 ค่า 28.5 แล้วค้นและพิมพ์พร้อม ok

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง

## ข้อ 2

สร้าง map ของ sensor-01 ค่า 25 ลบด้วย delete แล้วค้นพร้อม ok

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง
