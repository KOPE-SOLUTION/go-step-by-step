## คำถามทบทวน

ทำไมการทดสอบไม่ควรอิงลำดับที่ range map ให้มา?

ภาษารับประกันการเข้าถึงสมาชิก แต่ไม่รับประกันลำดับการวน map จึงต้องทดสอบด้วย key หรือจัดลำดับเองเมื่อจำเป็น
