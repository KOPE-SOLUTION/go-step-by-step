# แบบฝึกหัด EP.24 — ทดสอบค่าต่ำกว่า เท่ากับ และสูงกว่าเกณฑ์

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep24-boundary-tests` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เพิ่มกรณี 0 ต้อง false ในตาราง

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples` และ `go test ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
