# เฉลย EP.13

ลองทำ [แบบฝึกหัด](../exercises/README.md) ด้วยตนเองก่อนอ่านเฉลย โค้ดอาจเขียนต่างจากตัวอย่างได้ หากให้ผลตรงตามโจทย์

คำสั่งด้านล่างรันจากโฟลเดอร์ต้นฉบับ `lessons/phase-01/ep13-function-results` ไม่ใช่โฟลเดอร์ practics ซึ่งไม่มีเฉลย

## ข้อ 1

แทนค่าในสูตรได้ 32

ดู [main.go](01/main.go)

```powershell
go run ./solutions/01
```

ผล:

```text
32.0 F
```

## ข้อ 2

ผลของการเปรียบเทียบเป็น bool อยู่แล้ว

ดู [main.go](02/main.go)

```powershell
go run ./solutions/02
```

ผล:

```text
true
```

## คำถามทบทวน

ทำไมแยกการคืนค่าจากการพิมพ์จึงช่วยการทดสอบ?

ผู้ทดสอบเรียกฟังก์ชันแล้วเทียบค่าคืนโดยตรงได้ โดยไม่ต้องอ่านข้อความจาก terminal

## ฝึกทบทวนด้วยตนเอง

ปิดเฉลย เปลี่ยนค่าหนึ่งจุดในพื้นที่ฝึก แล้วอธิบายผลด้วยตนเอง [กลับบทเรียน](../README.md)
