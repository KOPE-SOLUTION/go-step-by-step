# ผลตรวจ EP.13 — รับค่าที่ฟังก์ชันส่งกลับ

ตรวจจริงเมื่อ 2026-09-19 บน Windows x64 ด้วย `go version go1.27.1 windows/amd64`

| การตรวจ | ผล |
|---|---|
| gofmt -l กับไฟล์ .go ทั้ง EP | ผ่าน ไม่มีไฟล์ที่ต้องจัดรูปแบบ |
| go test -count=1 ./... | ผ่าน ใช้ตรวจ compile; ไม่มี unit test function ใน EP นี้ |
| go run ./examples | exit 0 และข้อความตรงตามที่บทเรียนระบุ |
| go run ./solutions/01 | exit 0 และข้อความตรงตามเฉลยข้อ 1 |
| go run ./solutions/02 | exit 0 และข้อความตรงตามเฉลยข้อ 2 |

ใช้สคริปต์ [verify-phase01.ps1](../../../../scripts/verify-phase01.ps1) ตรวจต้นฉบับ ตั้ง `GOTOOLCHAIN=local` และ `GOPROXY=off` เฉพาะ process ไม่มี dependency ภายนอก กรณีตั้งใจทำให้ผิดทดลองเฉพาะสำเนาใน TEMP รายละเอียดรวมและวิธีรันซ้ำอยู่ใน [ผลตรวจ Phase 1](../../../../notes/phase-01-results.md)

ยังไม่ได้ตรวจ: Go 1.22.0 จริงหรือทุกเวอร์ชันระหว่างนั้น, Linux/macOS, การพิมพ์และแก้โค้ดในหน้าต่างของผู้เรียน, API/ฐานข้อมูล/MQTT/อุปกรณ์จริง

`go 1.22.0` ใน go.mod คือเวอร์ชันขั้นต่ำที่ประกาศ ไม่ใช่ผลการทดสอบกับ toolchain รุ่นนั้น และผลตรวจนี้ไม่ใช่การรับรองว่าผู้เรียนทำแบบฝึกหัดผ่านแล้ว
