# แบบฝึกหัด EP.13 — รับค่าที่ฟังก์ชันส่งกลับ

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep13-function-results` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

แปลง 0 องศาเซลเซียสแล้วพิมพ์ทศนิยมหนึ่งตำแหน่ง

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

เขียน isWarning(temperature float64) bool ให้คืนค่าการเปรียบเทียบ temperature >= 30 แล้วพิมพ์ผลเมื่อส่ง 30

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
