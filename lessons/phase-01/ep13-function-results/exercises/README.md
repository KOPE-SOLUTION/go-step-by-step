# แบบฝึกหัด EP.13 — รับค่าที่ฟังก์ชันส่งกลับ

สร้างพื้นที่ฝึกจากรากหลักสูตรด้วย `./scripts/new-practice.ps1 -Episode 13` แล้วเปิด `practics/phase-01/ep13-function-results` ([วิธีใช้](../../../../docs/PRACTICE.md))

## ข้อ 1

แปลง 0 องศาเซลเซียสแล้วพิมพ์ทศนิยมหนึ่งตำแหน่ง

## ข้อ 2

เขียน isWarning(temperature float64) bool ให้คืนค่าการเปรียบเทียบ temperature >= 30 แล้วพิมพ์ผลเมื่อส่ง 30
