# EP.4 — ทำซ้ำและสรุปค่าการวัดด้วย for

**เป้าหมาย:** เลือกลูปตามจำนวนรอบหรือตามเงื่อนไข ข้ามหรือหยุดรอบ และหาค่าเฉลี่ยจากข้อมูลจำลองได้

**ก่อนเริ่ม:** EP.3 — การคำนวณและเงื่อนไข

## ทำความเข้าใจ

**ลูป** คือการทำคำสั่งเดิมซ้ำ Go ไม่มีคำสั่ง `while` แต่ใช้ `for` แบบมีเฉพาะเงื่อนไขเพื่อทำงานแบบเดียวกันได้ บทนี้จะลองทั้งการนับรอบและการทำต่อขณะที่เงื่อนไขเป็นจริง ก่อนนำมาสรุปค่าการวัดจำลอง

## ลงมือทำทีละขั้น

ใช้ `practics/main.go` ไฟล์เดิม หากต้องการเก็บงานเดิม ให้คัดลอกเป็น `.txt` ก่อน เริ่มด้วยโค้ดขั้นที่ 1 แล้วแก้ต่อทีละขั้น บันทึกและรัน `go run main.go` จาก terminal ที่ `practics` ทุกครั้ง ก่อนดูผล ให้ลองคาดเดาสิ่งที่จะพิมพ์

### 1. เขียนลูปพิมพ์เลขรอบ

เริ่ม `main.go` ของบทนี้ด้วยโค้ดต่อไปนี้:

```go
package main

import "fmt"

func main() {
	for round := 1; round <= 5; round++ {
		fmt.Println(round)
	}
}
```

`round := 1` กำหนดค่าเริ่มต้นครั้งเดียว ก่อนทำแต่ละรอบจะตรวจ `round <= 5` และหลังทำคำสั่งในลูปจะเพิ่มค่าด้วย `round++` ซึ่งหมายถึงเพิ่มทีละ 1

**ลองคิดก่อนรัน:** โปรแกรมจะพิมพ์เลข 5 ด้วยหรือไม่?

<summary>รันแล้วค่อยเปิดตรวจผล</summary>

```text
1
2
3
4
5
```

</details>

### 2. ใช้ for แบบ while: ทำต่อขณะที่เงื่อนไขยังจริง

แบบนับรอบเหมาะกับงานที่กำหนดจำนวนไว้ เช่น ทำ 5 รอบ แต่ถ้าต้องการทำต่อจนค่าหรือสถานะเปลี่ยน ให้ใช้ `for เงื่อนไข` เช่น อ่านข้อมูลต่อขณะที่ยังมีข้อมูลเหลือ หรือลองทำงานซ้ำจนสำเร็จภายในขีดจำกัดที่กำหนด

ตอนนี้ลองด้วยอุณหภูมิจำลองที่ลดลงทีละ 1 จนไม่เกิน 30 โดยแทนเฉพาะ `main` ทั้งฟังก์ชัน เก็บ `package` และ `import` ไว้:

```go
func main() {
	celsius := 33.0
	for celsius > 30 {
		fmt.Printf("cooling: %.1f C\n", celsius)
		celsius -= 1
	}
	fmt.Printf("ready: %.1f C\n", celsius)
}
```

หลัง `for` มีเฉพาะเงื่อนไข ไม่ต้องใส่ `;` ค่าเริ่มต้นอยู่ก่อนลูป ส่วน `celsius -= 1` ภายในลูปย่อจาก `celsius = celsius - 1`

ลูปจะตรวจ `celsius > 30` **ก่อนทุกรอบ รวมถึงรอบแรก** ถ้าจริงจึงทำคำสั่งในลูป ถ้าเท็จจะไปพิมพ์ `ready` หลังลูป ตัวอย่างนี้ลดตัวเลขในโปรแกรมทันที ไม่ได้รอเวลาให้อุปกรณ์เย็นลงจริง

**ลองคิดก่อนรัน:** ข้อความ cooling จะมีค่า 30 ด้วยหรือไม่? หลังจบลูป celsius จะเหลือเท่าไร?

<summary>รันแล้วค่อยเปิดตรวจผล</summary>

```text

cooling: 32.0 C
cooling: 31.0 C
ready: 30.0 C
```

</details>

ลองเปลี่ยนค่าเริ่มต้นเป็น `29.0` แล้วรันอีกครั้ง ลูปจะทำงานสักรอบหรือไม่?

<details>
<summary>ผลเมื่อเงื่อนไขเป็นเท็จตั้งแต่แรก</summary>

```text
ready: 29.0 C
```

คำสั่งในลูปไม่ทำงานเลย เพราะ 29 ไม่มากกว่า 30

</details>

**จุดที่ต้องตรวจ:** ถ้าลืม `celsius -= 1` ค่าเริ่มต้น 33 จะไม่เปลี่ยนและลูปนี้ไม่จบ หากเผลอรัน ให้กด Ctrl+C เพื่อหยุด แล้วตรวจว่าคำสั่งใดทำให้เงื่อนไขเปลี่ยนเป็นเท็จ

ทั้งสองแบบใช้ `for` เหมือนกัน การเลือกแบบนับรอบหรือแบบมีเฉพาะเงื่อนไขขึ้นอยู่กับสิ่งที่ต้องการใช้ควบคุมการทำซ้ำ ขั้นถัดไปจะกลับไปใช้แบบนับรอบเพื่อสร้างรายงาน

### 3. สร้างอุณหภูมิจากเลขรอบ

แทนเฉพาะฟังก์ชัน `main` ทั้งฟังก์ชัน เก็บ `package` และ `import` ไว้เหมือนเดิม:

```go
func main() {
	for round := 1; round <= 5; round++ {
		celsius := 25.0 + float64(round)
		fmt.Printf("round %d: %.1f C\n", round, celsius)
	}
}
```

`float64(round)` แปลงเลขรอบชนิด `int` เป็น `float64` เพื่อใช้คำนวณกับค่าทศนิยม อุณหภูมินี้เป็นข้อมูลจำลองจากสูตร ยังไม่ได้อ่านอุปกรณ์

### 4. เพิ่มผลรวม total และจำนวน count

แทน `main` ด้วยเวอร์ชันนี้ เพื่อเพิ่มตัวสะสมและตรวจผลหลังจบลูป:

```go
func main() {
	total := 0.0
	count := 0
	for round := 1; round <= 5; round++ {
		celsius := 25.0 + float64(round)
		total += celsius
		count++
		fmt.Printf("round %d: %.1f C\n", round, celsius)
	}
	fmt.Printf("total: %.1f, count: %d\n", total, count)
}
```

ประกาศ `total` และ `count` ก่อนลูปเพื่อเก็บค่าต่อเนื่อง `total += celsius` ย่อจาก `total = total + celsius` ส่วน `count++` นับค่าที่นำมารวมแต่ละครั้ง

**ลองคิดก่อนรัน:** หลังจบห้ารอบ ผลรวมและจำนวนจะเป็นเท่าไร?

### 5. คำนวณค่าเฉลี่ยหลังจบลูป

แทนบรรทัด `fmt.Printf("total: ...")` หลังลูปด้วยบล็อกนี้:

```go
if count > 0 {
	fmt.Printf("average: %.2f C (%d readings)\n", total/float64(count), count)
}
```

ค่าเฉลี่ยคือผลรวมหารจำนวนค่า ใช้ `float64(count)` ให้ชนิดตรงกับ `total` และตรวจ `count > 0` ก่อนหาร

**ลองคิดก่อนรัน:** หากไม่มีค่าการวัดเลย เงื่อนไขนี้จะยอมให้หารหรือไม่?

### 6. เพิ่ม continue เพื่อข้ามรอบที่อ่านไม่ได้

ในลูป แทนบรรทัด `celsius := ...` ด้วยโค้ดนี้ เพื่อแทรกเงื่อนไขก่อนคำนวณและสะสมค่า:

```go
if round == 3 {
	fmt.Println("round 3: skipped")
	continue
}
celsius := 25.0 + float64(round)
```

`continue` ข้ามคำสั่งที่เหลือในรอบนั้น แต่ `for` แบบนี้ยังทำส่วนท้าย `round++` ก่อนตรวจรอบถัดไป รอบที่ข้ามจึงไม่เพิ่มทั้ง `total` และ `count` ส่วน `break` ใช้ออกจากลูปทันที ซึ่งจะได้ลองในแบบฝึกหัด

ถ้าใช้ `continue` กับลูปแบบขั้นที่ 2 ต้องระวังไม่ให้ข้ามบรรทัดเปลี่ยนค่า `celsius` เพราะแบบนั้นไม่มีส่วนท้ายเพิ่มหรือลดค่าให้อัตโนมัติ

**ลองคิดก่อนรัน:** เมื่อข้ามรอบ 3 ต้องหารผลรวมด้วย 5 หรือ 4? อธิบายก่อนรัน

### ตัวอย่างเมื่อทำครบ

<details>
<summary>เปิดเทียบโค้ดฉบับเต็มหลังทำครบทุกขั้น</summary>

ไฟล์ [main.go](main.go):

```go
package main

import "fmt"

func main() {
	total := 0.0
	count := 0
	for round := 1; round <= 5; round++ {
		if round == 3 {
			fmt.Println("round 3: skipped")
			continue
		}
		celsius := 25.0 + float64(round)
		total += celsius
		count++
		fmt.Printf("round %d: %.1f C\n", round, celsius)
	}
	if count > 0 {
		fmt.Printf("average: %.2f C (%d readings)\n", total/float64(count), count)
	}
}
```

</details>

<details>
<summary>วิธีรันตัวอย่างต้นฉบับและจุดที่ควรตรวจ</summary>

เปิด terminal ที่ `lessons/phase-01/ep04-loops` แล้วรัน `go run .` ผลต้องเหมือนขั้นที่ 6 ส่วนไฟล์ที่เขียนเองยังรัน `go run main.go` จาก `practics`

- หากจำนวนรอบผิด ให้ตรวจ `<` กับ `<=` เช่น `round < 5` ทำถึงรอบ 4 เท่านั้น
- ประกาศ `total` และ `count` ก่อนลูปเพื่อเก็บค่าต่อเนื่อง ถ้าประกาศในลูป ค่าจะเริ่มใหม่ทุกครั้ง
- เพิ่ม `count` เฉพาะค่าที่นำมารวม และตรวจ `count > 0` ก่อนหาร
- ถ้าลูปไม่หยุด ให้ตรวจเงื่อนไขกับบรรทัดเปลี่ยนค่า โดยเฉพาะลูปที่เขียนแบบ while

</details>

## ฝึกเอง

ฝึกใน `practics/main.go` ไฟล์เดิม ข้อ 1–2 เริ่มจากโค้ดตัวอย่างเต็มของบทนี้ ส่วนข้อ 3 เริ่มจากโค้ดขั้นที่ 2 หากต้องการเก็บคำตอบข้อก่อนหน้า ให้คัดลอกเป็นไฟล์ `.txt` ก่อน

1. เปลี่ยนเงื่อนไขลูปจาก `round <= 5` เป็น `round <= 3` โดยยังข้ามรอบ 3 ค่าเฉลี่ยต้องคำนวณจากสองรอบแรก
2. ให้หยุดลูปเมื่อถึงรอบ 3 โดยเปลี่ยน `continue` เป็น `break` และเปลี่ยนข้อความเป็น `round 3: stopped` คาดเดาก่อนรันว่ารอบ 4–5 จะทำงานหรือไม่
3. ข้อนี้เริ่มจากโค้ดขั้นที่ 2 แทนตัวอย่างเต็ม ตั้งอุณหภูมิเริ่มต้น 33.0 แต่ให้ลดทีละ 2 โดยยังทำต่อเมื่อมากกว่า 30 ลองคาดเดาค่าสุดท้าย แล้วรันตรวจ
