# แบบฝึกหัด EP.19 — ให้ข้อมูลมี method ของตัวเอง

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep19-methods` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

ใช้ Celsius: 29.9 แล้วเรียก IsWarning

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง
