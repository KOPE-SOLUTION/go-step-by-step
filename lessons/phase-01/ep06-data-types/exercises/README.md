# แบบฝึกหัด EP.6 — ชนิดข้อมูล string, int, float64 และ bool

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep06-data-types` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

เก็บรหัส 007 จำนวน 2 อุณหภูมิ 30.5 และสถานะ false แล้วพิมพ์คนละบรรทัด

1. คาดเดาผลและเขียนเหตุผลหนึ่งประโยค
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เทียบผลกับที่คาด ถ้าต่าง ให้อ่าน error หรือไล่ค่าทีละบรรทัดก่อนแก้อีกครั้ง
