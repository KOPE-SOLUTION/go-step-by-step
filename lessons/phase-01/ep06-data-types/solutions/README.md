# เฉลย EP.6

หยุดก่อนถ้ายังไม่ได้ลอง [แบบฝึกหัด](../exercises/README.md) คำตอบไม่จำเป็นต้องเขียนเหมือนกันทุกตัวอักษร แต่ต้องตรงข้อกำหนด

เลือกชนิดเดียวกับตัวอย่างแต่เปลี่ยนค่า

ดู [main.go](01/main.go)

```powershell

```

ผล:

```text
007
2
30.5
false
```

## ข้อ 2

ดู [main.go](02/main.go)

```powershell
go run ./solutions/02
```

ผล:

```text
5
```

## คำถามทบทวน

รหัส 001 กับจำนวน 1 ควรเลือกชนิดเหมือนกันเสมอไหม?

ไม่เสมอ รหัสใช้ string เพื่อรักษารูปแบบ ส่วนจำนวนใช้ int เพื่อคำนวณ
