# EP.5 — ตัวแปรและการเปลี่ยนค่า

Phase 1 — Go Basic • [สารบัญ](../../../docs/playlist-01-go-basic/README.md)

## เป้าหมายและสิ่งที่ควรรู้ก่อน

ประกาศตัวแปรหนึ่งตัวและเปลี่ยนค่าที่เก็บได้ ก่อนเริ่มควรทำ EP.4 ได้และอธิบายตัวอย่างด้วยคำของตนเอง ไม่จำเป็นต้องจำโค้ดจากความจำ

บทนี้มีหนึ่งเรื่องหลัก อ่านเป็นช่วงได้: ทำความเข้าใจ → คาดเดา → รัน → เปลี่ยนทีละจุด ถ้าต้องกลับไปทบทวนใช้ [ตอนก่อนหน้า](../ep04-read-errors/README.md)

## แนวคิดและคำใหม่

ตัวแปรคล้ายกล่องติดชื่อ เราอ่านค่าด้วยชื่อกล่องและใส่ค่าใหม่ลงกล่องเดิมได้ ชื่อ deviceName ช่วยบอกความหมายมากกว่าพิมพ์ข้อความเดิมกระจายหลายแห่ง

**ตัวแปร** คือชื่อที่ใช้เข้าถึงค่าที่เก็บ; **ประกาศ** คือสร้างชื่อนั้น; `:=` ประกาศแบบสั้นภายในฟังก์ชัน ส่วน `=` กำหนดค่าใหม่ให้ตัวแปรเดิม

## หยุดคาดเดาก่อนเปิดผล

สอง Println จะเห็นชื่อเดียวกันหรือไม่ เพราะอะไร?

จดคำตอบสั้น ๆ ก่อนรัน ผิดได้ เก็บเหตุผลที่คิดไว้เทียบกับสิ่งที่เกิดขึ้น

## ตัวอย่างเล็กที่รันได้

### examples/main.go

```go
package main

import "fmt"

func main() {
	deviceName := "sensor-01"
	fmt.Println(deviceName)
	deviceName = "sensor-02"
	fmt.Println(deviceName)
}
```

## ทำไมโค้ดจึงทำงานแบบนี้

- บรรทัดแรกประกาศชื่อและเริ่มด้วยค่า string ชนิดของตัวแปรจึงเป็น string
- บรรทัดที่ใช้ = เปลี่ยนค่าในตัวแปรเดิม ไม่สร้างกล่องชื่อซ้ำ
- ส่ง deviceName โดยไม่ใส่ quote เพื่ออ่านค่า ถ้าใส่ quote จะพิมพ์ชื่อเป็นข้อความตรงตัว

**แยกประเภท:** syntax และชนิดข้อมูลเป็นหลักของภาษา; การแยกหน้าที่ให้ส่วนเล็กอ่านง่ายเป็นแนวทางออกแบบ; ชื่อโฟลเดอร์และการใช้หนึ่ง module ต่อ EP เป็นทางเลือกของหลักสูตร เกณฑ์อุณหภูมิที่พบเป็นข้อกำหนดจำลอง

## ข้อผิดพลาดที่พบบ่อย

- ใช้ := ซ้ำกับชื่อเดิมเพียงชื่อเดียวในขอบเขตเดียวกัน: ไม่มีตัวแปรใหม่ให้ประกาศ ใช้ =
- ประกาศตัวแปรภายในฟังก์ชันแล้วไม่ใช้: compiler แจ้ง unused variable
