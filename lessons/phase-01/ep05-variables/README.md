# EP.5 — ตัวแปรและการเปลี่ยนค่า

**เป้าหมาย:** ประกาศตัวแปรหนึ่งตัวและเปลี่ยนค่าที่เก็บได้

## 1. อ่านโค้ด

ตัวแปรใช้ชื่อแทนค่าที่เก็บไว้ `:=` ประกาศตัวแปรใหม่ ส่วน `=` เปลี่ยนค่าของตัวแปรเดิม

ไฟล์ [examples/main.go](examples/main.go)

```go
package main

import "fmt"

func main() {
	deviceName := "sensor-01"
	fmt.Println(deviceName)
	deviceName = "sensor-02"
	fmt.Println(deviceName)
}
```

## 2. ลองรัน

**ก่อนรัน:** สอง Println จะเห็นชื่อเดียวกันหรือไม่ เพราะอะไร?

จากโฟลเดอร์หลักสูตรที่มี `lessons` เปิด PowerShell แล้วใช้:

```powershell
Set-Location -LiteralPath './lessons/phase-01/ep05-variables'
go run ./examples
```

<details>
<summary>ดูผลที่คาดหวังหลังลองรัน</summary>

```text
sensor-01
sensor-02
```

เมื่อเปลี่ยนค่าแล้ว คำสั่งถัดไปจะอ่านค่าใหม่

</details>

## 3. ฝึกเอง

ทำ [แบบฝึกหัด 2 ข้อ](exercises/README.md) ใน [practics](../../../docs/PRACTICE.md) แล้วลองตอบ: ทำไมเปลี่ยนค่าครั้งที่สองจึงใช้ = แทน :=?

<details>
<summary>อ่านเพิ่มเติมเมื่อสงสัย</summary>

ตัวแปรคล้ายกล่องติดชื่อ เราอ่านค่าด้วยชื่อกล่องและใส่ค่าใหม่ลงกล่องเดิมได้ ชื่อ deviceName ช่วยบอกความหมายมากกว่าพิมพ์ข้อความเดิมกระจายหลายแห่ง

**ตัวแปร** คือชื่อที่ใช้เข้าถึงค่าที่เก็บ; **ประกาศ** คือสร้างชื่อนั้น; `:=` ประกาศแบบสั้นภายในฟังก์ชัน ส่วน `=` กำหนดค่าใหม่ให้ตัวแปรเดิม

- บรรทัดแรกประกาศชื่อและเริ่มด้วยค่า string ชนิดของตัวแปรจึงเป็น string
- บรรทัดที่ใช้ = เปลี่ยนค่าในตัวแปรเดิม ไม่สร้างกล่องชื่อซ้ำ
- ส่ง deviceName โดยไม่ใส่ quote เพื่ออ่านค่า ถ้าใส่ quote จะพิมพ์ชื่อเป็นข้อความตรงตัว

**ข้อผิดพลาดที่พบบ่อย**

- ใช้ := ซ้ำกับชื่อเดิมเพียงชื่อเดียวในขอบเขตเดียวกัน: ไม่มีตัวแปรใหม่ให้ประกาศ ใช้ =
- ประกาศตัวแปรภายในฟังก์ชันแล้วไม่ใช้: compiler แจ้ง unused variable

</details>
