# เฉลย EP.5

หยุดก่อนถ้ายังไม่ได้ลอง [แบบฝึกหัด](../exercises/README.md) คำตอบไม่จำเป็นต้องเขียนเหมือนกันทุกตัวอักษร แต่ต้องตรงข้อกำหนด

คำสั่งด้านล่างรันจากโฟลเดอร์ต้นฉบับ `lessons/phase-01/ep05-variables` ไม่ใช่โฟลเดอร์ practics ซึ่งไม่มีเฉลย

## ข้อ 1

ใช้ := ครั้งแรกและ = ครั้งถัดไป

ดู [main.go](01/main.go)

```powershell
go run ./solutions/01
```

ผล:

```text
sensor-03
sensor-04
```

## ข้อ 2

บรรทัดหนึ่งเป็น string literal อีกบรรทัดอ่านตัวแปร

ดู [main.go](02/main.go)

```powershell
go run ./solutions/02
```

ผล:

```text
deviceName
sensor-01
```

## คำถามทบทวน

ทำไมเปลี่ยนค่าครั้งที่สองจึงใช้ = แทน :=?

เรากำลังกำหนดค่าใหม่ให้ตัวแปรที่ประกาศแล้ว ไม่ได้สร้างชื่อใหม่

## กลับไปลองอีกครั้ง

ปิดเฉลย เปลี่ยนค่าหนึ่งจุดในพื้นที่ฝึก แล้วอธิบายผลด้วยตนเอง [กลับบทเรียน](../README.md)
