# แบบฝึกหัด EP.26 — โปรเจกต์สรุป ตอนที่ 2 — ตรวจข้อมูลก่อนทำรายงาน

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep26-project-validation` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

ใช้ชื่อว่างกับค่า 25 ต้องรายงาน device ID is empty

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
