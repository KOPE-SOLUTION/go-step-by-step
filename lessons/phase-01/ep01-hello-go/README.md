# EP.1 — เขียนและรันโปรแกรม Go แรก

**เป้าหมาย:** รันโปรแกรม อ่านส่วนประกอบ และแก้ข้อผิดพลาดง่าย ๆ ได้ด้วยตัวเอง

**ก่อนเริ่ม:** มี Go พร้อมใช้งานและเปิดไฟล์ในโปรแกรมแก้ไขโค้ดได้

## ทำความเข้าใจ

Go เป็นภาษาสำหรับเขียนโปรแกรม เช่น เครื่องมือที่สั่งงานด้วยข้อความและบริการรับส่งข้อมูล บทนี้จะเริ่มจากข้อความทักทาย แล้วเพิ่มชื่ออุปกรณ์และสถานะด้วยข้อมูลจำลอง

**Terminal** คือหน้าต่างสำหรับพิมพ์คำสั่ง ส่วน **compiler** คือเครื่องมือตรวจและแปลโค้ดให้เป็นโปรแกรมที่เครื่องรันได้ คำสั่ง `go run` จะคอมไพล์โค้ด แล้วรันเมื่อคอมไพล์สำเร็จ

## ลงมือทำทีละขั้น

ตรวจเครื่องมือด้วยคำสั่งนี้ก่อน หากคำสั่งไม่ทำงาน ดู [วิธีตรวจปัญหา](../../../notes/troubleshooting.md)

```shell
go version
```

ในโฟลเดอร์หลักสูตร สร้างโฟลเดอร์ `practics` แล้วสร้างไฟล์ `main.go` ข้างใน ถ้ามีอยู่แล้วให้ใช้ไฟล์เดิม และคัดลอกงานที่ต้องการเก็บเป็น `.txt` ก่อนเปลี่ยนโค้ด ดูภาพรวมได้ที่ [วิธีเริ่มฝึก](../../../docs/PRACTICE.md)

คลิกขวาที่ `practics` ใน VS Code แล้วเลือก **Open in Integrated Terminal** หรือเปิด PowerShell / cmd ที่โฟลเดอร์นี้ บันทึกไฟล์และรันคำสั่งเดิมหลังแต่ละขั้น:

```shell
go run main.go
```

### 1. เขียนโปรแกรมทักทาย

**package** คือกลุ่มไฟล์ Go ที่ทำงานร่วมกัน ส่วน **ฟังก์ชัน** คือชุดคำสั่งที่เรียกให้ทำงานได้ เราจะใช้ฟังก์ชัน `main` เป็นจุดเริ่มของโปรแกรม และเรียก `Println` เพื่อแสดงข้อความ

เริ่ม `practics/main.go` ด้วยโค้ดนี้:

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}
```

- `package main` ระบุว่าไฟล์นี้อยู่ใน package สำหรับสร้างโปรแกรมที่รันได้
- `import "fmt"` ทำให้เรียกใช้เครื่องมือจัดรูปแบบและแสดงข้อความจาก package `fmt` ได้ ชื่อมาจากคำว่า format
- `func main()` ประกาศฟังก์ชันที่โปรแกรมเริ่มทำงาน คำสั่งภายใน `{ }` ทำจากบนลงล่าง
- ข้อความใน `" "` เรียกว่า **string** และ `fmt.Println` แสดงข้อความพร้อมขึ้นบรรทัดใหม่

ใน `fmt.Println("Hello, Go!")` จุดเชื่อมชื่อ package กับชื่อฟังก์ชัน ส่วน `( )` ครอบค่าที่ส่งให้ฟังก์ชันพิมพ์ออกมา

**ลองคิดก่อนรัน:** โปรแกรมจะพิมพ์ข้อความใด? เครื่องหมายคำพูดจะปรากฏด้วยหรือไม่?

<details>
<summary>รันแล้วค่อยเปิดตรวจผล</summary>

```text
Hello, Go!
```

</details>

### 2. เพิ่มชื่ออุปกรณ์ด้วย Print และ Println

แทนเฉพาะฟังก์ชัน `main` ทั้งฟังก์ชัน เก็บ `package` และ `import` ไว้เหมือนเดิม:

```go
func main() {
	fmt.Println("Hello, Go!")
	fmt.Print("Device: ")
	fmt.Println("sensor-01")
}
```

`Print` ไม่เติมบรรทัดใหม่ ส่วน `Println` เติมบรรทัดใหม่เมื่อพิมพ์เสร็จ ช่องว่างท้าย `"Device: "` ทำให้ชื่ออุปกรณ์ไม่ติดกับเครื่องหมาย `:`

**ลองคิดก่อนรัน:** `Device:` กับ `sensor-01` จะอยู่บรรทัดเดียวกันหรือคนละบรรทัด?

<details>
<summary>รันแล้วค่อยเปิดตรวจผล</summary>

```text
Hello, Go!
Device: sensor-01
```

</details>

### 3. เพิ่มสถานะเป็นบรรทัดสุดท้าย

เพิ่มคำสั่งนี้ต่อจาก `fmt.Println("sensor-01")` ภายใน `main`:

```go
	fmt.Println("Status: ready")
```

คำสั่งใหม่ทำงานหลังคำสั่งแสดงชื่ออุปกรณ์ และขึ้นบรรทัดใหม่เมื่อพิมพ์เสร็จ

**ลองคิดก่อนรัน:** ตอนนี้มีคำสั่งพิมพ์สี่ครั้ง แต่ข้อความจะมีกี่บรรทัด?

```text

```

</details>

### 4. ลองทำให้ผิด แล้วอ่านข้อความ error

เปลี่ยนเฉพาะบรรทัดทักทายให้ตัว **P ใหญ่เป็น p เล็ก**:

```go
	fmt.println("Hello, Go!")
```

Go แยกตัวพิมพ์เล็กกับตัวพิมพ์ใหญ่ บันทึกไฟล์แล้วรัน `go run main.go` อีกครั้ง

**ลองคิดก่อนรัน:** ถ้าคอมไพล์ไม่ผ่าน ข้อความอุปกรณ์และสถานะจะยังปรากฏหรือไม่?

<details>
<summary>รันแล้วค่อยเปิดตรวจผล</summary>

บรรทัดสำคัญของข้อความผิดพลาด:

```text
.\main.go:6:6: undefined: fmt.println (but have Println)
```

`main.go:6:6` ระบุไฟล์ บรรทัด และคอลัมน์ ส่วน `undefined: fmt.println` บอกว่าไม่พบชื่อนี้ ชื่อที่มีคือ `Println` โดยขึ้นต้นด้วย P ใหญ่ กรณีนี้คอมไพล์ไม่ผ่าน โปรแกรมจึงยังไม่พิมพ์ข้อความ

ตำแหน่งและข้อความประกอบอาจต่างกันตามโค้ดและรุ่น Go ให้ดูชื่อที่รายงานเป็นหลัก

</details>

**ลองคิดก่อนรัน:** เมื่อแก้ชื่อถูกต้อง ข้อความควรกลับมาเหมือนขั้นที่ 3 หรือไม่?

## ฝึกเอง

ฝึกใน `practics/main.go` ไฟล์เดิม ก่อนทำแต่ละข้อให้ใส่โค้ดตัวอย่างเต็มของบทนี้ แล้วแก้ตามโจทย์ หากต้องการเก็บคำตอบข้อก่อนหน้า ให้คัดลอกเป็นไฟล์ `.txt` ก่อน

1. เปลี่ยนชื่ออุปกรณ์เป็น `sensor-02` และสถานะเป็น `waiting` โดยยังแสดงผล 3 บรรทัด
2. ทำให้ชื่ออุปกรณ์อยู่คนละบรรทัดกับ `Device:` โดยเปลี่ยนคำสั่งแสดงผลเพียงหนึ่งจุด

ทำก่อนแล้วค่อยดู [เฉลยพร้อมเหตุผล](solutions/README.md)

**ลองอธิบาย:** ทำไมมี `import "fmt"` แล้วจึงยังต้องเรียก `fmt.Println` อีก?

<details>
<summary>แนวคำตอบ</summary>

`import "fmt"` ทำให้โค้ดเรียกใช้ฟังก์ชันจาก package `fmt` ได้ แต่ข้อความจะปรากฏเมื่อโปรแกรมเรียก `fmt.Print` หรือ `fmt.Println`

</details>
