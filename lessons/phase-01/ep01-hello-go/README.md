# EP.1 — เขียนและรันโปรแกรม Go แรก

**เป้าหมาย:** รันโปรแกรม อ่านส่วนประกอบ และแก้ข้อผิดพลาดง่าย ๆ ได้ด้วยตัวเอง

**ก่อนเริ่ม:** มี Go พร้อมใช้งานและเปิดไฟล์ในโปรแกรมแก้ไขโค้ดได้

## ทำความเข้าใจ

Go เป็นภาษาสำหรับเขียนโปรแกรม เช่น เครื่องมือใน terminal บริการ API และโปรแกรมรับข้อมูล ในบทนี้เราจะทำหน้าจอเริ่มต้นของอุปกรณ์จำลอง ยังไม่มีการเชื่อมต่ออุปกรณ์จริง

**Terminal** คือหน้าต่างพิมพ์คำสั่ง ส่วน **compiler** คือเครื่องมือแปลและตรวจโค้ดก่อนโปรแกรมทำงาน คำสั่ง `go run` จะจัดการขั้นตอนนี้แล้วรันให้

## ลงมือทำ

1. ตรวจเครื่องมือด้วย `go version` ถ้าคำสั่งไม่ทำงาน ดู [วิธีตรวจปัญหา](../../../notes/troubleshooting.md)
2. สร้าง `practics/main.go` ตาม [วิธีเริ่มฝึก](../../../docs/PRACTICE.md) แล้วเริ่มจากโค้ดด้านล่างโดยใส่เพียง `fmt.Println("Hello, Go!")` ใน `main`
3. รันให้สำเร็จก่อน แล้วเพิ่มข้อความอุปกรณ์และสถานะตามตัวอย่างเต็ม ลองคาดเดาว่า `Print` และ `Println` ต่างกันอย่างไร

### ตัวอย่างเมื่อทำครบ

ไฟล์ [main.go](main.go):

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
	fmt.Print("Device: ")
	fmt.Println("sensor-01")
	fmt.Println("Status: ready")
}
```

### รันและตรวจผล

งานฝึก: เปิด terminal ที่ `practics` แล้วรัน:

```shell
go run main.go
```

ถ้ารันตัวอย่างที่ให้มาโดยตรง ให้เปิด terminal ที่ `lessons/phase-01/ep01-hello-go` แล้วใช้ `go run .` ใช้ได้ทั้ง terminal ใน VS Code, PowerShell และ cmd

ก่อนเปิดผลลัพธ์ ลองคาดเดาว่าข้อมูลแต่ละรายการจะถูกจัดการอย่างไร

<details>
<summary>ผลลัพธ์ที่คาดหวัง</summary>

```text
Hello, Go!
Device: sensor-01
Status: ready
```

</details>

<details>
<summary>อธิบายโค้ดและวิธีตรวจเมื่อผลไม่ตรง</summary>

- `package main` ระบุว่าไฟล์นี้อยู่ใน package สำหรับสร้างโปรแกรมที่รันได้ **package** คือกลุ่มไฟล์ Go ที่ทำงานร่วมกัน
- `import "fmt"` ทำให้เรียกใช้ package `fmt` ซึ่งมีเครื่องมือจัดรูปแบบและแสดงข้อความ ชื่อมาจากคำว่า format การ import อย่างเดียวยังไม่พิมพ์อะไร
- `func main()` คือจุดเริ่มทำงานของโปรแกรม คำสั่งใน `{ }` ทำตามลำดับ
- `Print` ไม่เติมบรรทัดใหม่ ส่วน `Println` เติมบรรทัดใหม่ท้ายการแสดงผล ข้อความใน `" "` เรียกว่า **string**

**ลองตรวจเมื่อผิด:** ลองเปลี่ยน `Println` เป็น `PrintIn` (ตัว I ใหญ่) แล้วรัน อ่านชื่อไฟล์และเลขบรรทัดใน error: Go แยกตัวพิมพ์เล็กใหญ่และสะกดชื่อตรงตัว แก้ชื่อแล้วรันซ้ำ ถ้าผลยังเหมือนเดิมให้ตรวจว่าได้บันทึกไฟล์แล้ว

</details>

## ฝึกเอง

ใช้ `practics/main.go` เดิม เริ่มแต่ละข้อจากตัวอย่างของบทนี้ ไม่ต้องสร้างโฟลเดอร์แยกโจทย์ หากต้องการเก็บงานเดิมให้คัดลอกเป็นไฟล์ .txt ก่อนเปลี่ยนโค้ด

1. เปลี่ยนชื่ออุปกรณ์เป็น `sensor-02` และสถานะเป็น `waiting` โดยยังแสดงผล 3 บรรทัด
2. ทำให้ชื่ออุปกรณ์อยู่คนละบรรทัดกับ `Device:` โดยเปลี่ยนคำสั่งแสดงผลเพียงหนึ่งจุด

ทำก่อนแล้วค่อยดู [เฉลยพร้อมเหตุผล](solutions/README.md)

**ลองอธิบาย:** ทำไมมี `import "fmt"` แล้วจึงยังต้องเรียก `fmt.Println` อีก?

<details>
<summary>แนวคำตอบ</summary>

import ทำให้ใช้ชื่อและเครื่องมือของ package ได้ ส่วนการเรียกฟังก์ชันภายใน main จึงทำให้เกิดงานแสดงข้อความ

</details>
