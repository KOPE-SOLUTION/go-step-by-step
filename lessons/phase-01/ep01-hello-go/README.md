# EP.1 — เขียนและรันโปรแกรม Go แรก

**เป้าหมาย:** รันโปรแกรม อ่านส่วนประกอบ และแก้ข้อผิดพลาดง่าย ๆ ได้ด้วยตัวเอง

**ก่อนเริ่ม:** มี Go พร้อมใช้งานและเปิดไฟล์ในโปรแกรมแก้ไขโค้ดได้

## ทำความเข้าใจ

Go เป็นภาษาสำหรับเขียนโปรแกรม เช่น เครื่องมือที่สั่งงานด้วยข้อความและบริการรับส่งข้อมูล ในบทนี้เราจะเขียนโปรแกรมแสดงข้อความทักทาย ชื่ออุปกรณ์ และสถานะ โดยใช้ข้อมูลจำลอง

**Terminal** คือหน้าต่างสำหรับพิมพ์คำสั่ง ส่วน **compiler** คือเครื่องมือตรวจและแปลโค้ดให้เป็นโปรแกรมที่เครื่องรันได้

คำสั่ง `go run` จะคอมไพล์ (ตรวจและแปล) โค้ด แล้วรันโปรแกรมเมื่อคอมไพล์สำเร็จ หากคอมไพล์ไม่ผ่าน Go จะแสดงข้อความข้อผิดพลาดและยังไม่รันโปรแกรม

## ลงมือทำ

1. ตรวจเครื่องมือด้วย `go version` ถ้าคำสั่งไม่ทำงาน ดู [วิธีตรวจปัญหา](../../../notes/troubleshooting.md)
2. สร้าง `practics/main.go` ตาม [วิธีเริ่มฝึก](../../../docs/PRACTICE.md) พิมพ์ส่วน `package`, `import` และ `func main()` ตามตัวอย่างด้านล่าง โดยใส่เพียง `fmt.Println("Hello, Go!")` ภายใน `{ }` ของ `main` ก่อน
3. รันให้สำเร็จก่อน แล้วเพิ่มข้อความอุปกรณ์และสถานะตามตัวอย่างเต็ม ลองคาดเดาว่า `Print` และ `Println` ต่างกันอย่างไร

### ตัวอย่างเมื่อทำครบ

ไฟล์ [main.go](main.go):

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
	fmt.Print("Device: ")
	fmt.Println("sensor-01")
	fmt.Println("Status: ready")
}
```

### รันและตรวจผล

งานฝึก: เปิด terminal ที่ `practics` แล้วรัน:

```shell
go run main.go
```

ถ้ารันตัวอย่างที่ให้มาโดยตรง ให้เปิด terminal ที่ `lessons/phase-01/ep01-hello-go` แล้วใช้ `go run .` ใช้ได้ทั้ง terminal ใน VS Code, PowerShell และ cmd

ก่อนเปิดผลลัพธ์ ลองคาดเดาว่าคำสั่งใดพิมพ์ข้อความต่อกัน และทั้งหมดจะแสดงกี่บรรทัด

<details>
<summary>ผลลัพธ์ที่คาดหวัง</summary>

```text
Hello, Go!
Device: sensor-01
Status: ready
```

</details>

<details>
<summary>อธิบายโค้ด</summary>

- `package main` ระบุว่าไฟล์นี้อยู่ใน package สำหรับสร้างโปรแกรมที่รันได้ **package** คือกลุ่มไฟล์ Go ที่ทำงานร่วมกัน
- `import "fmt"` ทำให้เรียกใช้ package `fmt` ซึ่งมีเครื่องมือจัดรูปแบบและแสดงข้อความ ชื่อมาจากคำว่า format การ import อย่างเดียวยังไม่พิมพ์อะไร
- `func main()` คือจุดเริ่มทำงานของโปรแกรม คำสั่งใน `{ }` ทำตามลำดับ
- `Print` ไม่เติมบรรทัดใหม่ ส่วน `Println` เติมบรรทัดใหม่ท้ายการแสดงผล ข้อความใน `" "` เรียกว่า **string**

</details>

## ลองทำให้ผิด แล้วแก้ข้อผิดพลาด

ใช้ `practics/main.go` ที่รันสำเร็จแล้ว ทดลองทีละขั้นเพื่อดูว่า Go ช่วยบอกจุดที่ต้องแก้อย่างไร

### 1. เปลี่ยนชื่อให้ผิดแล้วลองรัน

เปลี่ยนเฉพาะบรรทัดทักทายจาก `fmt.Println("Hello, Go!")` ให้ตัว **P ใหญ่เป็น p เล็ก**:

```go
fmt.println("Hello, Go!")
```

ก่อนรัน ลองคาดเดาว่าข้อความสามบรรทัดจะยังปรากฏหรือไม่ จากนั้นบันทึกไฟล์ แล้วรันจาก `practics`:

```shell
go run main.go
```

### 2. อ่านว่าผิดตรงไหน

บรรทัดสำคัญที่ตรวจพบจริงบนเครื่องนี้:

```text
.\main.go:6:6: undefined: fmt.println (but have Println)
```

- `main.go:6:6` ชี้ไฟล์ บรรทัดที่ 6 และคอลัมน์ที่ 6
- `undefined: fmt.println` หมายถึงไม่พบชื่อนี้ใน package fmt ชื่อที่มีคือ `Println` โดยขึ้นต้นด้วย P ใหญ่

เลขบรรทัดและข้อความประกอบอาจต่างกันตามโค้ดและรุ่น Go ให้ดูชื่อที่รายงานเป็นหลัก กรณีนี้คอมไพล์ไม่ผ่าน โปรแกรมจึงยังไม่เริ่มพิมพ์ข้อความ

### 3. แก้ชื่อและรันซ้ำ

เปลี่ยนกลับเป็น:

```go
fmt.Println("Hello, Go!")
```

บันทึกไฟล์ แล้วใช้ `go run main.go` อีกครั้ง ต้องได้ข้อความทักทาย ชื่ออุปกรณ์ และสถานะครบสามบรรทัดเหมือนเดิม ถ้ายังเห็น error เดิม ให้ตรวจว่าแก้และบันทึกไฟล์ในโฟลเดอร์ที่กำลังรัน

**สิ่งที่ได้ฝึก:** อ่านชื่อไฟล์และตำแหน่ง → ตรวจชื่อที่ Go หาไม่พบ → แก้ทีละจุด → รันยืนยันผล

## ฝึกเอง

ฝึกใน `practics/main.go` ไฟล์เดิม ก่อนทำแต่ละข้อให้ใส่โค้ดตัวอย่างเต็มของบทนี้ แล้วแก้ตามโจทย์ หากต้องการเก็บคำตอบข้อก่อนหน้า ให้คัดลอกเป็นไฟล์ `.txt` ก่อน

1. เปลี่ยนชื่ออุปกรณ์เป็น `sensor-02` และสถานะเป็น `waiting` โดยยังแสดงผล 3 บรรทัด
2. ทำให้ชื่ออุปกรณ์อยู่คนละบรรทัดกับ `Device:` โดยเปลี่ยนคำสั่งแสดงผลเพียงหนึ่งจุด

ทำก่อนแล้วค่อยดู [เฉลยพร้อมเหตุผล](solutions/README.md)

**ลองอธิบาย:** ทำไมมี `import "fmt"` แล้วจึงยังต้องเรียก `fmt.Println` อีก?

<details>
<summary>แนวคำตอบ</summary>

`import "fmt"` ทำให้โค้ดเรียกใช้ฟังก์ชันจาก package `fmt` ได้ แต่ข้อความจะปรากฏเมื่อโปรแกรมเรียก `fmt.Print` หรือ `fmt.Println`

</details>

**นำไปใช้ต่อ:** รันโปรแกรม อ่านลำดับคำสั่ง และใช้ข้อความ error ช่วยหาจุดผิด ก่อนเพิ่มข้อมูลใน EP ถัดไป
