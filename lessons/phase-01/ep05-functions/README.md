# EP.5 — แยกงานด้วยฟังก์ชัน รับค่าและคืนค่า

**เป้าหมาย:** แยกการแปลงหน่วยและการตัดสินสถานะออกจากการแสดงผล แล้วเรียกซ้ำได้

**ก่อนเริ่ม:** EP.3–4 — เงื่อนไขและลูป

## ทำความเข้าใจ

**ฟังก์ชัน** คือชุดคำสั่งที่ตั้งชื่อเพื่อเรียกใช้ **parameter** คือช่องรับข้อมูลที่ประกาศไว้ และ **return value** คือผลที่ส่งกลับไปยังผู้เรียก เช่น รับ Celsius แล้วคืน Fahrenheit

## ลงมือทำ

1. ย้ายสูตรแปลงหน่วยจาก main ไปไว้ใน `toFahrenheit` แล้วลองเรียกด้วยค่า 0 และ 100
2. เพิ่ม `status` ให้รับทั้งค่าการวัดและเกณฑ์เตือน แทนการฝังเกณฑ์ไว้ภายใน
3. ให้ main รับผลมาแสดงตามตัวอย่าง ทดลองใช้ค่าการวัดเดียวกันกับเกณฑ์สองค่า เพื่อดูว่าฟังก์ชันใช้ซ้ำได้อย่างไร

### ตัวอย่างเมื่อทำครบ

ไฟล์ [main.go](main.go):

```go
package main

import "fmt"

func toFahrenheit(celsius float64) float64 {
	return celsius*9/5 + 32
}

func status(celsius, threshold float64) string {
	if celsius >= threshold {
		return "WARNING"
	}
	return "OK"
}

func main() {
	celsius := 30.0
	fmt.Printf("%.1f C = %.1f F [%s]\n",
		celsius, toFahrenheit(celsius), status(celsius, 30))
	fmt.Println("at threshold 35:", status(celsius, 35))
}
```

### รันและตรวจผล

งานฝึก: เปิด terminal ที่ `practics` แล้วรัน:

```shell
go run main.go
```

ถ้ารันตัวอย่างที่ให้มาโดยตรง ให้เปิด terminal ที่ `lessons/phase-01/ep05-functions` แล้วใช้ `go run .` ใช้ได้ทั้ง terminal ใน VS Code, PowerShell และ cmd

ก่อนเปิดผลลัพธ์ ลองคาดเดาว่าข้อมูลแต่ละรายการจะถูกจัดการอย่างไร

<details>
<summary>ผลลัพธ์ที่คาดหวัง</summary>

```text
30.0 C = 86.0 F [WARNING]
at threshold 35: OK
```

</details>

<details>
<summary>อธิบายโค้ดและวิธีตรวจเมื่อผลไม่ตรง</summary>

- `func toFahrenheit(celsius float64) float64` ระบุชื่อ ช่องรับค่า และชนิดผลลัพธ์ตามลำดับ
- `return` ส่งผลกลับและจบการเรียกฟังก์ชันครั้งนั้น ส่วน `Println` แสดงข้อความ จึงทำหน้าที่ต่างกัน
- `celsius, threshold float64` คือ parameter สองตัวชนิดเดียวกัน
- ชื่อภายในฟังก์ชันใช้ได้ในขอบเขตของมัน เรียกว่า **scope** ตัวแปร celsius ใน main กับ parameter ที่ชื่อเหมือนกันอยู่คนละขอบเขต
- การแยกคำนวณออกจากการพิมพ์เป็นแนวทางออกแบบ ช่วยให้ใช้กับรายงานหรือ API และทดสอบได้ง่ายขึ้น ไม่ใช่ข้อบังคับของภาษา

**ลองตรวจเมื่อผิด:** ฟังก์ชันที่ประกาศว่าคืนค่าต้องคืนค่าให้ครบทุกทางเดิน และเรียกด้วยจำนวนกับชนิด argument ให้ตรง ลองอ่าน signature ซึ่งเป็นส่วนชื่อและชนิดรับ/คืนก่อนแก้

</details>

## ฝึกเอง

ใช้ `practics/main.go` เดิม เริ่มแต่ละข้อจากตัวอย่างของบทนี้ ไม่ต้องสร้างโฟลเดอร์แยกโจทย์ หากต้องการเก็บงานเดิมให้คัดลอกเป็นไฟล์ .txt ก่อนเปลี่ยนโค้ด

1. เพิ่มฟังก์ชัน `toCelsius(fahrenheit float64) float64` ใช้สูตร `(fahrenheit - 32) * 5 / 9` แล้วพิมพ์ผลของ 86 F ต่อท้าย
2. ใช้ for เรียก status กับค่า 29, 30 และ 31 โดยใช้เกณฑ์ 30 แล้วพิมพ์ผลแต่ละค่า แทน main เดิม

ทำก่อนแล้วค่อยดู [เฉลยพร้อมเหตุผล](solutions/README.md)

**ลองอธิบาย:** ถ้า status พิมพ์ WARNING เอง แต่ไม่คืนค่า จะนำข้อความนั้นไปประกอบรายงานได้สะดวกเหมือนเดิมหรือไม่?

<details>
<summary>แนวคำตอบ</summary>

ไม่ การคืนค่าช่วยให้ผู้เรียกเลือกได้ว่าจะพิมพ์ เก็บ หรือใช้ต่อ ส่วนการพิมพ์ภายในผูกฟังก์ชันไว้กับการแสดงผล

</details>
