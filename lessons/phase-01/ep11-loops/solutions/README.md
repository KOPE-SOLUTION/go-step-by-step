## คำถามทบทวน

ค่าเริ่มต้น เงื่อนไข และการเพิ่มค่า ทำงานในลำดับใด?

ตั้งค่าเริ่มต้นหนึ่งครั้ง → ตรวจเงื่อนไข → ทำเนื้อหา → เพิ่มค่า → กลับไปตรวจเงื่อนไข
