# เฉลย EP.11

ลองทำ [แบบฝึกหัด](../exercises/README.md) ด้วยตนเองก่อนอ่านเฉลย โค้ดอาจเขียนต่างจากตัวอย่างได้ หากให้ผลตรงตามโจทย์

คำสั่งด้านล่างรันจากโฟลเดอร์ต้นฉบับ `lessons/phase-01/ep11-loops` ไม่ใช่โฟลเดอร์ practics ซึ่งไม่มีเฉลย

## ข้อ 1

ขยายเงื่อนไขเป็น <= 5

ดู [main.go](01/main.go)

```powershell
go run ./solutions/01
```

ผล:

```text
sample 1
sample 2
sample 3
sample 4
sample 5
```

## ข้อ 2

ตรวจเงื่อนไขก่อนรอบแรกจึงได้ศูนย์ครั้ง

ดู [main.go](02/main.go)

```powershell
go run ./solutions/02
```

ผล:

```text
DONE
```

## คำถามทบทวน

ค่าเริ่มต้น เงื่อนไข และการเพิ่มค่า ทำงานในลำดับใด?

ตั้งค่าเริ่มต้นหนึ่งครั้ง → ตรวจเงื่อนไข → ทำเนื้อหา → เพิ่มค่า → กลับไปตรวจเงื่อนไข

## ฝึกทบทวนด้วยตนเอง

ปิดเฉลย เปลี่ยนค่าหนึ่งจุดในพื้นที่ฝึก แล้วอธิบายผลด้วยตนเอง [กลับบทเรียน](../README.md)
