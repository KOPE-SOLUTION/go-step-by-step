# แบบฝึกหัด EP.3 — พิมพ์หลายบรรทัดและอ่านลำดับคำสั่ง

ก่อนแก้ ใช้พื้นที่ `practics/phase-01/ep03-output-lines` ตาม [วิธีฝึก](../../../../docs/PRACTICE.md) เก็บผลคาดเดาก่อนรัน ไม่แก้ตัวอย่างต้นฉบับ

## ข้อ 1

พิมพ์ READY ก่อน Device: sensor-01

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข

## ข้อ 2

ใช้ Println สองครั้งให้ได้ Device: sensor-01 และ STOPPED คนละบรรทัด

1. คาดเดาผลลัพธ์และเขียนเหตุผลสั้น ๆ
2. แก้ในพื้นที่ฝึก บันทึก แล้วรัน `go run ./examples`
3. เปรียบเทียบผลจริงกับที่คาด หากต่างกัน ให้อ่านข้อความผิดพลาดหรือตรวจค่าตามลำดับคำสั่งก่อนแก้ไข
