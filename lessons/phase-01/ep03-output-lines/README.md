# EP.3 — พิมพ์หลายบรรทัดและอ่านลำดับคำสั่ง

**เป้าหมาย:** คาดเดาลำดับข้อความและแยก Print กับ Println ได้

## 1. อ่านโค้ด

โปรแกรมทำคำสั่งจากบนลงล่าง `Print` พิมพ์ต่อในบรรทัดเดิม ส่วน `Println` พิมพ์แล้วขึ้นบรรทัดใหม่

ไฟล์ [examples/main.go](examples/main.go)

```go
package main

import "fmt"

func main() {
	fmt.Print("Device: ")
	fmt.Println("sensor-01")
	fmt.Println("READY")
}
```

## 2. ลองรัน

**ก่อนรัน:** เรียกฟังก์ชันพิมพ์ 3 ครั้ง จะได้ 3 บรรทัดเสมอหรือไม่?

รันจากโฟลเดอร์ `lessons/phase-01/ep03-output-lines`:

```shell
go run ./examples
```

## 3. ฝึกเอง

ใช้ **`practics/main.go` ไฟล์เดิม** เปลี่ยนเนื้อหาทั้งไฟล์เป็นโค้ดจาก [ตัวอย่าง EP นี้](examples/main.go) แล้วทำโจทย์ด้านล่าง

ถ้ายังไม่มีไฟล์ ให้สร้างโฟลเดอร์ `practics` ใน `Go` แล้วสร้าง `main.go` ข้างใน ไม่ต้องมี `examples` หรือ `go.mod` ดู [วิธีสร้างครั้งแรก](../../../docs/PRACTICE.md)

**แก้ `main.go` ในโฟลเดอร์ฝึก** ทีละข้อ:

1. สลับคำสั่งให้แสดง `READY` ก่อน `Device: sensor-01`
2. ใช้ `Println` สองครั้งให้แสดง `Device: sensor-01` และ `STOPPED` คนละบรรทัด

บันทึกไฟล์ (Ctrl+S) แล้วรันจาก **`practics`**:

```shell
go run main.go
```

<details>
<summary>อ่านเพิ่มเติมเมื่อสงสัย</summary>

เหมือนรายการงานบนกระดาษ โปรแกรมสั้นนี้ทำบรรทัดบนก่อนบรรทัดล่าง การเห็นคำว่า READY เป็นเพียงข้อความ ไม่ได้หมายความว่าเชื่อมต่ออุปกรณ์แล้ว

**ลำดับคำสั่ง** คือก่อน–หลังที่โค้ดส่วนนี้ทำงาน; `Print` แสดงค่าโดยไม่เติมบรรทัดใหม่ ส่วน `Println` เติมบรรทัดใหม่หลังค่า

- Print แรกยังไม่ขึ้นบรรทัดใหม่ ข้อความจาก Println ถัดไปจึงต่อในบรรทัดเดียวกัน
- เว้นวรรคหลัง `Device:` อยู่ใน string ถ้าเอาออกข้อความจะติดกัน
- ตัวอย่างนี้ไม่มีงานพร้อมกัน ลำดับการเรียกทั้งสามจึงอ่านจากบนลงล่างได้

**ข้อผิดพลาดที่พบบ่อย**

- ใช้ Print แล้วข้อความติดกัน: ไม่มีการเติม newline ให้อัตโนมัติ
- ลืมช่องว่างภายใน quote: โปรแกรมทำตาม string ที่เขียนจริง
