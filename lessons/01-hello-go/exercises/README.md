# แบบฝึกหัดเพิ่มเติม — Hello Go

ใช้ทบทวนหลัง EP2–4 ใน [พื้นที่ฝึกส่วนตัว](../../../docs/PRACTICE.md)

## ข้อ 1 — เปลี่ยนข้อความ

ให้โปรแกรมแสดง `Hello, learner!` หนึ่งบรรทัด ต้องแก้ส่วนใดของโค้ด?

## ข้อ 2 — เพิ่มอีกบรรทัด

เพิ่มคำสั่งให้ได้ผลตามนี้ แล้วลองสลับลำดับคำสั่ง:

```text
Hello, learner!
Gateway simulator is starting.
```

## ข้อ 3 — อ่านข้อผิดพลาด

เปลี่ยน `Println` เป็น `println` ในไฟล์ฝึก แล้วรัน อ่าน error ก่อนแก้กลับให้ถูกต้อง

รันจากพื้นที่ฝึก EP1 เดิมด้วย `go run .` หากสร้างด้วยสคริปต์ใหม่ ให้ใช้ `go run ./examples/hello` ตามตำแหน่งที่สคริปต์แจ้ง
