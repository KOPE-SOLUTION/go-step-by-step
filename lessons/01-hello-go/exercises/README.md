# แบบฝึกหัด — ลองก่อนเปิดเฉลย

ตั้งแต่แบ่งหลักสูตรเป็น Phase ให้แก้งานของตัวเองใน `Go/practics/phase-01/ep01-hello-go/main.go` ซึ่ง Git ignore ทั้งหมด รันจากโฟลเดอร์นั้นด้วย `go run .` ดู [วิธีเลือกโฟลเดอร์ฝึก](../../../docs/PRACTICE.md) บันทึกผลแต่ละข้อก่อนแก้ไฟล์เดิมเพื่อทำข้อถัดไป

`exercises/my-hello/main.go` เดิมยังเก็บเป็น starter อ้างอิง ไม่ลบหรือเขียนทับงานเดิม ข้อฝึกในหน้านี้ใช้สำหรับ EP.2–3 หลังเรียน EP.1 แล้ว และยังต้องรอผู้เรียนขอไปต่อ

## ข้อ 1: เปลี่ยนคำทักทาย

เปลี่ยนข้อความให้ได้ผลลัพธ์หนึ่งบรรทัดตามนี้:

```text
Hello, learner!
```

ก่อนรัน: จะต้องเปลี่ยนชื่อ package หรือชื่อฟังก์ชันด้วยไหม? เพราะอะไร?

```powershell
go run .
```

เกณฑ์: ข้อความตรงตามโจทย์ ไม่มีเครื่องหมายคำพูดในผลลัพธ์ อธิบายได้ว่าเปลี่ยนส่วนที่เป็นข้อมูล

คำใบ้: มองข้อความที่อยู่ระหว่าง `"` ยังไม่ต้องเรียนตัวแปร

## ข้อ 2: ข้อความสองบรรทัด

ต่อจากข้อ 1 เพิ่มคำสั่งให้ได้:

```text
Hello, learner!
Gateway simulator is starting.
```

คาดเดาก่อนรันว่าคำสั่งไหนทำงานก่อน ใช้คำสั่งรันเดิม หากสลับลำดับสองคำสั่ง ผลจะเป็นอย่างไร? ลองจริงแล้วคืนลำดับตามโจทย์

เกณฑ์: มีสองบรรทัดตามลำดับ และอธิบายได้ว่าข้อความเกี่ยวกับ gateway ยังเป็นข้อความธรรมดา ไม่ได้เปิดอุปกรณ์หรือบริการใด

คำใบ้: `Println` หนึ่งครั้งในตัวอย่างนี้พิมพ์ข้อความและขึ้นบรรทัดใหม่

## ข้อ 3: ทดลองทำให้ผิด แล้วหาสาเหตุ

ในไฟล์ฝึก เปลี่ยน `Println` ของคำสั่งแรกเป็น `println` จากนั้นบันทึก ก่อนรันให้ทายว่าจะเกิดอะไร

1. รันแล้วจดคำสั่ง โฟลเดอร์ เลขบรรทัด และ error จริง
2. อธิบายว่าต่างจากกรณีหา `go` ไม่พบอย่างไร
3. ตรวจเอกสาร `fmt` หรือเทียบตัวอย่าง หาจุดที่ต้องแก้เพียงจุดเดียว
4. แก้แล้วรันซ้ำให้ผลกลับมาตรงข้อ 2

เกณฑ์: อธิบายได้ว่าตัวใหญ่เล็กเป็นส่วนหนึ่งของชื่อ และแยกปัญหาเครื่องมือออกจากปัญหาโค้ดได้ อย่าแก้ไฟล์ตัวอย่างหรือหลายจุดพร้อมกัน

เมื่อได้ลองครบแล้วจึงเปิดโฟลเดอร์ `solutions` ไม่ต้องถือว่าคำตอบเหมือนเฉลยทุกตัวอักษรหากผลตรงและอธิบายเหตุผลได้
