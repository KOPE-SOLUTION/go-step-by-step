# EP.1 — รัน Go ครั้งแรก

**เป้าหมาย:** เปิด PowerShell และรันโปรแกรมให้แสดงข้อความหนึ่งบรรทัด

## 1. ตรวจสอบ Go

เปิด **PowerShell** จากเมนู Start แล้วพิมพ์คำสั่งนี้ หน้าต่างสำหรับพิมพ์คำสั่งเรียกว่า terminal

```powershell
go version
```

ถ้าเห็นเลขเวอร์ชัน แสดงว่า Go พร้อมใช้ หากไม่พบคำสั่ง ดู [วิธีตรวจเครื่องมือ](../../notes/troubleshooting.md)

## 2. ลองรันโปรแกรม

เลือกโฟลเดอร์บทเรียนบนเครื่องนี้ แล้วตรวจตำแหน่ง:

```powershell
Set-Location -LiteralPath 'C:\Users\kopes\Documents\Codex\2026-09-17\go-youtube-go-iot-edge-gateway\Go\lessons\01-hello-go'
Get-Location
```

ถ้าเก็บหลักสูตรไว้ที่อื่น ให้เปลี่ยนเส้นทางให้ตรง ส่วนท้ายควรเป็น `lessons\01-hello-go`

เปิด [main.go](examples/hello/main.go) แล้วดูบรรทัดนี้ ซึ่งสั่งแสดงข้อความ:

```go
fmt.Println("Hello, Go!")
```

**ก่อนรัน:** จะเห็นข้อความอะไร? เครื่องหมายคำพูดจะปรากฏด้วยหรือไม่?

```powershell
go run ./examples/hello
```

<details>
<summary>ดูผลที่คาดหวังหลังลองรัน</summary>

```text
Hello, Go!
```

เมื่อหน้าต่างกลับมารอรับคำสั่ง โปรแกรมทำงานเสร็จแล้ว

</details>

## 3. ลองด้วยตนเอง

1. รันซ้ำอีกครั้ง ผลเหมือนเดิมหรือไม่?
2. อธิบายว่า `go version` กับ `go run` ต่างกันอย่างไร

<details>
<summary>คำอธิบายเพิ่มเติมและวิธีแก้ปัญหา</summary>

Go คือภาษาโปรแกรม ส่วนคำสั่ง go ใช้เรียกเครื่องมือของภาษา go run เตรียมโปรแกรมจากโค้ดแล้วรัน จึงอาจใช้เวลาสักครู่ในครั้งแรก

- ไม่พบคำสั่ง go: เปิด PowerShell ใหม่ หากยังไม่ได้ ดู [การติดตั้ง](../../notes/setup-windows.md)
- หาโฟลเดอร์ไม่พบ: ตรวจเส้นทางที่ใส่ใน Set-Location
- พบ no Go files: ตรวจว่ารัน `go run ./examples/hello` จากโฟลเดอร์บทเรียน
