# EP.1 — เปิดหน้าต่างคำสั่ง แล้วรัน Go ครั้งแรก

อัปเดต 2026-09-19 • เรียนทีละขั้นและหยุดทบทวนได้ตามต้องการ

## วันนี้เอาแค่ไหน

ตอนนี้อยู่ใน **Phase 1 — Go Basic** ดู [สารบัญ Playlist](../../docs/playlist-01-go-basic/README.md) EP.1 ยังทดลองรันตัวอย่างเดิมได้ เมื่อเริ่มแก้โค้ดในตอนถัดไปใช้ [practics](../../docs/PRACTICE.md) ซึ่งแยกจากต้นฉบับและไม่เข้า Git ตามปกติ

เป้าหมายเล็ก ๆ คือเปิด PowerShell ตรวจว่า Go พร้อม และรันโปรแกรมที่เตรียมไว้หนึ่งครั้ง ไม่ต้องจำโค้ด ไม่ต้องเขียนจากความจำ และยังไม่ต้องอ่านเอกสารทั้งบท

ก่อนเริ่ม: ใช้แป้นพิมพ์และเปิดโปรแกรมบน Windows ได้ หากยังไม่คุ้นกับการคัดลอกคำสั่ง ให้ลองทีละบรรทัด ดูผลตรวจเครื่องได้ในบันทึกของบท แล้วลองคำสั่งด้วยตนเองเพื่อยืนยันผล

คำใหม่วันนี้มีเพียง 3 คำ:

- **โปรแกรม:** ชุดคำสั่งที่ให้คอมพิวเตอร์ทำงาน เช่นแสดงข้อความหนึ่งบรรทัด
- **Terminal:** หน้าต่างที่เราพิมพ์คำสั่งแล้วกด Enter ในบทนี้ใช้โปรแกรมชื่อ PowerShell
- **โฟลเดอร์ปัจจุบัน:** ตำแหน่งที่หน้าต่างคำสั่งกำลังทำงาน เหมือนยืนอยู่หน้าลิ้นชักหนึ่งช่องก่อนหยิบไฟล์

Go คือภาษาที่ใช้เขียนโปรแกรม ส่วนคำสั่ง `go` ใช้เรียกเครื่องมือของภาษานี้ วันนี้ใช้เพียงตรวจเวอร์ชันและสั่งรัน ยังไม่ต้องจำคำว่า module หรือ package

## จังหวะที่ 1 — เปิดหน้าต่างคำสั่ง

1. กดปุ่ม Windows บนแป้นพิมพ์
2. พิมพ์ `PowerShell` แล้วเปิดโปรแกรมชื่อนี้ หน้าต่างอาจสีดำหรือสีน้ำเงิน สีไม่มีผลกับบทเรียน
3. ถ้าเปิดหน้าต่างนี้ค้างไว้ตั้งแต่ก่อนติดตั้ง Go ให้ปิดแล้วเปิดใหม่
4. พิมพ์คำสั่งนี้ แล้วกด Enter หนึ่งครั้ง:

```powershell
go version
```

ก่อนกด Enter ลองคิด: คำสั่งนี้น่าจะตรวจเครื่องมือ หรือรันโปรแกรมทักทายของเรา?

ถ้าเห็นบรรทัดขึ้นต้นด้วย `go version` ตามด้วยเลขรุ่น แปลว่าเรียกเครื่องมือได้ บนเครื่องที่เตรียมครั้งนี้ควรเป็น `go version go1.27.1 windows/amd64` ยังไม่ต้องจำเลขรุ่น

**จุดตรวจ:** หากไม่รู้จักคำสั่ง ให้เปิด PowerShell จากเมนู Start ใหม่ หากยังไม่ได้ เก็บข้อความ error แล้วดู [วิธีตรวจเครื่องมือ](../../notes/troubleshooting.md) ก่อนทำขั้นถัดไป PATH คือรายการตำแหน่งที่ Windows ใช้ค้นหาโปรแกรม ไม่ต้องเดาสุ่มแก้ค่าระบบ

## จังหวะที่ 2 — ไปให้ถูกโฟลเดอร์

เมื่อจังหวะแรกผ่านและพร้อมแล้ว คัดลอกบรรทัดนี้ลง PowerShell แล้วกด Enter:

```powershell
Set-Location -LiteralPath 'C:\Users\kopes\Documents\Codex\2026-09-17\go-youtube-go-iot-edge-gateway\Go\lessons\01-hello-go'
```

คำสั่งนี้เลือกโฟลเดอร์ที่จะทำงาน ชื่อคำสั่งยาวจึงคัดลอกได้ ไม่ต้องท่อง ตรวจตำแหน่งด้วย:

```powershell
Get-Location
```

ส่วนท้ายของตำแหน่งควรเป็น `Go\lessons\01-hello-go` การเปลี่ยนตำแหน่งไม่ใช่การย้ายหรือลบไฟล์ หากไม่เจอโฟลเดอร์ ให้ตรวจเส้นทางก่อน ไม่สร้างไฟล์ใหม่เพื่อกลบข้อผิดพลาด

## จังหวะที่ 3 — มองโปรแกรมสั้น ๆ

โปรแกรมที่จะรันอยู่ใน `examples/hello/main.go` เปิดไฟล์นี้ด้วย editor ที่มีอยู่ เนื้อหาคือ:

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}
```

วันนี้มองแค่บรรทัด `fmt.Println("Hello, Go!")` ซึ่งสั่งแสดงข้อความในเครื่องหมายคำพูดแล้วขึ้นบรรทัดใหม่ ส่วนที่เหลือเป็นโครงที่โปรแกรมนี้ต้องใช้ เราจะอธิบายทีละส่วนใน EP.2 ไม่ได้ขอให้จำหรือแก้ส่วนที่ยังไม่เข้าใจ

แยกประเภทให้ชัด: รูปแบบการเขียนนี้เป็นเรื่องของภาษา ส่วนชื่อโฟลเดอร์ examples/hello เป็นรูปแบบการจัดเก็บของบทเรียน และใช้ editor ตัวใดเป็นทางเลือกของผู้เรียน

## จังหวะที่ 4 — คาดเดาแล้วค่อยรัน

ลองตอบก่อน: จะเห็นข้อความอะไร? เครื่องหมายคำพูดจะติดออกมาหรือไม่? ไม่ต้องเปิดเฉลยก่อนตอบ

จากตำแหน่งในจังหวะที่ 2 พิมพ์:

```powershell
go run ./examples/hello
```

`go run` สั่งให้เครื่องมือเตรียมโปรแกรมจากโค้ดแล้วรัน ส่วน `./examples/hello` เลือกโฟลเดอร์ตัวอย่างใต้ตำแหน่งปัจจุบัน หากรอนานในการรันครั้งแรก ให้รอคำสั่งจบ ไม่กด Enter ซ้ำหลายครั้ง

เทียบผลจริงกับคำที่คุณทายไว้ ถ้าต้องการตรวจคำตอบ เปิด [ผลที่คาดหวังและเหตุผล](solutions/ep01.md) หลังลองแล้ว เมื่อหน้าต่างกลับมารอคำสั่งใหม่ โปรแกรมนี้ทำงานจบแล้ว ไม่ใช่อาการพัง

## ลองเอง 2 ข้อ

1. อธิบายด้วยคำของตัวเองว่า `go version` กับ `go run ./examples/hello` ใช้ทำอะไรต่างกัน ไม่ต้องตอบด้วยศัพท์เทคนิค
2. รันคำสั่งเดิมอีกหนึ่งครั้ง ก่อนรันทายว่าข้อความจะเหมือนเดิมไหม แล้วจดว่าผลจริงตรงกับที่คิดหรือไม่ โดยยังไม่แก้โค้ด

คำถามทบทวน: การเห็นข้อความบนหน้าจอพิสูจน์ว่าโปรแกรมอ่านอุปกรณ์จริงได้แล้วหรือยัง? เรารู้ได้อย่างไรว่าเลือกโฟลเดอร์ถูก?

## ถ้ายังทำไม่ได้

| สิ่งที่เห็น | ทำเพียงขั้นนี้ก่อน |
|---|---|
| ไม่รู้จักคำสั่ง go | เปิด PowerShell ใหม่จาก Start แล้วลอง go version เก็บผลไว้แล้วดู troubleshooting |
| หาโฟลเดอร์ไม่พบ | ตรวจบรรทัด Set-Location และเก็บข้อความ error |
| no Go files | ตรวจว่าคำสั่งมี `./examples/hello` ต่อท้าย ไม่ใช่แค่ `go run .` |
| หน้าจอมีข้อความผิดพลาดอื่น | หยุดและส่งข้อความจริง ไม่จำเป็นต้องเดาแก้เอง |

วันนี้คุณฝึกวงจร “สั่ง → ดูผล → เปรียบเทียบ” ซึ่งจะใช้ซ้ำกับข้อมูลอุปกรณ์จำลองในภายหลัง ดู [ผลตรวจตัวอย่าง](tests/RESULTS.md) และบันทึกสิ่งที่คุณทำเองได้ใน PROGRESS.md

จบ EP.1 ได้เมื่อทำซ้ำด้วยตนเองและเล่าสิ่งที่เกิดขึ้นได้ เราจะไม่เริ่ม EP.2 จนกว่าคุณจะขอ ความช้าไม่ใช่เหตุผลให้ข้ามขั้น
