# EP.1 — รัน Go ครั้งแรก

**เป้าหมาย:** รันโปรแกรม Go ให้แสดงข้อความหนึ่งบรรทัด

## 1. ตรวจสอบ Go

Terminal คือหน้าต่างสำหรับพิมพ์คำสั่ง ใช้ terminal ใน **VS Code** หรือเปิด **PowerShell / Command Prompt (cmd)** ก็ได้ แล้วพิมพ์:

```shell
go version
```

ถ้าเห็นเลขเวอร์ชัน แสดงว่า Go พร้อมใช้ หากไม่พบคำสั่ง ดู [วิธีตรวจเครื่องมือ](../../notes/troubleshooting.md)

## 2. ลองรันโปรแกรม

เปิด terminal ที่โฟลเดอร์ `lessons/01-hello-go` ถ้าใช้ VS Code ให้คลิกขวาโฟลเดอร์นี้ในแถบ Explorer แล้วเลือก **Open in Integrated Terminal**

ถ้า terminal อยู่ในโฟลเดอร์บทเรียนแล้ว ใช้งานต่อได้เลย

เปิด [main.go](examples/hello/main.go) แล้วดูบรรทัดนี้ ซึ่งสั่งแสดงข้อความ:

```go
fmt.Println("Hello, World!")
```

**ก่อนรัน:** จะเห็นข้อความอะไร? เครื่องหมายคำพูดจะปรากฏด้วยหรือไม่?

```shell
go run ./examples/hello
```

## 3. ฝึกเอง

**สร้างครั้งเดียว:** ใน VS Code สร้างโฟลเดอร์ `practics` ภายใน `Go` แล้วสร้างไฟล์ `main.go` ข้างใน ใช้โฟลเดอร์เดิมถ้ามีแล้ว

พิมพ์โค้ดตั้งต้นจาก [main.go ของ EP.1](examples/hello/main.go) ลงใน `practics/main.go` แล้วบันทึกไฟล์ ไม่ต้องสร้าง `examples` หรือ `go.mod`

คลิกขวา `practics` → **Open in Integrated Terminal** เพื่อรันงานฝึกจากโฟลเดอร์นี้

**แก้ `main.go` ในโฟลเดอร์ฝึก** ทีละข้อ:

1. อ่านข้อความใน `fmt.Println(...)` คาดเดาผล แล้วลองรันสองครั้ง ผลเหมือนกันหรือไม่?
2. รัน `go version` แล้วอธิบายว่าต่างจาก `go run` อย่างไร

บันทึกไฟล์ (Ctrl+S) แล้วรันจาก **`practics`**:

```shell
go run main.go
```

- ไม่พบคำสั่ง go: เปิด terminal ใหม่ หากใช้ VS Code ที่เปิดค้างไว้ก่อนติดตั้ง Go ให้เปิด VS Code ใหม่ด้วย หากยังไม่ได้ ดู [การติดตั้ง](../../notes/setup-windows.md)
- หาโฟลเดอร์ไม่พบ หรือพบ no Go files: ตรวจว่า terminal อยู่ที่ `lessons/01-hello-go` แล้วรัน `go run ./examples/hello`
