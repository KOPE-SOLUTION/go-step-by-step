# EP.1 — เปิด PowerShell และรันโปรแกรม Go ครั้งแรก

ปรับถ้อยคำ 2026-09-20 • เรียนและทบทวนได้ตามความพร้อม

## เป้าหมายของบทเรียน

บทนี้อยู่ใน **Phase 1 — Go Basic** ดูภาพรวมได้จาก [สารบัญ](../../docs/playlist-01-go-basic/README.md)

เมื่อจบบทเรียน คุณจะเปิด PowerShell ตรวจสอบว่า Go พร้อมใช้งาน เลือกโฟลเดอร์ทำงาน และรันโปรแกรมตัวอย่างได้ เป้าหมายคือเข้าใจขั้นตอนเหล่านี้ก่อน ส่วนรายละเอียดของโค้ดจะเรียนใน EP.2

**ก่อนเริ่ม:** บทนี้ใช้ Windows และต้องติดตั้ง Go แล้ว เครื่องที่ใช้เตรียมหลักสูตรติดตั้งเรียบร้อย ดู [ผลตรวจสภาพแวดล้อม](../../notes/environment.md) ได้ หากใช้เครื่องอื่นให้ดู [วิธีติดตั้งบน Windows](../../notes/setup-windows.md) ก่อน

## คำศัพท์ที่ควรรู้

- **โปรแกรม:** ชุดคำสั่งที่ให้คอมพิวเตอร์ทำงาน เช่น แสดงข้อความหนึ่งบรรทัด
- **Terminal:** หน้าต่างสำหรับพิมพ์คำสั่ง ในบทนี้เราจะเปิด PowerShell เพื่อพิมพ์และเรียกใช้คำสั่ง
- **โฟลเดอร์ปัจจุบัน:** ตำแหน่งที่หน้าต่างคำสั่งกำลังทำงาน เหมือนเลือกเปิดลิ้นชักให้ตรงกับไฟล์ที่ต้องการใช้

Go คือภาษาโปรแกรม ส่วนคำสั่ง `go` ใช้เรียกเครื่องมือของภาษานี้ ในบทนี้จะใช้ตรวจสอบเวอร์ชันและรันโปรแกรม

## ขั้นตอนที่ 1 — เปิด PowerShell และตรวจสอบ Go

1. กดปุ่ม Windows บนแป้นพิมพ์
2. พิมพ์ `PowerShell` แล้วเปิดโปรแกรมชื่อนี้
3. หากเปิด PowerShell ค้างไว้ตั้งแต่ก่อนติดตั้ง Go ให้ปิดแล้วเปิดใหม่
4. พิมพ์คำสั่งต่อไปนี้ แล้วกด Enter:

```powershell
go version
```

ก่อนกด Enter ลองคิดว่าคำสั่งนี้ใช้ตรวจสอบเครื่องมือ หรือใช้รันโปรแกรมทักทายของเรา

หากเห็นบรรทัดขึ้นต้นด้วย `go version` ตามด้วยเลขรุ่น แสดงว่าเรียกใช้เครื่องมือได้ บนเครื่องที่เตรียมหลักสูตรนี้ควรเป็น `go version go1.27.1 windows/amd64`

**หากไม่พบคำสั่ง go:** เปิด PowerShell จากเมนู Start ใหม่แล้วลองอีกครั้ง หากยังไม่ได้ ให้เก็บข้อความผิดพลาดและดู [วิธีตรวจเครื่องมือ](../../notes/troubleshooting.md) ก่อนทำขั้นตอนถัดไป ในเอกสารนั้นจะพบคำว่า PATH ซึ่งหมายถึงรายการตำแหน่งที่ Windows ใช้ค้นหาโปรแกรม

## ขั้นตอนที่ 2 — เลือกโฟลเดอร์ทำงาน

เมื่อเรียกใช้ `go version` ได้แล้ว ให้คัดลอกคำสั่งนี้ลง PowerShell แล้วกด Enter:

```powershell
Set-Location -LiteralPath 'C:\Users\kopes\Documents\Codex\2026-09-17\go-youtube-go-iot-edge-gateway\Go\lessons\01-hello-go'
```

คำสั่งนี้เลือกโฟลเดอร์ที่จะทำงาน หากวางหลักสูตรไว้ที่ตำแหน่งอื่น ให้เปลี่ยนเส้นทางให้ตรงกับเครื่องของคุณ จากนั้นตรวจสอบตำแหน่งด้วย:

```powershell
Get-Location
```

ส่วนท้ายของตำแหน่งควรเป็น `Go\lessons\01-hello-go` หากหาโฟลเดอร์ไม่พบ ให้ตรวจชื่อและตำแหน่งที่เก็บหลักสูตรอีกครั้ง

## ขั้นตอนที่ 3 — อ่านโค้ดตัวอย่าง

เปิดไฟล์ `examples/hello/main.go` ด้วยโปรแกรมแก้ไขโค้ด หรือ editor ที่ใช้อยู่ เนื้อหาคือ:

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}
```

เริ่มจากบรรทัด `fmt.Println("Hello, Go!")` ซึ่งสั่งแสดงข้อความในเครื่องหมายคำพูดแล้วขึ้นบรรทัดใหม่ ส่วนที่เหลือเป็นโครงสร้างของโปรแกรม เราจะอธิบายทีละส่วนใน EP.2

รูปแบบคำสั่งในโค้ดเป็นเรื่องของภาษา Go ส่วนชื่อโฟลเดอร์ `examples/hello` เป็นวิธีจัดเก็บตัวอย่างของหลักสูตร คุณเลือกใช้ editor ที่ถนัดได้

## ขั้นตอนที่ 4 — คาดเดาผลลัพธ์และรันโปรแกรม

ก่อนรัน ลองตอบว่าจะเห็นข้อความอะไร และเครื่องหมายคำพูดจะปรากฏด้วยหรือไม่

จากโฟลเดอร์ที่เลือกไว้ในขั้นตอนที่ 2 พิมพ์:

```powershell
go run ./examples/hello
```

`go run` สั่งให้เครื่องมือเตรียมโปรแกรมจากโค้ดแล้วรัน ส่วน `./examples/hello` เลือกโฟลเดอร์ตัวอย่างใต้ตำแหน่งปัจจุบัน การรันครั้งแรกอาจใช้เวลาสักครู่ ให้รอจนคำสั่งทำงานเสร็จ

เปรียบเทียบผลจริงกับที่คาดเดาไว้ แล้วเปิด [ผลที่คาดหวังและคำอธิบาย](solutions/ep01.md) เพื่อตรวจคำตอบ เมื่อหน้าต่างกลับมารอรับคำสั่ง แสดงว่าโปรแกรมตัวอย่างทำงานเสร็จแล้ว

## แบบฝึกหัด

1. อธิบายด้วยคำของตนเองว่า `go version` กับ `go run ./examples/hello` ใช้ทำอะไรต่างกัน
2. รันคำสั่งเดิมอีกครั้งโดยยังไม่แก้โค้ด ก่อนรันให้คาดเดาว่าข้อความจะเหมือนเดิมหรือไม่ แล้วบันทึกผลที่เกิดขึ้น

คำถามทบทวน: การเห็นข้อความบนหน้าจอบอกอะไรเกี่ยวกับโปรแกรมนี้? เราตรวจสอบได้อย่างไรว่าเลือกโฟลเดอร์ถูกต้อง?

## ปัญหาที่พบบ่อยและวิธีตรวจสอบ

| สิ่งที่พบ | วิธีตรวจสอบ |
|---|---|
| ไม่รู้จักคำสั่ง go | เปิด PowerShell ใหม่จากเมนู Start แล้วลอง go version หากยังไม่ได้ ให้เก็บข้อความผิดพลาดและดูเอกสาร troubleshooting |
| หาโฟลเดอร์ไม่พบ | ตรวจเส้นทางในคำสั่ง Set-Location ให้ตรงกับตำแหน่งหลักสูตร |
| no Go files | ตรวจว่าคำสั่งมี `./examples/hello` ต่อท้าย ไม่ใช่เพียง `go run .` |
| พบข้อความผิดพลาดอื่น | เก็บคำสั่งที่ใช้ ตำแหน่งโฟลเดอร์ และข้อความผิดพลาดทั้งหมดไว้ตรวจสอบหรือขอความช่วยเหลือ |
