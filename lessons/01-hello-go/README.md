# บทที่ 1: Hello Go และการรันโปรแกรมแรก

**เริ่มจาก [EP.1 ฉบับทีละก้าว](EP01.md) ก่อน** เอกสารหน้านี้เป็นเนื้อหารวมของบท ไม่ต้องอ่านจบในครั้งเดียว ลำดับการเรียนคือ รันครั้งแรก → อ่านและแก้ข้อความ → เพิ่มข้อความและอ่าน error หยุดทบทวนแต่ละส่วนได้ตามต้องการ

## 1. เป้าหมายและสิ่งที่ต้องเตรียม

เมื่อจบบท คุณจะรันโปรแกรมหนึ่งไฟล์ แก้ข้อความแล้วรันใหม่ และอธิบายหน้าที่ของ `package main`, `import`, `func main` และ `fmt.Println` ด้วยคำของตนเองได้

ความรู้ก่อนเรียน: เปิดโฟลเดอร์ แก้และบันทึกไฟล์ข้อความได้ ไม่ต้องรู้ Go มาก่อน ใช้ editor ที่มีอยู่และ PowerShell

**สถานะเครื่อง 2026-09-19:** ติดตั้ง Go 1.27.1 windows/amd64 แล้ว ตรวจ compile/run/build ผ่าน ดูหลักฐานและข้อจำกัดที่ [tests/RESULTS.md](tests/RESULTS.md) เครื่องนี้ไม่ต้องติดตั้งซ้ำ ผลในตัวอย่างด้านล่างยังระบุเป็นผลที่คาดหวังเพื่อให้ผู้เรียนคาดเดาก่อนเทียบกับการทดลองของตนเอง

## 2. Go คืออะไร และศัพท์ที่ต้องรู้ก่อน

Go เป็นภาษาสำหรับเขียนโปรแกรม เครื่องมือของ Go แปลงโค้ดเป็นโปรแกรมที่รันได้ เหมาะจะใช้ฝึกสร้างเครื่องมือบรรทัดคำสั่งและบริการรับส่งข้อมูล หลักสูตรนี้จะต่อยอดไปยังโปรแกรมบนเครื่อง gateway ที่รวบรวมข้อมูลจำลอง ไม่ได้อ้างว่าโค้ด Go นี้ลงบอร์ดไมโครคอนโทรลเลอร์ได้ทุกชนิด

โปรแกรมรวบรวมข้อมูลทำงานคล้ายพนักงานที่รับค่าจากเครื่องวัด ตรวจสอบ แล้วส่งต่อ บทนี้เริ่มจากให้โปรแกรมแสดงข้อความหนึ่งบรรทัด เพื่อยืนยันว่าเรียกใช้งานได้ ก่อนเพิ่มการอ่านและจัดการข้อมูลในบทถัดไป

| ศัพท์ | ความหมายที่ใช้ในบทนี้ |
|---|---|
| Source code | ข้อความคำสั่งที่เขียนในไฟล์ `.go` |
| Terminal / PowerShell | หน้าต่างที่เราพิมพ์คำสั่งเพื่อให้เครื่องมือทำงาน |
| Compiler | เครื่องมือแปลง source code และตรวจความถูกต้องก่อนรัน |
| Function | ชุดคำสั่งที่มีชื่อ เรียกให้ทำงานได้ |
| Package | กลุ่มไฟล์ Go ในโฟลเดอร์เดียวกันที่ทำงานร่วมกัน |
| Import | การระบุ package ที่ไฟล์นี้จะใช้ |
| Standard library | package ที่มากับ Go เช่น `fmt` สำหรับจัดรูปแบบและแสดงข้อความ |
| String | ค่าข้อความ เช่น `"Hello, Go!"` เครื่องหมายคำพูดครอบข้อความไว้ |
| Module | กลุ่ม package ที่มี `go.mod` ระบุชื่อและข้อกำหนด |
| Current directory | โฟลเดอร์ที่ terminal กำลังทำงานอยู่ มีผลกับคำสั่งที่ใช้เส้นทางสัมพัทธ์ |

อ้างอิงภาพรวม: [เริ่มต้น Go ทางการ](https://go.dev/doc/tutorial/getting-started)

## 3. อ่านโค้ดและคาดเดาผลลัพธ์

เปิด `examples/hello/main.go`:

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}
```

**ก่อนอ่านผลด้านล่าง:** จะเห็นกี่บรรทัด เครื่องหมาย `"` จะปรากฏด้วยหรือไม่? ลองเขียนคำตอบของคุณก่อน

### แต่ละส่วนทำอะไร

- `package main` บอกว่าไฟล์อยู่ใน package สำหรับสร้างโปรแกรมที่สั่งรันได้ ชื่อ `main` ตรงนี้ไม่ใช่ชื่อไฟล์
- `import "fmt"` ทำให้ไฟล์นี้ใช้เครื่องมือจาก `fmt` ได้ โดยไม่ต้องเขียนวิธีแสดงข้อความขึ้นมาเอง ไม่ต้องดาวน์โหลด package นี้เพิ่ม
- `func main()` ประกาศฟังก์ชันเริ่มต้นของโปรแกรม ส่วน `()` บทนี้ไม่มีข้อมูลส่งเข้า `{` และ `}` ครอบชุดคำสั่งของฟังก์ชัน
- `fmt.Println(...)` เรียกฟังก์ชัน `Println` ของ package `fmt` ให้แสดงข้อความแล้วขึ้นบรรทัดใหม่ ชื่อ `Println` สะกดตัวใหญ่เล็กตามนี้
- `"Hello, Go!"` เป็นข้อมูลข้อความ เครื่องหมายคำพูดทำหน้าที่กำหนดขอบเขต ไม่ใช่ส่วนที่พิมพ์ออกมา

สำหรับตัวอย่างนี้ เมื่อเริ่มทำงานจะเข้าฟังก์ชัน `main` พิมพ์ข้อความ แล้วจบ ไม่มีลูปและไม่มีงานเบื้องหลังที่ต้องเรียนในตอนนี้

**หลักของภาษา:** โปรแกรมที่รันได้ใช้ package `main` และฟังก์ชัน `main` ตามรูปแบบนี้ รายละเอียดการเริ่มโปรแกรมดู [spec](https://go.dev/ref/spec#Program_execution)

**แนวทางออกแบบ:** แยก `examples/hello` ออกจาก `exercises/my-hello` เพื่อเก็บตัวอย่างให้กลับมาเทียบได้ง่าย

**ทางเลือก:** ตั้งชื่อไฟล์ `hello.go` แทน `main.go` ก็ได้ `main.go` เป็นชื่อที่ใช้บ่อย ไม่ใช่เงื่อนไขว่าต้องชื่อนี้ ส่วนการจัดย่อหน้าให้สม่ำเสมอใช้ `gofmt`

## 4. รันครั้งแรก

เปิด PowerShell แล้วพิมพ์ทีละบรรทัด ไม่คัดลอกเครื่องหมาย prompt `PS>` ถ้ามีแสดงอยู่ใน terminal

```powershell
Set-Location -LiteralPath 'C:\Users\kopes\Documents\Codex\2026-09-17\go-youtube-go-iot-edge-gateway\Go\lessons\01-hello-go'
Get-Location
go version
go run ./examples/hello
```

หากย้ายชุดหลักสูตรไปที่อื่น ให้แก้ path บรรทัดแรกตามจริง คำสั่งที่เหลือใช้เหมือนเดิม

`go run` ให้เครื่องมือ compile แล้วรันโปรแกรม ส่วน `./examples/hello` หมายถึงโฟลเดอร์ตัวอย่างภายใต้โฟลเดอร์ปัจจุบัน `go.mod` มีให้แล้ว ไม่ต้องสร้างซ้ำ

ผลที่คาดหวัง:

```text
Hello, Go!
```

เห็นหนึ่งบรรทัด ไม่มีเครื่องหมายคำพูด เมื่อโปรแกรมจบ PowerShell จะแสดง prompt ให้พิมพ์คำสั่งต่อได้ การกลับมาที่ prompt ไม่ใช่ข้อผิดพลาด

อีกรูปแบบที่ให้ผลเหมือนกันคือเข้าโฟลเดอร์ `examples/hello` แล้วใช้ `go run .` เครื่องหมาย `.` หมายถึงโฟลเดอร์ปัจจุบัน แต่ `go run .` จากรากบทจะไม่เจอไฟล์ Go เพราะรากบทเก็บเอกสารและ go.mod

`go run` เหมาะกับวงจรทดลอง โค้ดเปลี่ยนแล้วต้องบันทึกและรันอีกครั้ง ถ้าต้องการไฟล์โปรแกรมไว้เรียกเอง มี `go build` ซึ่งอยู่ในขั้นตรวจเพิ่มเติมด้านล่าง อ้างอิง [คำสั่ง go](https://pkg.go.dev/cmd/go#hdr-Compile_and_run_Go_program)

ไปที่ [แบบฝึกหัด](exercises/README.md) โดยแก้สำเนาส่วนตัวใน `Go/practics/phase-01/ep01-hello-go/main.go` ที่ Git ignore ส่วน `exercises/my-hello/main.go` เก็บเป็น starter อ้างอิง อ่าน [วิธีใช้พื้นที่ฝึก](../../docs/PRACTICE.md)

```powershell

```

อ่านผลก่อนตัดสินว่าถูกหรือผิด: รันไฟล์ที่แก้จริงหรือยัง? บันทึกแล้วหรือยัง? ถ้าเกิด error ให้เริ่มที่ข้อความแรกและเลขบรรทัด ไม่ต้องเปลี่ยนหลายอย่างพร้อมกัน

## 6. ข้อผิดพลาดที่พบบ่อย

| อาการ | สาเหตุที่ควรตรวจ | วิธีตรวจ/แก้ |
|---|---|---|
| `go` ไม่เป็นที่รู้จัก | ไม่มี Go ใน PATH ของ terminal นี้ | เปิด terminal ใหม่หลังติดตั้ง ใช้ `Get-Command go` ดูคู่มือติดตั้ง |
| หา go.mod ไม่เจอ | อยู่ผิดโฟลเดอร์ | `Get-Location` และ `Get-ChildItem` แล้วกลับรากบท |
| `no Go files` | สั่งรันรากบทซึ่งไม่มี main.go | ใช้ `go run ./examples/hello` |
| ข้อความลักษณะ `undefined: fmt.println` | ตัวใหญ่เล็กไม่ตรง | เทียบ `Println` กับเอกสาร ไม่ใช่ `println` |
| `imported and not used` | import package แต่ลบคำสั่งที่ใช้ออก | คืนคำสั่งที่ใช้หรือเอา import ที่ไม่ต้องใช้ออก |
| `syntax error` | วงเล็บ ปีกกา หรือ quote ไม่ครบ | อ่านเลขบรรทัดและตรวจบรรทัดก่อนหน้า ใช้ quote ตรง `"` ไม่ใช่ quote โค้งจากเอกสาร |
| รันแล้วข้อความไม่เปลี่ยน | ไม่ได้บันทึก หรือรันตัวอย่างแทนไฟล์ฝึก | บันทึกไฟล์และเช็ก argument หลัง `go run` |

ทดสอบกรณี `fmt.println` ในสำเนาชั่วคราวด้วย Go 1.27.1 แล้ว ได้ `undefined: fmt.println (but have Println)` จริง ส่วนกรณี error อื่นในตารางเป็นคำแนะนำที่ยังไม่ได้ทดลองครบ อ่าน [วิธีตามปัญหา](../../notes/troubleshooting.md) เพิ่มได้

## 7. คำถามตรวจความเข้าใจ

1. `package main` กับ `func main()` มีหน้าที่ต่างกันอย่างไร?
2. ทำไม `import "fmt"` อย่างเดียวจึงไม่พิมพ์ข้อความ?
3. เหตุใดแก้ไฟล์ฝึกแล้วสั่ง `go run ./examples/hello` จึงไม่เห็นข้อความใหม่?
4. หากเปลี่ยนชื่อ `main.go` เป็น `hello.go` แต่คงโค้ดเดิม ทำไมจึงยังมีโอกาสรันได้? สิ่งที่จำเป็นจริง ๆ คืออะไร?
5. ข้อความ `Gateway simulator is starting.` พิสูจน์หรือไม่ว่าอ่านอุปกรณ์ได้แล้ว?
