# เฉลย EP.1 — เปิดหลังคาดเดาและลองรัน

ผลของ `go run ./examples/hello` ที่คาดหวัง:

```text
Hello, Go!
```

มีข้อความหนึ่งบรรทัด เครื่องหมายคำพูดในโค้ดใช้ครอบข้อความ จึงไม่ได้แสดงเป็นส่วนของข้อความนี้

1. `go version` ตรวจว่าเรียกเครื่องมือ Go ได้และบอกเลขรุ่น ส่วน `go run ./examples/hello` ให้เครื่องมือรันโปรแกรมตัวอย่างที่ระบุ
2. เมื่อโค้ดยังเหมือนเดิม โปรแกรมตัวอย่างนี้จะพิมพ์ข้อความเดิมทุกครั้งที่รัน ไม่มีข้อมูลสุ่มหรือการอ่านอุปกรณ์ในตัวอย่างนี้

การเห็นข้อความพิสูจน์ได้เพียงว่ารันโปรแกรมพิมพ์ข้อความได้ ยังไม่ใช่หลักฐานว่าอ่านอุปกรณ์ ส่ง MQTT หรือเก็บข้อมูลได้ ก่อนรันให้ terminal อยู่ที่โฟลเดอร์ `lessons/01-hello-go`

เกณฑ์ผ่านคืออธิบายได้และลองด้วยตนเอง ไม่ต้องตอบเหมือนข้อความนี้ทุกคำ
