# เฉลย EP.1 — เปิดหลังลองรัน

1. โปรแกรมแสดงข้อความที่เขียนไว้ใน `fmt.Println(...)` โดยไม่แสดงเครื่องหมายคำพูด เมื่อโค้ดไม่เปลี่ยน โปรแกรมนี้จะแสดงข้อความเดิมทั้งสองครั้ง
2. `go version` ใช้ตรวจเลขเวอร์ชันของเครื่องมือ Go ส่วน `go run main.go` ใช้รันโค้ดจากไฟล์ `main.go` ในโฟลเดอร์ฝึกปัจจุบัน

ตัวอย่าง: ถ้าในโค้ดเป็น `fmt.Println("Hello, Go!")` ผลคือ:

```text
Hello, Go!
```
