# เฉลย — เปิดหลังลองด้วยตนเอง

## ข้อ 1

ดู `01-greeting/main.go` เปลี่ยนเฉพาะ string เพราะโครงสร้างโปรแกรมและการเรียก Println ยังทำงานเหมือนเดิม

จากรากบท:

```powershell
go run ./solutions/01-greeting
```

ผลที่คาดหวัง: `Hello, learner!` หนึ่งบรรทัด

## ข้อ 2

ดู `02-two-lines/main.go` เรียก Println สองครั้ง ภายใน main ของตัวอย่างนี้คำสั่งทำตามลำดับที่เขียน

```powershell
go run ./solutions/02-two-lines
```

ผลที่คาดหวัง:

```text
Hello, learner!
Gateway simulator is starting.
```

ถ้าสลับคำสั่ง ลำดับข้อความก็สลับ ไม่ได้เปลี่ยนความสามารถของโปรแกรมให้ติดต่อ gateway จริง

## ข้อ 3

อ่าน [เหตุผลและวิธีตรวจ](03-debug.md)

## แนวคำตอบตรวจความเข้าใจ

1. package main ระบุ package ของโปรแกรมที่รันได้ ส่วน func main เป็นจุดเริ่มทำงานของโค้ดตัวอย่างนี้
2. import ทำให้ใช้ package ได้ แต่ยังต้องเรียกฟังก์ชันให้ทำงาน
3. เส้นทางหลัง go run เลือกคนละโปรแกรม ต้องสั่งรันโฟลเดอร์ไฟล์ฝึก
4. ชื่อไฟล์ main.go ไม่ใช่เงื่อนไขบังคับ ต้องเป็น source file Go ที่เหมาะสมใน package main และมี func main รูปแบบที่ถูกต้อง
5. ไม่พิสูจน์ เป็นเพียง string ที่ส่งไปแสดงผล ยังไม่มีคำสั่งอ่านอุปกรณ์

ถ้าคำตอบต่าง ให้ย้อนทดสอบสมมติฐานหนึ่งอย่างก่อนเปลี่ยนโค้ด ไม่จำเป็นต้องคัดลอกเฉลยทั้งหมด
