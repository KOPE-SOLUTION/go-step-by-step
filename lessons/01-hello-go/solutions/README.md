# เฉลยเพิ่มเติม — Hello Go

คำสั่งรันจาก `lessons/01-hello-go`

## ข้อ 1

แก้เฉพาะข้อความในเครื่องหมายคำพูด ดู [main.go](01-greeting/main.go)

```powershell
go run ./solutions/01-greeting
```

ผล: `Hello, learner!`

## ข้อ 2

เรียก Println สองครั้งตามลำดับ ดู [main.go](02-two-lines/main.go)

```powershell
go run ./solutions/02-two-lines
```

```text
Hello, learner!
Gateway simulator is starting.
```
