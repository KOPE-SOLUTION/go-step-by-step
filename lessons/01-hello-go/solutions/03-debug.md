# เฉลยข้อ 3: อ่าน error แล้วแก้จุดเดียว

`fmt.println` ใช้ชื่อที่ไม่มีให้เรียกใน package fmt ต้องเขียน `fmt.Println` โดย `P` เป็นตัวใหญ่ ภาษา Go แยกตัวใหญ่เล็ก `Println` มีตัว l เล็กก่อน n อย่าสับสนกับตัว I ใหญ่

วิธีตรวจ:

1. ยืนยันว่า `go version` ทำงาน ถ้าไม่ทำงานยังไม่ถึงขั้นตรวจโค้ด
2. ดูไฟล์และเลขบรรทัดใน error เทียบกับไฟล์ฝึกที่บันทึกแล้ว
3. เทียบชื่อกับ [fmt.Println ทางการ](https://pkg.go.dev/fmt#Println)
4. แก้ `fmt.println` กลับเป็น `fmt.Println` เพียงจุดเดียว แล้วรัน `go run .` อีกครั้งจากโฟลเดอร์ส่วนตัว `Go/practics/phase-01/ep01-hello-go` ตามแนวทางพื้นที่ฝึกปัจจุบัน

อย่าแก้โดยลบ `fmt.` เพียงเพื่อให้ error หาย เพราะจะเปลี่ยนไปเรียกคนละฟังก์ชัน เป้าหมายโจทย์คือเข้าใจชื่อฟังก์ชันที่ตั้งใจใช้

ถ้ายังผิด ให้ดู error ใหม่ อาจมีการเปลี่ยน quote หรือวงเล็บเพิ่มโดยไม่ตั้งใจ ไม่ควรสรุปว่าติดตั้ง Go เสียเพียงเพราะ compile ไม่ผ่าน

ทดสอบในสำเนาชั่วคราวแล้วเมื่อ 2026-09-19 ด้วย Go 1.27.1 windows/amd64 ได้ข้อความ `undefined: fmt.println (but have Println)` และ exit code 1 ไม่ได้แก้ไฟล์ฝึกของผู้เรียนเพื่อทำการตรวจนี้ ดูบันทึกใน tests/RESULTS.md
