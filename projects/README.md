# โปรเจกต์ในอนาคต

ยังไม่มีโค้ดโปรเจกต์ในช่วงนี้ เมื่อผู้เรียนพร้อมตาม ROADMAP จึงสร้าง Console mini project (Phase 1), Application Core (Phase 2), API (Phase 3), การเก็บข้อมูลถาวร (Phase 4) และ Gateway จำลอง (Phase 5) เฉพาะเมื่อเริ่มเฟสนั้นจริง แต่ละโปรเจกต์เลือก module ที่เหมาะสมในตอนนั้น

โฟลเดอร์นี้มีไว้เก็บโปรเจกต์อ้างอิงที่ตั้งใจแชร์ ส่วนงานฝึกของผู้เรียนอยู่ใน `practics/` ซึ่ง Git ignore ดู `docs/PRACTICE.md`

ใช้ข้อมูลสมมติและบริการบน localhost ออกแบบการทดลองให้หยุด/เริ่มได้ ไม่เชื่อมต่อ production ไม่ใช้ข้อมูลบริษัท ไม่ติดตั้ง broker หรือ Docker ล่วงหน้า
