# สารบัญหลักสูตรตาม Phase / Playlist

| Phase | Playlist | สถานะ |
|---|---|---|
| 1 | [Go Basic](playlist-01-go-basic/README.md) | มีบทเรียนครบ EP1–28 เริ่มเรียนทีละ EP |

| 5 | [IoT & Edge Gateway](FUTURE_ROADMAP.md#phase-5--iot--edge-gateway) | แผน |

**Phase** คือช่วงการเรียนใหญ่, **Playlist** คือชุดบทเรียนของช่วงนั้น, **บท** คือกลุ่มแนวคิด และ **EP** คือตอนที่ทำเป้าหมายเล็กหนึ่งอย่าง บทหนึ่งแตกหลาย EP ได้ เลข EP จะใช้ร่วมกับ Phase เพื่อไม่สับสน เช่น Phase 1 • EP.1

ลำดับใช้งาน: [README รวม](../README.md) → Playlist → EP → คาดเดา → รัน → ลองแก้ใน [practics](PRACTICE.md) → ตรวจผล → ทบทวน ผู้เรียนเลือกเริ่ม EP ถัดไปเมื่อพร้อม
