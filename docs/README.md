# สารบัญหลักสูตร

เริ่มจาก Phase 1 แล้วเลือกเปิดบทเรียนทีละ EP ส่วน Phase 2–5 เป็นแผนสำหรับต่อยอด

| Phase | เนื้อหา | สถานะ |
|---|---|---|
| 1 | [Go Basic](playlist-01-go-basic/README.md) | มีบทเรียนครบ EP1–28 เริ่มเรียนทีละ EP |
| 2 | [Practical Go / Application Core](FUTURE_ROADMAP.md#phase-2--practical-go--application-core) | แผน |
| 3 | [Go Back-end & REST API](FUTURE_ROADMAP.md#phase-3--go-back-end--rest-api) | แผน |
| 4 | [Database & Persistence](FUTURE_ROADMAP.md#phase-4--database--persistence) | แผน |
| 5 | [IoT & Edge Gateway](FUTURE_ROADMAP.md#phase-5--iot--edge-gateway) | แผน |

**Phase** คือช่วงการเรียน และ **EP** คือตอนย่อยที่ฝึกทีละเรื่อง แต่ละช่วงมีสารบัญให้เลือกเปิดบทเรียนตามลำดับ

แต่ละ EP เริ่มจากอ่านโค้ด ลองคาดเดาผล แล้วรันและทำโจทย์ใน [พื้นที่ฝึก](PRACTICE.md) เมื่อเข้าใจแล้วค่อยเรียนตอนถัดไป

บทเรียนและโค้ดตัวอย่างอยู่ใน `lessons/` ใช้สารบัญด้านบนเพื่อเปิดตอนที่ต้องการ
