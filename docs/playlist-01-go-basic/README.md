# Phase 1 — Go Basic: เริ่มจากศูนย์

มีบทเรียนครบ **28 EP** เตรียมไว้ให้เลือกเปิดตามลำดับ แต่เรียนทีละ EP ได้ ไม่ต้องอ่านทั้งชุดในคราวเดียว และไม่กำหนดจำนวนวันที่ต้องเรียนจบ

เป้าหมายคือเข้าใจโปรแกรมเล็ก ๆ ด้วยตนเอง ไม่ต้องมีพื้นฐานภาษาอื่น จบเฟสด้วยรายงานค่าจำลองใน terminal พร้อมการทดสอบ ส่วน API และ Database อยู่เฟสถัดไป

## ลำดับการเรียน

| ช่วง | เรื่อง | นำไปต่อยอด |
|---|---|---|
| EP1–4 | รัน อ่านโค้ด พิมพ์ข้อความ อ่าน error | วงจรแก้–รัน–ดูผล |
| EP5–9 | ตัวแปร ชนิดข้อมูล ค่าศูนย์ รูปแบบผล คำนวณ | เก็บข้อมูลการวัด |
| EP10–14 | เงื่อนไข ลูป ฟังก์ชัน และ error | ตรวจเกณฑ์และจัดการข้อมูลผิด |
| EP15–20 | array, slice, map, struct, method, pointer | รายการอุปกรณ์และแบบข้อมูล |
| EP21–24 | package, module และ test | จัดไฟล์และตรวจพฤติกรรม |
| EP25–28 | โปรเจกต์รายงานจำลองทีละขั้น | รวมความรู้ก่อน Practical Go |

แบ่งการพิมพ์ข้อความกับการอ่าน error เป็นคนละ EP และแยกฟังก์ชันรับค่า/คืนค่า เพื่อให้ทดลองได้ทีละเรื่อง ส่วนโปรเจกต์แยกข้อมูล → ตรวจข้อมูล → รายงานหลายรายการ → test จึงเห็นเหตุผลของแต่ละส่วนก่อนประกอบรวม

## ใช้เอกสารแต่ละตอน

แต่ละ EP มี 3 ขั้นตอน: อ่านโค้ด → ลองรัน → ฝึกเอง ส่วนคำอธิบายเพิ่มเติมพับไว้ให้เปิดเมื่อสงสัย

โจทย์อยู่ในหัวข้อ **3. ฝึกเอง** ของแต่ละ EP ใช้ `practics/main.go` ไฟล์เดิม เมื่อขึ้น EP ใหม่ก็เขียนโค้ดทับได้ ไม่ต้องสร้างโฟลเดอร์แยกตอน ดู [วิธีเริ่มฝึก](../PRACTICE.md)

EP1 ใช้ตำแหน่งเดิม `lessons/01-hello-go/EP01.md` ส่วน EP2–28 อยู่ `lessons/phase-01` แต่ละ EP มี go.mod แยก เพื่อทดลองได้โดยไม่ทำให้ตอนอื่นเสีย

ผลตรวจตัวอย่างและเฉลยจริง: [ผลตรวจ Phase 1](../../notes/phase-01-results.md) การเตรียมไฟล์หรือการทดสอบโดยผู้ช่วยไม่ได้แปลว่าผู้เรียนผ่านแล้ว

## ทบทวนก่อนเรียนต่อ

หลังแต่ละช่วงให้ปิดเฉลย แล้วอธิบายโค้ดหนึ่งตัวอย่างจากช่วงนั้น เปลี่ยนข้อมูลหนึ่งจุดและคาดผลได้ ถ้ายังไม่แน่ใจย้อนทบทวนได้ ไม่ต้องเร่งไปตามจำนวนไฟล์

ก่อน Phase 2 ควรรันโปรแกรม อ่าน error พื้นฐาน แยกฟังก์ชัน จัดข้อมูล และเขียน test กรณีเล็กได้ ไม่ต้องจำ syntax ทุกคำ ใช้เอกสารอ้างอิงได้ เริ่มเฟสถัดไปเมื่อพร้อม
