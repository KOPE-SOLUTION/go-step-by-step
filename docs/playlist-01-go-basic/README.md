# Phase 1 — พื้นฐาน Go

เรียนเป็น 14 EP แต่ละบทมีงานหลักให้ทำจนจบ พร้อมโจทย์ 2 ข้อและเฉลยแยกกัน ใช้ข้อมูลจำลองตั้งแต่บทแรกจนถึงโปรเจกต์สรุป

| EP | บทเรียน | สิ่งที่ทำได้เมื่อจบบท |
|---|---|---|
| 1 | [เขียนและรันโปรแกรม Go แรก](../../lessons/phase-01/ep01-hello-go/README.md) | รันโปรแกรม อ่านส่วนประกอบ และแก้ข้อผิดพลาดง่าย ๆ ได้ด้วยตัวเอง |
| 2 | [เก็บข้อมูลด้วยตัวแปรและชนิดข้อมูล](../../lessons/phase-01/ep02-variables-types/README.md) | เก็บชื่ออุปกรณ์ ค่าการวัด และสถานะ แล้วจัดรูปแบบรายงานได้ |
| 3 | [คำนวณและตรวจเงื่อนไขของข้อมูล](../../lessons/phase-01/ep03-calculations-conditions/README.md) | แปลงหน่วยและแยกข้อมูลปกติ ค่าสูง และค่าที่อยู่นอกช่วงจำลองได้ |
| 4 | [ทำซ้ำและสรุปค่าการวัดด้วย for](../../lessons/phase-01/ep04-loops/README.md) | ประมวลผลหลายรอบ ข้ามรอบที่อ่านไม่ได้ และหาค่าเฉลี่ยจากจำนวนที่สำเร็จ |
| 5 | [แยกงานด้วยฟังก์ชัน รับค่าและคืนค่า](../../lessons/phase-01/ep05-functions/README.md) | แยกการแปลงหน่วยและการตัดสินสถานะออกจากการแสดงผล แล้วเรียกซ้ำได้ |
| 6 | [รับมือข้อมูลผิดด้วย error](../../lessons/phase-01/ep06-errors/README.md) | แปลงข้อความเป็นตัวเลข ตรวจ error และให้โปรแกรมรับข้อมูลรายการถัดไปได้ |
| 7 | [จัดการรายการข้อมูลด้วย array และ slice](../../lessons/phase-01/ep07-arrays-slices/README.md) | เก็บหลายค่าการวัด เพิ่มรายการ และสรุปค่าเฉลี่ยกับจำนวนคำเตือน |
| 8 | [ค้นหาและอัปเดตข้อมูลด้วย map](../../lessons/phase-01/ep08-maps/README.md) | เก็บค่าล่าสุดตามชื่ออุปกรณ์ และแยกค่าศูนย์จริงออกจากชื่อที่ไม่พบได้ |
| 9 | [สร้างชนิดข้อมูลการวัดด้วย struct](../../lessons/phase-01/ep09-structs/README.md) | รวมชื่อกับอุณหภูมิเป็นข้อมูลหนึ่งรายการ แล้วทำรายงานหลายรายการได้ |
| 10 | [เพิ่ม method และแก้ต้นฉบับด้วย pointer](../../lessons/phase-01/ep10-methods-pointers/README.md) | เลือกได้ว่างานใดอ่านสำเนา และงานใดตั้งใจแก้ข้อมูลต้นฉบับ |
| 11 | [สลับแหล่งข้อมูลด้วย interface](../../lessons/phase-01/ep11-interfaces/README.md) | ใช้ฟังก์ชันเดียวอ่านตัวจำลองที่สำเร็จและล้มเหลว โดยไม่ผูกกับชนิดอุปกรณ์เดียว |
| 12 | [จัดโค้ดเป็น package และ module](../../lessons/phase-01/ep12-packages-modules/README.md) | แยกกฎสถานะออกจาก main และอธิบายว่า import หาโค้ดจากที่ใด |
| 13 | [ทดสอบกฎและค่าขอบเขตด้วย unit test](../../lessons/phase-01/ep13-unit-tests/README.md) | เขียน test ที่จับความผิดพลาดตรงค่าเกณฑ์ได้ และอ่านว่าผลจริงต่างจากที่ต้องการอย่างไร |
| 14 | [โปรเจกต์สรุป: รายงานข้อมูลการวัด](../../lessons/phase-01/ep14-measurement-report/README.md) | ประกอบความรู้พื้นฐานเป็นรายงานที่ตรวจข้อมูล ทำต่อหลังรายการเสีย และมี test ยืนยัน |

เริ่มที่ EP.1 และทำโจทย์ในหน้าบทเรียน ใช้ [practics ไฟล์เดิม](../PRACTICE.md) ตลอดเฟส เพิ่มไฟล์เฉพาะบท package และ test

หัวข้อย่อยภายในบทใช้แบ่งขั้นฝึก ไม่ต้องเรียนให้จบในครั้งเดียว เมื่อทำโปรเจกต์ EP.14 และอธิบายผล test ได้แล้ว จึงไป [Phase 2](../FUTURE_ROADMAP.md)
