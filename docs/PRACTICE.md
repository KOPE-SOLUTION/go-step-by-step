# ฝึกในไฟล์เดียว

ใช้ `practics/main.go` เป็นพื้นที่ฝึก ขึ้น EP ใหม่ก็เปลี่ยนโค้ดในไฟล์เดิม ตัวอย่างแต่ละบทอยู่ใน `lessons/phase-01/` ให้ย้อนดูได้

## เตรียมครั้งเดียว

1. ใน VS Code สร้างโฟลเดอร์ `practics` ภายในโฟลเดอร์หลักสูตร ถ้ามีอยู่แล้วให้ใช้ของเดิม
2. สร้างไฟล์ `main.go` ข้างใน แล้วพิมพ์โค้ดของบทที่กำลังเรียน
3. บันทึกไฟล์ คลิกขวาที่ `practics` → **Open in Integrated Terminal** แล้วรัน:

```shell
go run main.go
```

ใช้ได้ทั้ง terminal ใน VS Code, PowerShell และ cmd โดยตำแหน่งปัจจุบันต้องเป็น `practics`

## เมื่อขึ้นบทใหม่

เปลี่ยนเนื้อหา main.go เป็นโค้ดตั้งต้นของบท แล้วทำโจทย์ในหน้าเดียวกัน ไม่ต้องสร้างโฟลเดอร์ราย EP หรือ examples ถ้าอยากเก็บงานที่ปรับเองให้คัดลอกเป็น `main-ep01.txt` ก่อนเขียนทับ เพื่อไม่ให้ Go นำไฟล์เก่ามารันรวม

| ช่วง | ไฟล์และคำสั่ง |
|---|---|
| EP.1–11 | main.go เพียงไฟล์เดียว ใช้ `go run main.go` |
| EP.12 | สร้าง go.mod ครั้งเดียวด้วย `go mod init example.com/go-practice` และเพิ่ม sensor/reading.go แล้วใช้ `go run .` |
| EP.13 | เพิ่ม main_test.go ใช้ `go test -v .` และใช้ go.mod เดิม |
| EP.14 | เปลี่ยนทั้ง main.go และ main_test.go เป็นโปรเจกต์สรุป ใช้ go.mod เดิม |

ถ้ามี go.mod อยู่แล้ว ให้ตรวจชื่อ module และใช้ import ให้ตรง ไม่ต้อง init ซ้ำ ไฟล์ sensor/reading.go ของ EP.12 เก็บไว้ได้ใน EP.13–14 แต่ main ของสองบทนี้ยังไม่เรียกใช้

`practics/` ถูก Git ignore ผู้ที่ clone จึงสร้างพื้นที่นี้เอง การเพิ่มไฟล์เข้า Git ตามปกติจะไม่รวมงานฝึก ไม่จำเป็นต้องใช้คำสั่ง Git เพื่อเริ่มเรียน
