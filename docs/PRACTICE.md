# ฝึกในไฟล์เดียว

ใช้ `practics/main.go` เป็นพื้นที่ฝึก ขึ้น EP ใหม่ก็เปลี่ยนโค้ดในไฟล์เดิม ตัวอย่างแต่ละบทอยู่ใน `lessons/phase-01/` ให้ย้อนดูได้

## เตรียมครั้งเดียว

1. ใน VS Code สร้างโฟลเดอร์ `practics` ภายในโฟลเดอร์หลักสูตร ถ้ามีอยู่แล้วให้ใช้ของเดิม
2. สร้างไฟล์ `main.go` ข้างใน แล้วพิมพ์โค้ดของบทที่กำลังเรียน
3. บันทึกไฟล์ คลิกขวาที่ `practics` → **Open in Integrated Terminal** แล้วรัน:

```shell
go run main.go
```

ใช้ได้ทั้ง terminal ใน VS Code, PowerShell และ cmd โดยตำแหน่งปัจจุบันต้องเป็น `practics`

## เมื่อขึ้นบทใหม่

เปิด README ของบทที่กำลังเรียน แล้วทำตามลำดับในบทนั้น สำหรับ **EP.4–14** ให้เริ่มจากโค้ดขั้นที่ 1 แล้วเพิ่มหรือแทนเฉพาะส่วนที่ระบุ บันทึกและรันก่อนทำขั้นถัดไป ส่วน **ตัวอย่างเมื่อทำครบ** ใช้เปิดเทียบหลังฝึกครบแล้ว จากนั้นจึงทำโจทย์ท้ายบท

ใช้ `main.go` ไฟล์เดิม ไม่ต้องสร้างโฟลเดอร์ราย EP หรือ `examples` ถ้าต้องการเก็บงานเดิม ให้คัดลอกเป็นไฟล์ เช่น `main-ep01.txt` ก่อนเปลี่ยนโค้ด Go จะไม่นำไฟล์ `.txt` มาคอมไพล์รวมกับ `.go`

| ช่วง | ไฟล์และคำสั่ง |
|---|---|
| EP.1–11 | `main.go` เพียงไฟล์เดียว ใช้ `go run main.go` |
| EP.12 | สร้าง `go.mod` ครั้งเดียวด้วย `go mod init example.com/go-practice` และเพิ่ม `sensor/reading.go` แล้วใช้ `go run .` |
| EP.13 | เพิ่ม `main_test.go` ใช้ `go test -v .` และใช้ `go.mod` เดิม |
| EP.14 | เขียนรายงานใน `main.go` ทีละขั้น แล้วแทน `main_test.go` เมื่อถึงขั้นทดสอบ ใช้ `go.mod` เดิม |

ถ้ามี `go.mod` อยู่แล้ว ให้ใช้ชื่อ module เดิมเป็นส่วนต้นของ import ไม่ต้อง init ซ้ำ ส่วนไฟล์ `sensor/reading.go` ของ EP.12 เก็บไว้ได้ เพราะ EP.13–14 ไม่ได้ import package `sensor`

`practics/` ถูกระบุไว้ใน `.gitignore` เพื่อไม่เก็บงานฝึกใน Git ผู้ที่ดาวน์โหลดหรือ clone หลักสูตรจึงต้องสร้างโฟลเดอร์นี้เองตามขั้นตอนข้างต้น ไม่จำเป็นต้องใช้คำสั่ง Git เพื่อเริ่มเรียน
