# ผลตรวจพื้นที่ฝึกไฟล์เดียว

ตรวจเมื่อ 2026-09-20 ด้วย Go 1.27.1 windows/amd64

- รันโค้ดตั้งต้น EP.1–28 ต่อเนื่องในโฟลเดอร์ TEMP เดียว โดยเขียนทับ `main.go` เมื่อเปลี่ยน EP: ผ่านครบ 28 ตอนและผลตรงกับตัวอย่างปัจจุบัน
- EP.1–20 ใช้ `go run main.go` โดยไม่มี `go.mod`; EP.1 ปัจจุบันแสดง `Hello, World!`
- EP.21 สร้าง module `example.com/go-practice` และ `sensor/reading.go`; EP.22 ใช้ชุดเดิม: รันผ่าน
- EP.23, 24 และ 28 ใช้โค้ดโปรแกรมที่รวมใน `main.go` กับ `main_test.go`: `go test -count=1 .` ผ่านทั้งสามตอน
- EP.25 เปลี่ยนเนื้อหา `main_test.go` เหลือ `package main`: รันโปรแกรมได้และไม่มี test เก่าที่เรียกฟังก์ชันซึ่งเลิกใช้ ผล `go test` แจ้ง `[no tests to run]` จึงไม่นับเป็นการทดสอบพฤติกรรมของโปรเจกต์
- ทดลองเปลี่ยน `>= 30` เป็น `> 30` ในโค้ด EP.23: test ค่า 30 ล้มเหลวตามคาด
- ย้ายงานฝึกราย EP เดิมไปโฟลเดอร์สำรองนอก repository ตามที่ผู้ใช้เลือก: ตรวจ hash ตรงกันครบ 67 ไฟล์ โฟลเดอร์เดิมถูกย้ายออกจาก `practics` แล้ว

การตรวจครั้งนี้ตั้ง `GOTOOLCHAIN=local`, `GOPROXY=off` และ `GOWORK=off` เฉพาะ process ทดสอบ ไม่มีการดาวน์โหลด dependency และไม่ได้สร้าง `practics/main.go` ให้ผู้เรียนล่วงหน้า

ยังไม่ได้ลองพิมพ์และเปิด terminal ผ่าน UI ของ VS Code หรือรันคำสั่งผ่าน cmd และไม่ได้รันเฉลยทุกข้อซ้ำในรอบนี้ การตรวจผ่านไม่หมายความว่าผู้เรียนทำแบบฝึกหัดแล้ว
