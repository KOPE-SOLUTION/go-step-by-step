# ผลตรวจ Phase 1 — หลักสูตร 14 EP

ตรวจวันที่ 2026-09-21 ด้วย `go version go1.27.1 windows/amd64` โค้ดประกาศ Go 1.22.0 ใน go.mod ใช้ standard library เท่านั้น ระหว่างตรวจตั้ง GOTOOLCHAIN=local, GOPROXY=off และ GOWORK=off เฉพาะกระบวนการทดสอบ

## ผลที่ตรวจจริง

- รันตัวอย่าง 14 โปรแกรมและเฉลย 28 โปรแกรม ผลตรงกับ manifest ทั้ง 42 รายการ
- gofmt ไม่พบไฟล์ที่ต้องจัดรูปแบบเพิ่ม
- go test -count=1 ./... ผ่านในทุกบท EP.1–12 เป็นการตรวจ build และผลโปรแกรม ยังไม่มี unit test เฉพาะบท
- EP.13–14 มี unit test ของตัวอย่างและเฉลย ตรวจเกณฑ์ ช่วงข้อมูล รายการผิด และการทำงานต่อ
- จำลองการฝึกใน practics/main.go ไฟล์เดียวใน TEMP ครบ 14 บท: เริ่มไม่มี go.mod, สร้างครั้งเดียวใน EP.12, เพิ่ม test ใน EP.13 และแทน test ใน EP.14
- ทดลองสะกด Println เป็น PrintIn ใน TEMP แล้วตรวจพบ undefined: fmt.PrintIn
- ทดลองเปลี่ยน >= เป็น > ใน TEMP แล้ว test กรณีเท่ากับเกณฑ์ของ EP.13 ล้มเหลวตามที่ต้องการ

## ตรวจซ้ำ

เปิด PowerShell 7 ที่โฟลเดอร์หลักสูตร:

```powershell
./scripts/verify-phase01.ps1
./scripts/verify-practice.ps1
```

หาก go ไม่อยู่ใน PATH ส่ง `-GoCommand` พร้อม path ของ go executable สคริปต์ตรวจ practice ใช้ TEMP และไม่สร้างหรือเปลี่ยนไฟล์ใน practics ของหลักสูตร

EP.1–12 ไม่จำเป็นต้องเพิ่ม unit test ที่ตรวจเพียงคำสั่งพิมพ์ซ้ำกับโค้ด ใช้ผลลัพธ์ที่คาดและการ compile แทน เริ่ม test พฤติกรรมเมื่อมีฟังก์ชันกับกฎให้ตรวจใน EP.13
