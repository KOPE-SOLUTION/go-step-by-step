# ผลตรวจ Phase 1 — หลักสูตร 14 EP

ตรวจวันที่ 2026-09-21 ด้วย `go version go1.27.1 windows/amd64` โค้ดประกาศ Go 1.22.0 ใน go.mod ใช้ standard library เท่านั้น ระหว่างตรวจตั้ง GOTOOLCHAIN=local, GOPROXY=off และ GOWORK=off เฉพาะกระบวนการทดสอบ

## ตรวจเพิ่มวันที่ 2026-09-30 — โค้ดระหว่างทาง EP.4–14

ปรับบทเรียนให้เขียนเพิ่มทีละส่วน แล้วประกอบโค้ดตามลำดับในโฟลเดอร์ TEMP ด้วย Go 1.27.1 บน Windows โดยไม่สร้างหรือแก้ไฟล์ใน `practics` ของผู้เรียน

- ตรวจครบ 49 ขั้น: 48 ขั้นรันหรือทดสอบสำเร็จ และ 1 ขั้นจงใจเปลี่ยน `>=` เป็น `>` ใน EP.13 ซึ่ง test ตรวจพบความผิดพลาดตามที่คาด จากนั้นขั้นแก้กลับผ่าน
- เทียบผลที่พิมพ์กับผลในบทเรียนทุกขั้นที่รันโปรแกรม ส่วนขั้น unit test ตรวจทั้ง exit code และชื่อกรณีที่ผ่านหรือไม่ผ่าน
- ตรวจว่าโค้ด Go 64 บล็อกในขั้นฝึกตรงกับโค้ดที่ใช้ประกอบทดสอบ โดยไม่นับความต่างของการเยื้องบรรทัด และจัดรูปแบบส่วนโค้ดด้วย gofmt
- EP.12 ตรวจทั้งก่อนมี module การสร้างด้วย `go mod init` และ import `example.com/go-practice/sensor` ใน module งานฝึก
- EP.13 ตรวจ test หนึ่งกรณี ก่อนเพิ่มตารางและ `t.Run`; EP.14 ตรวจ test รายการผิดแล้วทำต่อ ก่อนเพิ่มชุดตรวจขอบช่วง ข้อมูลว่าง และเกณฑ์อื่น
- ตัวอย่างอ้างอิงและเฉลยไฟล์ `.go` เดิมไม่ได้เปลี่ยน รอบนี้ตรวจโค้ดระหว่างทางและชุด test ที่ใช้ในขั้นใหม่ ไม่ได้รันเฉลยทั้ง 28 โปรแกรมซ้ำ

ตั้ง `GOTOOLCHAIN=local`, `GOPROXY=off`, `GOWORK=off` และ `GOENV=off` เฉพาะกระบวนการตรวจ รอบแรกพบข้อความจาก Go telemetry ว่าเขียนไฟล์ไม่ได้ จึงแยกตำแหน่งตั้งค่า Go ไปไว้ใน TEMP และปิด telemetry เฉพาะพื้นที่ทดสอบ แล้วตรวจใหม่ครบ 49 ขั้นได้ผลตามคาด โดยไม่เปลี่ยนการตั้งค่า Go ของผู้ใช้

ยังไม่ได้ตรวจด้วย Go 1.22, macOS หรือ Linux และยังไม่ได้ทดลองให้ผู้เริ่มต้นทำตามผ่าน VS Code จริง จึงยังไม่ยืนยันเวลาที่ใช้เรียนหรือความยาวคลิป

## ตรวจเพิ่มวันที่ 2026-09-28 — ขั้นทดลอง error ใน EP.1

เปลี่ยนเฉพาะคำสั่งทักทายจาก Println เป็น println ในสำเนา TEMP ด้วย Go 1.27.1 บน Windows ได้ exit code 1 พร้อม `undefined: fmt.println (but have Println)` และยังไม่มีข้อความจากโปรแกรม จากนั้นแก้ P กลับเป็นตัวใหญ่แล้วรันซ้ำ ได้ผล 3 บรรทัดตรงตัวอย่าง โดยไม่แก้ไฟล์ฝึกของผู้เรียน

ขั้นทดลองนี้แสดงเป็นหัวข้อหลักใน EP.1 และสคริปต์ verify-practice.ps1 ใช้ตรวจทั้งตอนสะกดผิดและหลังแก้กลับ ผลนี้ยืนยันกรณีที่ทดลอง ไม่ครอบคลุม error ทุกประเภท

## ผลตรวจทั้งเฟสวันที่ 2026-09-21

- รันตัวอย่าง 14 โปรแกรมและเฉลย 28 โปรแกรม ผลตรงกับ manifest ทั้ง 42 รายการ
- gofmt ไม่พบไฟล์ที่ต้องจัดรูปแบบเพิ่ม
- go test -count=1 ./... ผ่านในทุกบท EP.1–12 เป็นการตรวจ build และผลโปรแกรม ยังไม่มี unit test เฉพาะบท
- EP.13–14 มี unit test ของตัวอย่างและเฉลย ตรวจเกณฑ์ ช่วงข้อมูล รายการผิด และการทำงานต่อ
- จำลองการฝึกใน practics/main.go ไฟล์เดียวใน TEMP ครบ 14 บท: เริ่มไม่มี go.mod, สร้างครั้งเดียวใน EP.12, เพิ่ม test ใน EP.13 และแทน test ใน EP.14
- ทดลองสะกด Println เป็น PrintIn ใน TEMP แล้วตรวจพบ undefined: fmt.PrintIn
- ทดลองเปลี่ยน >= เป็น > ใน TEMP แล้ว test กรณีเท่ากับเกณฑ์ของ EP.13 ล้มเหลวตามที่ต้องการ

## ตรวจซ้ำ

เปิด PowerShell 7 ที่โฟลเดอร์หลักสูตร:

```powershell
./scripts/verify-phase01.ps1
./scripts/verify-practice.ps1
```

หาก go ไม่อยู่ใน PATH ส่ง `-GoCommand` พร้อม path ของ go executable สคริปต์ตรวจ practice ใช้ TEMP และไม่สร้างหรือเปลี่ยนไฟล์ใน practics ของหลักสูตร

EP.1–12 ไม่จำเป็นต้องเพิ่ม unit test ที่ตรวจเพียงคำสั่งพิมพ์ซ้ำกับโค้ด ใช้ผลลัพธ์ที่คาดและการ compile แทน เริ่ม test พฤติกรรมเมื่อมีฟังก์ชันกับกฎให้ตรวจใน EP.13
