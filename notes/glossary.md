# คำศัพท์ Go พื้นฐาน

| คำ | ความหมายในหลักสูตร |
|---|---|
| terminal | หน้าต่างพิมพ์คำสั่ง |
| compiler | เครื่องมือแปลและตรวจโค้ดก่อนรัน |
| variable / type | ตัวแปรที่อ้างถึงค่า / ชนิดของค่า |
| zero value | ค่าเริ่มต้นของชนิด เช่น 0, false และข้อความว่าง |
| constant | ค่าคงที่ที่ประกาศด้วย const |
| function / parameter / return | ชุดคำสั่งที่ตั้งชื่อ / ช่องรับข้อมูล / การคืนผล |
| scope | ขอบเขตที่ใช้ชื่อหนึ่งได้ |
| error | ค่าที่อธิบายว่างานไม่สำเร็จ |
| nil | ค่าศูนย์ของบางชนิด เช่น pointer, slice, map หรือ interface; ใช้กับ error เพื่อบอกว่าไม่มี error |
| array / slice | รายการจำนวนคงที่ / ค่าที่อ้างถึงช่วงของ array เบื้องหลัง |
| index / len / cap | ตำแหน่งเริ่มที่ 0 / จำนวนสมาชิก / ความจุที่ใช้ได้จากจุดเริ่ม slice |
| map / key / value | คู่ข้อมูลสำหรับค้นหา / ค่าที่ใช้ค้น / ข้อมูลที่เก็บไว้ |
| struct / field | ชนิดที่รวมหลายช่องข้อมูล / ช่องข้อมูลใน struct |
| pointer | ค่าที่อ้างถึงตำแหน่งข้อมูล |
| method / receiver | ฟังก์ชันที่ผูกกับชนิด / ค่าที่ method ทำงานด้วย |
| interface | ข้อตกลงของ method ที่ค่าหนึ่งต้องรองรับในบทพื้นฐาน |
| package / module | กลุ่มไฟล์ในโฟลเดอร์ / ชุด package ที่มี go.mod กำกับ |
| exported | ชื่อที่ขึ้นต้นตัวใหญ่และใช้จาก package อื่นได้ |
| unit test | โค้ดตรวจพฤติกรรมของส่วนเล็ก ๆ ด้วย input และผลที่ต้องการ |

คำใหม่จะอธิบายในบทก่อนใช้งาน ไม่จำเป็นต้องจำตารางนี้ทั้งหมดก่อนเริ่มเรียน
