# คำศัพท์ Go Basic — เปิดทบทวนเมื่อพบ

| คำ | ความหมายและตัวอย่าง |
|---|---|
| Go | ภาษาโปรแกรม และชื่อชุดเครื่องมือที่ใช้คำสั่ง `go` |
| Source code | คำสั่งที่มนุษย์เขียน เช่นไฟล์ `main.go` |
| Compiler / compile | เครื่องมือ/การแปลง source code พร้อมตรวจความถูกต้องเพื่อสร้างโปรแกรม |
| Terminal | หน้าต่างรับคำสั่ง เช่น terminal ใน VS Code ใช้ PowerShell หรือ cmd ได้ |
| Current directory | โฟลเดอร์ที่ terminal ใช้งานอยู่ คำสั่งที่ใช้เส้นทางสัมพัทธ์จะอ้างอิงจากตำแหน่งนี้ |
| PATH | รายการโฟลเดอร์ที่ระบบใช้ค้นหาคำสั่ง เช่น go.exe |
| Function | ชุดคำสั่งที่มีชื่อ เช่น main และ Println |
| Package | กลุ่มไฟล์ Go ในโฟลเดอร์เดียวกันที่ทำงานร่วมกัน |
| Import | ระบุ package ที่ไฟล์จะใช้ |
| Standard library | package ที่มากับ Go เช่น fmt |
| String | ค่าข้อความ เช่น `"Hello, Go!"` |
| Module | กลุ่ม package ภายใต้ go.mod หนึ่งชุด ใช้ระบุชื่อและข้อกำหนดของโค้ด |
| go.mod | ไฟล์กำหนด module และรุ่นภาษาขั้นต่ำ ไม่ใช่ตัวโปรแกรมที่ติดตั้ง Go |
| stdout | ช่องทางข้อความผลลัพธ์ปกติของโปรแกรม โดยทั่วไปแสดงใน terminal |
| stderr | ช่องทางข้อความข้อผิดพลาด ซึ่งอาจแสดงใน terminal เดียวกับ stdout |
| Exit code | เลขสถานะเมื่อคำสั่งจบ โดยทั่วไป 0 คือสำเร็จ คำสั่ง Go ใช้ค่าที่ไม่ใช่ 0 เมื่อผิดพลาด |
| Smoke test | การตรวจพฤติกรรมหลักแบบสั้น เช่น รันแล้วเทียบข้อความจริงกับที่คาด |
| Unit test | การตรวจส่วนย่อยของโค้ด เช่นฟังก์ชันคำนวณ ลงมือเขียนใน EP23–24 |
| Localhost / loopback | การติดต่อบริการภายในเครื่องเดียวกัน ยังไม่ใช้เครือข่ายในบท 1 |
| Gateway | โปรแกรมหรือเครื่องที่รวบรวมข้อมูลจากแหล่งหนึ่งและส่งต่อ อีกหลายบทจึงจะลงมือจำลอง |

ศัพท์ concurrency, MQTT, ACK และคิวจะเพิ่มพร้อมคำอธิบายก่อนเริ่มใช้ในบทที่เกี่ยวข้อง ไม่ต้องท่องก่อนเรียนบทแรก

## คำศัพท์เพิ่มใน Phase 1

| คำ | ความหมาย | เริ่มใช้ |
|---|---|---|
| Variable | ตัวแปรที่มีชื่อ ชนิด และค่า | EP5 |
| Zero value | ค่าเริ่มต้นเมื่อไม่ได้กำหนดค่า เช่น 0, false, ข้อความว่าง | EP7 |
| Format verb | ตัวกำหนดรูปแบบเช่น %s, %d, %.1f | EP8 |
| Type conversion | แปลงค่าเป็นอีกชนิดอย่างชัดเจน เช่น float64(total) | EP9 |
| Condition | คำถามที่ให้ผล bool | EP10 |
| Loop | คำสั่งทำซ้ำตามเงื่อนไข | EP11 |
| Parameter / argument | ตัวแปรรับค่า / ค่าที่ส่งตอนเรียก | EP12 |
| Return | คืนผลและจบการเรียกฟังก์ชันครั้งนั้น | EP13 |
| Error / nil | ค่าบอกปัญหา / ไม่มี error ในสัญญาการคืนค่าที่ใช้ | EP14 |
| Array / index | ชุดข้อมูลความยาวคงที่ / ตำแหน่งเริ่ม 0 | EP15 |
| Slice | ค่าที่อ้างถึงช่วงของ array | EP16 |
| Map / key | คู่ข้อมูลค้นด้วยกุญแจ / กุญแจค้นหา | EP17 |
| Struct / field | ชนิดรวมข้อมูล / ช่องข้อมูลที่มีชื่อ | EP18 |
| Method / receiver | ฟังก์ชันที่ผูกกับชนิด / ค่าฝั่งที่เรียก method | EP19 |
| Pointer | ค่าที่ชี้ไปยังตัวแปร ใช้ & และ * ตามหน้าที่ | EP20 |
| Export | เปิดให้ package อื่นใช้ชื่อที่ขึ้นต้นตัวใหญ่ | EP21 |
| Dependency | ชุดโค้ดที่โปรแกรมต้องใช้ | EP22 |
| Boundary test | ทดสอบค่าต่ำกว่า เท่ากับ และสูงกว่าเกณฑ์ | EP24 |
| Validation | ตรวจข้อมูลตามข้อกำหนด | EP26 |
| Continue | ข้ามส่วนที่เหลือของรอบแล้วไปทำรอบถัดไป | EP27 |
| Regression | พฤติกรรมเดิมเสียหลังแก้โค้ด | EP28 |
