# ตรวจสอบและแก้ไขปัญหาทีละขั้นตอน

## 1. เครื่องมือพร้อมหรือยัง

ใช้ PowerShell หรือ Command Prompt (cmd) แล้วลอง:

```shell
go version
```

ถ้าไม่พบคำสั่ง ให้ตรวจว่าติดตั้งหรือยัง และเปิด terminal ใหม่แล้วหรือยัง หากใช้ VS Code ที่เปิดค้างไว้ก่อนติดตั้ง Go ให้เปิด VS Code ใหม่ด้วย ดู [setup-windows.md](setup-windows.md) ก่อนแก้ไข PATH หรือ GOROOT

## 2. อยู่โฟลเดอร์ไหน และรันอะไร

ดูเส้นทางหน้าคำสั่งใน terminal แล้วแสดงรายการไฟล์ด้วยคำสั่งนี้ ใช้ได้ทั้ง PowerShell และ cmd:

```shell
dir
```

ที่โฟลเดอร์ `lessons/01-hello-go` จะเห็น `go.mod` กับ `examples` ใช้ `go run ./examples/hello` ถ้าอยู่ผิดโฟลเดอร์ ใน VS Code ให้คลิกขวาโฟลเดอร์บทเรียนแล้วเลือก **Open in Integrated Terminal**

ส่วนงานที่แก้ฝึกเองใช้โฟลเดอร์ `Go/practics/phase-01/ep01-hello-go` และสั่ง `go run .` จากในโฟลเดอร์นั้น ดู [วิธีฝึก](../docs/PRACTICE.md) การรันราก `Go` หรือรากบทด้วย `go run .` จะไม่ใช่ตำแหน่งของโปรแกรมตัวอย่าง

## 3. อ่าน compiler error

เก็บข้อความแรกกับชื่อไฟล์และเลขบรรทัด ตรวจตัวใหญ่เล็กของ Println, quote ตรง, วงเล็บ และปีกกา บันทึกไฟล์ แก้ครั้งละจุด แล้วรันคำสั่งเดิมเพื่อพิสูจน์สาเหตุ อย่าแก้ไฟล์ตัวอย่างโดยไม่รู้ว่าแตกต่างตรงไหน

## 4. อักษรไทยเพี้ยน

บันทึก source เป็น UTF-8 และเลือกฟอนต์ที่รองรับไทย ตัวอย่างแรกใช้ข้อความภาษาอังกฤษเพื่อแยกปัญหาการแสดงอักษรออกจากการเริ่มเรียน ยังไม่ต้องเปลี่ยน code page ทั้งระบบ

## 5. สคริปต์ตรวจถูกบล็อก

ถ้า PowerShell ไม่ยอมรัน `tests/verify.ps1` ไม่ต้องเปลี่ยน execution policy ให้ใช้คำสั่งตรวจทีละบรรทัดใน `tests/README.md` สคริปต์เป็นตัวช่วย ไม่ใช่ข้อบังคับสำหรับการเรียน

## 6. เวอร์ชันหรือ toolchain ไม่ตรง

ตรวจ `go version` และอ่านค่า `go` ใน go.mod ถ้า Go เก่ากว่า 1.22.0 ให้ใช้ stable ที่รองรับอยู่จากทางการ บท 1 ไม่มี external dependency หากเครื่องมือพยายามดาวน์โหลดหรือเกิด proxy error ให้เก็บข้อความและตรวจการตั้งค่าเดิมก่อน ไม่เพิ่ม `go get` เพื่อแก้แบบสุ่ม

## เมื่อต้องการให้ช่วยดู

ส่งชื่อบท โฟลเดอร์ที่รัน คำสั่ง ผล `go version` และ error เต็มของการทดลองที่เกี่ยวข้อง พร้อมสิ่งที่คาดว่าจะเกิด ใช้เฉพาะข้อมูลจำลอง ตรวจให้ไม่มีรหัสผ่านหรือข้อมูลบริษัทติดมาด้วย
