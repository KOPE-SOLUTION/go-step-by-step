# go-step-by-step — เรียน Go ทีละก้าว

หลักสูตรภาษา Go สำหรับผู้เริ่มต้น อธิบายเป็นภาษาไทย พร้อมโค้ดตัวอย่างและแบบฝึกหัดสั้น ๆ เรียนทีละเรื่องและทบทวนได้ตามเวลาของตัวเอง

**พร้อมเรียน:** Phase 1 — พื้นฐาน Go ครบ 28 EP ส่วน Phase 2–5 ยังเป็นแผนสำหรับต่อยอด

## เริ่มเรียน

1. เปิด terminal แล้วพิมพ์ `go version` เพื่อตรวจว่าเครื่องมี Go พร้อมใช้งาน หากไม่พบคำสั่ง ดู [วิธีตรวจเครื่องมือ](notes/troubleshooting.md)
2. เริ่มที่ [EP.1 — รัน Go ครั้งแรก](lessons/01-hello-go/EP01.md)
3. อ่านโค้ด ลองรัน และทำแบบฝึกหัดในหน้าเดียวกัน เมื่อพร้อมค่อยไปตอนต่อไปจาก [สารบัญ Phase 1](docs/playlist-01-go-basic/README.md)

## เส้นทางการเรียนรู้

หลักสูตรแบ่งเป็น 5 ช่วง หรือ **Phase** โดยใช้ข้อมูลอุณหภูมิจากอุปกรณ์จำลองเป็นตัวอย่าง เริ่มจากโปรแกรมแสดงข้อความ แล้วค่อยต่อยอดไปสู่การรับส่งและจัดเก็บข้อมูล

| Phase | เนื้อหา | สิ่งที่จะได้ฝึก |
|---|---|---|
| 1 | [พื้นฐาน Go](docs/playlist-01-go-basic/README.md) | เขียนโปรแกรมเล็ก ๆ และรายงานค่าอุณหภูมิใน terminal |
| 2 | การเขียนโปรแกรมใช้งาน | อ่านไฟล์ตั้งค่า จัดการไฟล์ และทำงานหลายอย่างพร้อมกัน |
| 3 | Back-end และ API | สร้างบริการให้โปรแกรมอื่นเรียกอ่านหรือส่งข้อมูล |
| 4 | Database | บันทึกและค้นข้อมูลในฐานข้อมูล |
| 5 | IoT และ Edge Gateway | รับข้อมูลจากอุปกรณ์จำลอง ส่งผ่าน MQTT และเก็บข้อมูลไว้เมื่อการเชื่อมต่อขัดข้อง |

ดูรายละเอียดและลำดับหัวข้อใน [ROADMAP](ROADMAP.md) และ [แผน Phase 2–5](docs/FUTURE_ROADMAP.md)

## พื้นที่ฝึก

สร้างโฟลเดอร์ `practics` ภายในโฟลเดอร์หลักสูตร แล้วสร้าง `main.go` ข้างในครั้งเดียว เมื่อขึ้น EP ใหม่ก็เปลี่ยนโค้ดในไฟล์เดิมได้ ตัวอย่างแต่ละตอนยังเปิดย้อนดูได้ใน `lessons/`

ช่วง EP.1–20 รันจาก `practics` ด้วย `go run main.go` เมื่อถึงบท package และการทดสอบ จึงค่อยเพิ่มไฟล์ตามขั้นตอนในบท

`practics/` ถูก Git ignore งานฝึกจึงไม่ติดไปกับการเพิ่มไฟล์เข้า Git ตามปกติ ผู้ที่ดาวน์โหลดหลักสูตรมาจะสร้างพื้นที่นี้เอง ดู [วิธีเริ่มฝึก](docs/PRACTICE.md)

## โครงสร้างโดยย่อ

```text
Go/
  README.md       # หน้าเริ่มต้น
  ROADMAP.md      # แผนหลักสูตร
  docs/           # สารบัญและวิธีฝึก
  lessons/        # บทเรียน ตัวอย่าง แบบฝึกหัด และเฉลย
  practics/       # พื้นที่ฝึกที่สร้างเอง
    main.go
  projects/       # พื้นที่สำหรับโปรเจกต์ในอนาคต
  notes/          # คำศัพท์ วิธีแก้ปัญหา และผลตรวจ
  scripts/        # เครื่องมือสำหรับตรวจตัวอย่าง
```

## ขอบเขตการทดลอง

ใช้ข้อมูลจำลองและบริการบนเครื่องตัวเองเป็นหลัก ไม่เชื่อมต่ออุปกรณ์หรือระบบของบริษัท ตัวอย่างไม่ใช้รหัสผ่านหรือข้อมูลจริงขององค์กร

ช่วงพื้นฐานยังไม่ใช้ Docker ส่วนบทคิวข้อมูลและการยืนยันว่าได้รับข้อมูลแล้วเป็นแบบฝึกหัดเพื่อทำความเข้าใจ ยังไม่ใช่ระบบที่พร้อมนำไปใช้งานจริง

<details>
<summary>การจัดโค้ดและผลตรวจ</summary>

**Module** คือชุดโค้ดที่มี `go.mod` ระบุชื่อและเวอร์ชัน Go ขั้นต่ำ ตัวอย่างใน `lessons/` แยก module ตาม EP เพื่อให้รันและทดสอบแต่ละตอนได้อิสระ ส่วนพื้นที่ฝึกเริ่มใช้ module เดียวร่วมกันตั้งแต่ EP.21

ตัวอย่างประกาศ Go 1.22.0 เป็นขั้นต่ำ และมีผลตรวจด้วย Go 1.27.1 บน Windows ยังไม่ได้ทดสอบด้วย Go 1.22 หรือบนระบบปฏิบัติการอื่น
